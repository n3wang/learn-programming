# Game systems design

## 6.1.1 Identify and diagram a system pattern from an existing game

:::caution Instructor question
Pick a favourite game. Identify a feedback loop (balancing or reinforcing) and **diagram** the relationship. Drawings, icons, or even Paint are fine. Clarity and systemic correctness matter more than polish.
:::

:::tip Gabriel’s tip
A simple reinforcing loop is enough. Do not list every element. Abstract, and show a tiny part of the game. You can grow the diagram later.
:::

:::info Reflection opportunity
How do real-world systems influence game systems? Which real-world systems are over- or underrepresented in video and board games? In your favourite games?
:::

## 6.2 What other systems can you add?

:::caution Instructor question
You have a solid core: a fun, meaningful combat system. Next, add a **meta-system**: a system that takes performance from core play and lets players invest resources to improve that core. Meta-systems often use “engine” patterns and happen **between matches**.

Design a meta-game around combat. Add elements that feed combat and feed themselves. **Diagram** how the meta-game feeds back into core play.

Then implement it and playtest if you can. Extra art in a similar style is available from [Kenney Assets](https://kenney.nl/).
:::

:::tip Gabriel’s tip
Stuck? Think of an RPG: core play is combat; doing well gives coins and XP; better weapons and skills improve combat; that yields more coins and XP. The cycle continues.
:::

:::info Reflection opportunity
Meta-systems often “keep players playing.” Find a free-to-play game, identify a meta-system, and explain how it might keep people playing longer.
:::
