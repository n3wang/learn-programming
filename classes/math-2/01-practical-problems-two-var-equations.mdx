# 实际问题与二元一次方程组

> 用两个未知数描述两类事物，再从题目里找出**两个相等关系**，列成二元一次方程组。下面五道练习都可以点「书题目」回到原题，或点「随机」换数字反复练。

一元一次方程只有一个未知数；当题目里天然出现两类数量（大巴与小巴、VIP 与普通、成人票与学生票……），往往更适合设两个未知数，写出两个方程联立求解。解法见上一课：[解二元一次方程组](./solving-systems-of-equations)（代入法、加减消元法）。

解题步骤与一元时类似，只是「列」变成了列**方程组**：

**设** 两个未知数 → **列** 两个方程 → **解** 方程组（代入法或加减消元法）→ **检**验 → **答**。

## 4. 影院票：总张数 + 总收入

这是最常见的骨架：一类方程是 x + y = 总数，另一类是单价加权和。用代入法很顺手——由第一个方程写出 y = 总数 − x，再代入第二个。

## 5. 稍难：没有「总数」方程

篮球队、排球队的人数和报名费都不同，题目只给了总报名费和总运动员人数——**没有**「一共多少支队」。这时两个方程都是加权和，仍然可以直接联立；只是不能再靠 x + y = n 做代入，加减消元更合适。

书题目对应的方程组是：

$$
\begin{cases}
600x + 800y = 8800 \\
12x + 18y = 186
\end{cases}
$$

（约分后即 $3x+4y=44$，$2x+3y=31$。）

<SportsTeamTwoVarSimulator />

:::tip 什么时候用二元一次方程组？
问自己：题目里是不是有**两类**需要分别求出来的量？能不能找到**两个彼此独立的相等关系**？如果只有一个相等关系、却硬设两个未知数，方程会不够；如果两个关系其实不独立（一个是另一个的倍数），方程组会无解或无穷多解——这时要回到题意检查。
:::

## 小结

| 题型 | 典型方程组 |
| --- | --- |
| 总数 + 金额（票） | $x+y=n$，$ax+by=c$ |
| 人数 + 金额（车、包厢） | $a_1x+b_1y=c_1$，$a_2x+b_2y=c_2$（总数可检验） |
| 两个加权和、无总数 | 同上，但必须两个加权方程都用上 |
