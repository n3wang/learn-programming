# 11.2 一元一次不等式

> **改编自：** 人教版《义务教育教科书·数学》八年级 第十一章 11.2。上一课是 [习题 11.1](./inequality-exercises)。

不等式有多种类型。与学习了方程后重点研究一元一次方程类似，本节研究一类简单的不等式，探索它的解法，并用它解决一些实际问题。

## 思考：它们有什么共同特征？

观察下面的不等式：

$$
x - 7 > 26,\quad 3x < 2x + 1,\quad \frac{2}{3}x > 50,\quad -4x > 3.
$$

每个不等式都只含有一个未知数，含有未知数的式子都是整式，未知数的次数是 1。

类似于一元一次方程，只含有一个未知数，且含有未知数的式子都是整式，未知数的次数是 1 的不等式，叫作**一元一次不等式**。

## 移项

上一节例 3 解 x − 7 &gt; 26 时，根据不等式的性质 1，两边加 7，不等号的方向不变，得

$$
x - 7 + 7 > 26 + 7,
$$

即 x &gt; 26 + 7。

这一过程相当于把左边的项 −7 变号为 +7 后移到右边。解不等式时也可以移项：把不等式一边的某项变号后移到另一边，不等号的方向不变。

一般地，利用不等式的性质，采取与解一元一次方程类似的步骤，就可以求出一元一次不等式的解集。常见步骤是：去分母、去括号、移项、合并同类项，再把系数化为 1。系数化为 1 时，如果除以负数，不等号方向要改变。

## 思考

解一元一次不等式与解一元一次方程的步骤和依据有什么类似之处？

步骤都可以是去分母、去括号、移项、合并同类项、把系数化为 1。依据不同：方程用等式的性质，最后化成 x = m；不等式用不等式的性质，最后化成 x &lt; m、x ≤ m、x &gt; m 或 x ≥ m。乘或除以负数时，方程的等号不变，不等式的不等号要变向。

## 练习

### 1. 解下列不等式，并在数轴上表示解集

(1) 5x + 15 &gt; 4x − 1。移项后 x &gt; −16。空心圆圈在 −16，射线向右。

<InequalitySolutionSetSimulator demo label="−16" dir="right" />

(2) 2(x + 5) ≤ 3(x − 5)。去括号得 2x + 10 ≤ 3x − 15，移项合并得 −x ≤ −25。两边除以 −1，方向改变，x ≥ 25。实心圆圈在 25，射线向右。

<InequalitySolutionSetSimulator demo label="25" dir="right" closed />

(3) (x − 1)/7 &gt; (2x + 5)/3。两边乘 21，得 3(x − 1) &gt; 7(2x + 5)，即 3x − 3 &gt; 14x + 35。移项合并得 −11x &gt; 38。两边除以 −11，方向改变，x &lt; −38/11。空心圆圈在 −38/11，射线向左。

<InequalitySolutionSetSimulator demo label="−38/11" dir="left" />

(4) (x + 1)/6 ≥ (2x − 5)/4 + 1。两边乘 12，得 2(x + 1) ≥ 3(2x − 5) + 12，即 2x + 2 ≥ 6x − 3。移项合并得 −4x ≥ −5。两边除以 −4，方向改变，x ≤ 5/4。实心圆圈在 5/4，射线向左。

### 2. 当 x 或 y 满足什么条件时，下列关系成立？

(1) 2(x + 1) 大于或等于 1。写成 2(x + 1) ≥ 1，解得 x ≥ −1/2。

(2) 4x 与 7 的和不小于 6。不小于是 ≥，写成 4x + 7 ≥ 6，解得 x ≥ −1/4。

(3) y 与 1 的差不大于 2y 与 3 的差。不大于是 ≤，写成 y − 1 ≤ 2y − 3。移项合并得 −y ≤ −2，两边除以 −1，方向改变，y ≥ 2。

(4) 3y 与 7 的和的 1/4 小于 −2。写成 (3y + 7)/4 &lt; −2，两边乘 4 得 3y + 7 &lt; −8，y &lt; −5。
