# 二元一次方程组应用题练习

> 第十章练习：从「运货组合」「票价表」「上下坡时间」到「分段计价」「账目验算」。点「书题目」回到原题，点「随机」换数字反复练。

上一课练过常见骨架（总数 + 金额、两个加权和）。本课把书上的综合题拆开：有的先求中间量再代入所问；有的要去分母、整理方程；有的两个方程其实矛盾——答案是「账记错了」。

解法仍是：**设 → 列 → 解 → 验 → 答**。需要复习消元时，回到 [解二元一次方程组](./solving-systems-of-equations)。

## 1. 大小货车：两组运量 → 求第三组

已知两种组合的运货量，先解出每辆大车、小车的运量，再代入「3 大 + 5 小」。

书题目对应：

$$
\begin{cases}
2x + 3y = 15.5 \\
5x + 6y = 35
\end{cases}
$$

解得 $x=4$，$y=2.5$，故 $3x+5y=24.5$。

## 3. 上坡 · 平路 · 下坡：求全程

去程走「上坡 + 平路」，回程走「下坡 + 平路」（同一段坡，方向反过来）。时间用小时（分钟 ÷ 60）列方程。

书题目：上坡 $30$、平路 $40$、下坡 $50$（km/h），$54$ min / $42$ min → 上坡 $15$ km、平路 $16$ km，全程 $31$ km。

## 4. 化工厂：公路运费 + 铁路运费

原料吨数 $x$、成品吨数 $y$。公路、铁路各自的「吨·公里 × 运价 = 总运费」各成一个方程；解出质量后再算「销售收入 −（原料费 + 运费）」。

## 5. 解方程组（含整理与去分母）

先把第二个方程整理成标准形，或两边乘公倍数去掉分数，再代入 / 消元。

**书题目（1）**

$$
\begin{cases}
3x - y = 5 \\
5y - 1 = 3x + 5
\end{cases}
$$

整理得 $-3x + 5y = 6$，与第一式联立，解为 $x=\dfrac{31}{12}$，$y=\dfrac{11}{4}$。

**书题目（2）**

$$
\begin{cases}
\dfrac{2}{3}x + \dfrac{3}{4}y = \dfrac{17}{12} \\[0.4em]
\dfrac{1}{6}x - \dfrac{1}{2}y = -\dfrac{1}{3}
\end{cases}
$$

去分母后得 $8x+9y=17$，$x-3y=-2$，解为 $x=1$，$y=1$。

## 9. 草坪与等宽通道

长方形场地分成 $3\times 2$ 块相同草坪，夹着等宽通道。一块草坪两边成定比，列「长边方程 + 宽边方程」求通道宽。

书题目：$18\times 13$，比 $8:9$ → 通道宽 $1$ m。

## 10. 展板 · 宣传册 · 横幅

宣传册件数是展板的倍数，三个量里其实只有两个未知数：时间方程 + 利润方程。问的是**总件数**。

## 11. 毛笔：分段零售价

超过阈值的部分单价更低。先按规则写出两方案实付（含常数优惠项），再整理成关于零售价的二元一次方程组。

## 12. 牙刷牙膏账目：是否有误？

若两天销量成同一比例，价格不变时收入也应成同一比例。比例对、收入不对 → 方程组矛盾，账有误。

书题目：牙刷 $39:52$、牙膏 $21:28$ 都是 $3:4$，收入应按比例为 $528$ 元，账上却是 $518$ 元。

## 13. 自己编一道应用题

编一道符合实际意义的应用题，使未知数满足：

$$
\begin{cases}
2x + 3y = 21 \\
3x + 4y = 29
\end{cases}
$$

（可先解出 $x=3$，$y=5$，再反过来编故事：例如「大杯 $2$ 杯、小杯 $3$ 杯共 $21$ 元……」。）

与同学交换题目，互相求解并检验。

:::tip 编题小提示
- 两个方程要**彼此独立**（一个不是另一个的倍数），否则无唯一解。
- $x$、$y$ 取正数更符合「件数、人数、价钱」等实际意义。
- 编完后把解代回方程验算一遍。
:::

## 小结

| 题型 | 关键 |
| --- | --- |
| 两组组合 → 求第三组 | 先解 $x,y$，再代入所问线性式 |
| 票 / 徒步 / 机器人 | 总数或相差 + 加权和；或已解出一式直接代入 |
| 上下坡时间 | 去程、回程各一个时间方程；注意坡段速度不同 |
| 运费 / 展板利润 | 两个加权方程；问的可能是派生量（利润差、总件数） |
| 分段计价 | 超量部分写成「零售价 − 优惠」，移项后成标准方程组 |
| 账目检验 | 系数成比例时看右边是否同比例；否则无解 → 记录有误 |
| 几何通道 | 用块数 × 草坪边 + 通道条数 × 宽 = 场地边长 |
