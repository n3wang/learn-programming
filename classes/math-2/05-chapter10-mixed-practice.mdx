# 10.1–10.4 综合练习

<Chapter10MixedPractice>

从第十章各课的练习里均衡抽题，一题接一题做完。上一课是 [10.4 应用与复习](./three-var-applications-practice)，做完后去 [小结：二元一次方程组](./systems-summary)。

题目来自：

- [10.1 概念](./two-var-system-concept)：判断是不是方程组的解、由解求系数；
- [10.2 消元](./solving-systems-of-equations)：代入法、加减消元法；
- [10.3 实际问题](./practical-problems-two-var-equations) 与 [综合练习](./two-var-applications-practice)：列二元一次方程组解应用题；
- [10.4 三元解法](./solving-three-var-systems) 与 [应用](./three-var-applications-practice)：三元一次方程组及其应用。

默认一组 **10 题**，可以改成 5 题或 15 题。每题先在纸上写完整过程（**设 → 列 → 解 → 验 → 答**），再把每个未知数的值填进对应的框里（应用题的框旁边写着 $x$、$y$、$z$ 各代表什么），点「检查」。

- 答案可以写整数、小数或分数，分数写成 `5/2`、`-3/4`；
- 填错了可以改了再检查，卡住了随时可以点右边的「💡 看讲解」——但看了这一题就算错，「连对」也会清零；
- 做完一组会显示各课的对错情况，错得多的那一课建议回去再练。

</Chapter10MixedPractice>
