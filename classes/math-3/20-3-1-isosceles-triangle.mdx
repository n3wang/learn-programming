# 20.3.1 等腰三角形

> **改编自：** 人教版八年级上册（五·四学制）20.3.1。上一课是 [20.2 画轴对称图形](./drawing-symmetric-figures)。

有两条边相等的三角形叫做**等腰三角形**。相等的两边叫做**腰**，另一边叫做**底边**，两腰的夹角叫做**顶角**，腰和底边的夹角叫做**底角**。

把一张长方形纸对折，剪出一个三角形再展开，就得到一个等腰三角形 ABC（$AB = AC$）。它是轴对称图形，折痕 $AD$ 就是对称轴。沿折痕重合的有：

- $AB$ 与 $AC$，$BD$ 与 $CD$；
- $\angle B$ 与 $\angle C$，$\angle BAD$ 与 $\angle CAD$，$\angle ADB$ 与 $\angle ADC$。

---

## 一、等腰三角形的性质

<IsoscelesSimulator />

> **性质 1**　等腰三角形的两个底角相等（简写成「**等边对等角**」）。
>
> **性质 2**　等腰三角形的顶角平分线、底边上的中线、底边上的高相互重合（简写成「**三线合一**」）。

**证明性质 1：** 作底边的中线 $AD$。

<GeoFig
  width={220}
  points={{ A: [0, 3.6], B: [-2, 0], C: [2, 0], D: [0, 0] }}
  segments={['AB', 'AC', 'BC', { s: 'AD', dash: true, color: '#e0245e' }]}
  ticks={[['AB', 1], ['AC', 1], ['B D', 2], ['D C', 2]]}
  labelPos={{ D: 's' }}
/>

$$
\left.\begin{aligned}
&AB = AC \\
&BD = CD \\
&AD = AD
\end{aligned}\right\}
\Rightarrow \triangle BAD \cong \triangle CAD\ (\text{SSS}) \Rightarrow \angle B = \angle C .
$$

同时还得到 $\angle BAD = \angle CAD$，$\angle ADB = \angle ADC = 90^\circ$，所以中线 $AD$ 也是顶角平分线和底边上的高——这就是性质 2。

由轴对称还可以知道：**等腰三角形是轴对称图形，底边上的中线（顶角平分线、底边上的高）所在的直线就是它的对称轴。**

### 例 1

在 △ABC 中，$AB = AC$，点 $D$ 在 $AC$ 上，且 $BD = BC = AD$。求 △ABC 各角的度数。

<GeoFig
  width={220}
  points={{ A: [0, 4.6], B: [-1.5, 0], C: [1.5, 0], D: [0.57, 2.85] }}
  segments={['AB', 'AC', 'BC', { s: 'BD', color: '#e0245e' }]}
  ticks={[['BD', 2], ['BC', 2], ['AD', 2]]}
  labelPos={{ D: 'e' }}
/>

**分析：** 图里有三个等腰三角形：△ABC、△ABD、△BCD。设 $\angle A = x$，用「等边对等角」把每个角都用 $x$ 表示，再用内角和列方程。

**解：** $AD = BD$，所以 $\angle ABD = \angle A = x$；$\angle BDC$ 是 △ABD 的外角，$\angle BDC = 2x$。

$BD = BC$，所以 $\angle C = \angle BDC = 2x$；$AB = AC$，所以 $\angle ABC = \angle C = 2x$。

在 △ABC 中：$x + 2x + 2x = 180^\circ$，$x = 36^\circ$。

所以 $\angle A = 36^\circ$，$\angle ABC = \angle C = 72^\circ$。

:::tip 设而不求、用方程表示角
等腰三角形套等腰三角形时，**设最小的那个角为 $x$**，沿着「等边对等角」和「外角等于不相邻两内角之和」一路推，最后用内角和 180° 列方程。
:::

## 二、等腰三角形的判定

反过来，如果一个三角形有两个角相等，那么它们所对的边相等吗？

> **判定**　如果一个三角形有两个角相等，那么这两个角所对的边也相等（简写成「**等角对等边**」）。

**证明：** 在 △ABC 中，$\angle B = \angle C$。作 $\angle BAC$ 的平分线 $AD$，则 △BAD 和 △CAD 中 $\angle 1 = \angle 2$，$\angle B = \angle C$，$AD = AD$，所以 $\triangle BAD \cong \triangle CAD\ (\text{AAS})$，$AB = AC$。

### 例 2

求证：如果三角形一个外角的平分线平行于三角形的一边，那么这个三角形是等腰三角形。

<GeoFig
  width={260}
  points={{ A: [0, 2.6], B: [-2.2, 0], C: [1.6, 0], D: [-1.4, 4.2], E: [2.5, 2.6] }}
  segments={['AB', 'AC', 'BC', { s: 'A D', dash: true }, { s: 'A E', color: '#e0245e' }]}
  labelPos={{ A: 'n', E: 'e' }}
  caption="∠CAD 是外角，AE 平分 ∠CAD，AE ∥ BC"
/>

**已知：** $\angle CAD$ 是 △ABC 的外角，$\angle 1 = \angle 2$（$AE$ 平分 $\angle CAD$），$AE \parallel BC$。**求证：** $AB = AC$。

**证明：** $AE \parallel BC$，所以 $\angle 1 = \angle B$（同位角相等），$\angle 2 = \angle C$（内错角相等）。又 $\angle 1 = \angle 2$，所以 $\angle B = \angle C$，于是 $AB = AC$（等角对等边）。

### 例 3　作等腰三角形

已知等腰三角形底边长为 $a$，底边上的高为 $h$，求作这个三角形。

1. 作线段 $AB = a$；
2. 作 $AB$ 的垂直平分线 $MN$，与 $AB$ 交于 $D$；
3. 在 $MN$ 上取一点 $C$，使 $DC = h$；
4. 连接 $AC$、$BC$，△ABC 就是所求的等腰三角形。

依据：垂直平分线上的点到 $A$、$B$ 距离相等，所以 $CA = CB$。

## 三、分类讨论

题目只说「等腰三角形有一个角是 50°」「一边长 4、周长 20」时，**不知道它是顶角还是底角、是腰还是底**，必须分情况，最后还要检验：

- 角：钝角只能作顶角（两个钝角加起来就超过 180°）；锐角两种都有可能。
- 边：两腰之和要**大于**底边，才能组成三角形。

## 小结

| | 内容 |
| --- | --- |
| 性质 1 | 等边对等角 |
| 性质 2 | 三线合一（顶角平分线、底边中线、底边上的高） |
| 判定 | 等角对等边 |
| 对称轴 | 底边上的中线所在直线 |
| 解题方法 | 设角为 $x$ 列方程；不确定时分类讨论并检验三边关系 |
