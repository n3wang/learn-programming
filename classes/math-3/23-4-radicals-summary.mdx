# 小结：二次根式

> 第二十三章复习。前面的课：[23.1 二次根式](./quadratic-radicals)、[23.2 乘除](./radical-multiplication)、[23.3 加减](./radical-addition)。

## 一、知识结构

| 主题 | 内容 |
| --- | --- |
| 概念 | $\sqrt a\ (a\ge 0)$；有意义 ⇔ $a\ge 0$；双重非负性 $\sqrt a\ge 0$ |
| 性质 | $(\sqrt a)^2 = a\ (a\ge 0)$；$\sqrt{a^2} = \lvert a\rvert$ |
| 乘除 | $\sqrt a\cdot\sqrt b = \sqrt{ab}$；$\frac{\sqrt a}{\sqrt b} = \sqrt{\frac ab}$（$a\ge 0$，$b>0$） |
| 最简二次根式 | 被开方数不含分母、不含开得尽方的因数（因式） |
| 加减 | 先化最简，再合并同类二次根式 |
| 混合运算 | 运算律、乘法公式照样用 |

## 二、回顾与思考

1. 二次根式的乘除法则**反过来**就是化简的方法：$\sqrt{ab} = \sqrt a\cdot\sqrt b$、$\sqrt{\frac ab} = \frac{\sqrt a}{\sqrt b}$。
2. 二次根式的加减类比整式的「合并同类项」；混合运算类比整式运算——把 $\sqrt2$、$\sqrt3$ 看成字母一样处理。
3. 所有法则都有条件：被开方数非负，除数不为 0。

## 三、本章易错点

| 错误 | 正确 |
| --- | --- |
| $\sqrt{(-3)^2} = -3$ | $= 3$ |
| $\sqrt2 + \sqrt3 = \sqrt5$ | 不能合并 |
| $2\sqrt3\times 3\sqrt3 = 6\sqrt3$ | $= 6\times 3 = 18$ |
| $\sqrt{12}$ 作为最后答案 | $2\sqrt3$ |
| $\frac{1}{\sqrt2}$ 作为最后答案 | $\frac{\sqrt2}{2}$ |

## 四、复习题 23

**1.** 已知 $x = \sqrt3 + 1$，$y = \sqrt3 - 1$，求 $x^2 - y^2$ 和 $x^2 + xy + y^2$。

<details>
<summary>答案</summary>

$x + y = 2\sqrt3$，$x - y = 2$，$xy = 3 - 1 = 2$。$x^2 - y^2 = (x+y)(x-y) = 4\sqrt3$；$x^2 + xy + y^2 = (x+y)^2 - xy = 12 - 2 = 10$。

</details>

**2.** 比较大小：$3\sqrt2$ 与 $2\sqrt3$。

<details>
<summary>答案</summary>

把系数移到根号里：$3\sqrt2 = \sqrt{18}$，$2\sqrt3 = \sqrt{12}$，所以 $3\sqrt2 > 2\sqrt3$。

</details>

**3.** 已知 $a < 2$，化简 $\sqrt{(a-2)^2} + |a - 5|$。

<details>
<summary>答案</summary>

$\sqrt{(a-2)^2} = |a - 2| = 2 - a$；$a < 2 < 5$，$|a - 5| = 5 - a$。原式 $= 7 - 2a$。

</details>
