# 20.3.2 等边三角形

> **改编自：** 人教版八年级上册（五·四学制）20.3.2。上一课是 [20.3.1 等腰三角形](./isosceles-triangle)。

三条边都相等的三角形叫做**等边三角形**（正三角形）。等边三角形是特殊的等腰三角形——把任何一条边看成底边都可以。

---

## 一、性质与判定

把等腰三角形的性质用到每一条边上：

> **性质**　等边三角形的三个内角都相等，并且每一个角都等于 $60^\circ$。

**判定：**

1. 三个角都相等的三角形是等边三角形；
2. **有一个角是 $60^\circ$ 的等腰三角形**是等边三角形。

第 2 条为什么对？若 $60^\circ$ 是顶角，两个底角各 $(180^\circ - 60^\circ)\div 2 = 60^\circ$；若 $60^\circ$ 是底角，另一个底角也是 $60^\circ$，顶角 $= 60^\circ$。两种情况三个角都是 $60^\circ$。

等边三角形是轴对称图形，有 **3 条**对称轴——每条边上的中线（高、对角平分线）所在的直线。

### 例 4

△ABC 是等边三角形，$DE \parallel BC$，分别交 $AB$、$AC$ 于点 $D$、$E$。求证 △ADE 是等边三角形。

<GeoFig
  width={220}
  points={{ A: [0, 3.46], B: [-2, 0], C: [2, 0], D: [-1, 1.73], E: [1, 1.73] }}
  segments={['AB', 'BC', 'CA', { s: 'DE', color: '#e0245e' }]}
  labelPos={{ D: 'w', E: 'e' }}
/>

**证明：** △ABC 是等边三角形，$\angle A = \angle B = \angle C$。$DE \parallel BC$，所以 $\angle ADE = \angle B$，$\angle AED = \angle C$。于是 $\angle A = \angle ADE = \angle AED$，△ADE 是等边三角形。

## 二、含 30° 角的直角三角形

用两个含 30° 角的三角尺拼成一个三角形：拼成的是等边三角形，于是发现了一个重要结论。

<GeoFig
  width={260}
  points={{ A: [0, 3.46], B: [0, 0], C: [2, 0], D: [-2, 0] }}
  segments={['AB', 'AC', 'BC', { s: 'AD', dash: true }, { s: 'D B', dash: true }]}
  right={['A B C']}
  arcs={[{ at: 'A', from: 'B', to: 'C', label: '30°', r: 26 }]}
  labelPos={{ B: 's', D: 'w' }}
  caption="延长 CB 到 D，使 BD = BC，△ACD 是等边三角形"
/>

> 在直角三角形中，如果一个锐角等于 $30^\circ$，那么它所对的直角边等于斜边的一半。

**证明：** 如图，在 Rt△ABC 中，$\angle ABC = 90^\circ$，$\angle BAC = 30^\circ$，斜边是 $AC$，要证 $BC = \frac12 AC$。

延长 $CB$ 到 $D$，使 $BD = BC$，连接 $AD$。$AB \perp CD$ 且平分 $CD$，所以 $AD = AC$；又 $\angle ACB = 90^\circ - 30^\circ = 60^\circ$，所以 △ACD 是等边三角形（有一个角是 60° 的等腰三角形），$CD = AC$。于是

$$
BC = \frac12 CD = \frac12 AC .
$$

### 例 5　屋架

屋架设计图的一部分：立柱 $BC$ 垂直于横梁 $AC$，$AB = 7.4\ \text{m}$，$\angle A = 30^\circ$。立柱 $BC$、$DE$ 要多长？（$D$ 是 $AB$ 的中点，$DE \perp AC$。）

<GeoFig
  width={280}
  points={{ A: [0, 0], C: [3.46, 0], B: [3.46, 2], D: [1.73, 1], E: [1.73, 0] }}
  segments={['AB', 'AC', 'BC', 'DE']}

  arcs={[{ at: 'A', from: 'C', to: 'B', label: '30°' }]}

**解：** Rt△ABC 中 $\angle A = 30^\circ$，所以 $BC = \frac12 AB = 3.7\ \text{m}$。$D$ 是 $AB$ 中点，$AD = 3.7\ \text{m}$；Rt△ADE 中 $\angle A = 30^\circ$，$DE = \frac12 AD = 1.85\ \text{m}$。

### 实验与探究：三角形中边与角的不等关系

同一个三角形里，**大边对大角，大角对大边**。比如 △ABC 中 $AC > BC$，在 $AC$ 上截取 $CD = CB$，则 $\angle CDB = \angle CBD$；而 $\angle ABC > \angle CBD = \angle CDB > \angle A$（外角大于不相邻的内角），所以 $\angle B > \angle A$。
