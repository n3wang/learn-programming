# 数学 八年级上册

八年级上册课堂笔记（人教版 五·四学制）。每一课都有讲解、例题、互动图，以及**自动出题、自动批改**的练习：数字每次重抽，式子直接打字输入（如 `x^2+5x+6`、`(x+2)(x-3)`、`3√2`），系统会检查结果对不对、形式是不是要求的形式（分解彻底、合并同类项、最简二次根式……）。

4. [20.3.2 等边三角形](./equilateral-triangle)（性质与判定；含 30° 角的直角三角形）
