# 小结：整式的乘法与因式分解

> 第二十一章复习。前面的课：[幂的运算](./power-rules)、[整式的乘法与除法](./polynomial-multiplication)、[乘法公式](./multiplication-formulas)、[因式分解](./factorization)。

## 一、知识结构

| 层次 | 内容 |
| --- | --- |
| 幂的运算 | $a^m a^n = a^{m+n}$，$(a^m)^n = a^{mn}$，$(ab)^n = a^nb^n$，$a^m\div a^n = a^{m-n}$，$a^0 = 1$ |
| 整式乘法 | 单 × 单 → 单 × 多（分配律）→ 多 × 多 |
| 整式除法 | 单 ÷ 单；多 ÷ 单（逐项相除） |
| 乘法公式 | $(a+b)(a-b) = a^2 - b^2$；$(a\pm b)^2 = a^2\pm 2ab + b^2$ |
| 因式分解 | 提公因式法；公式法；$x^2 + (p+q)x + pq = (x+p)(x+q)$ |

**整式乘法与因式分解是互逆的变形**：

$$
\underbrace{(a+b)(a-b)}_{\text{积}}\ \underset{\text{因式分解}}{\overset{\text{整式乘法}}{\rightleftarrows}}\ \underbrace{a^2 - b^2}_{\text{和差}}
$$

## 二、回顾与思考

1. 单项式乘多项式、多项式乘多项式，最终都**转化**为单项式乘单项式；单项式乘单项式又转化为幂的运算。这就是「转化」的思想。
2. 乘法公式是特殊的多项式乘法，记住它们的**结构**：平方差两项，完全平方三项。
3. 因式分解要分解到每个因式都**不能再分解**为止（在有理数范围内）。

## 三、本章易错点

| 错误 | 正确 |
| --- | --- |
| $a^3 + a^3 = a^6$ | $a^3 + a^3 = 2a^3$ |
| $(a^3)^2 = a^5$ | $(a^3)^2 = a^6$ |
| $(-3a)^2 = -9a^2$ | $(-3a)^2 = 9a^2$ |
| $(a+b)^2 = a^2 + b^2$ | $(a+b)^2 = a^2 + 2ab + b^2$ |
| $x^3 - x = x(x^2-1)$ | $x^3 - x = x(x+1)(x-1)$（要分解彻底） |
| $-x - y$ 提 $-$ 后写成 $-(x - y)$ | $-(x + y)$：括号里每项都变号 |

## 四、复习题 21

**1.** 已知 $a + b = 7$，$ab = 12$，求 $a^2 + b^2$ 和 $(a-b)^2$。

<details>
<summary>答案</summary>

$a^2 + b^2 = (a+b)^2 - 2ab = 49 - 24 = 25$；$(a-b)^2 = (a+b)^2 - 4ab = 49 - 48 = 1$。

</details>

**2.** 利用因式分解计算：$2025^2 - 2024^2$；$1.99^2 + 1.99\times 0.02 + 0.01^2$。

<details>
<summary>答案</summary>

$2025^2 - 2024^2 = (2025 + 2024)(2025 - 2024) = 4049$；第二个是完全平方：$(1.99 + 0.01)^2 = 4$。

</details>

**3.** 说明：两个连续奇数的平方差是 8 的倍数。

<details>
<summary>答案</summary>

设两个连续奇数为 $2n+1$、$2n-1$。$(2n+1)^2 - (2n-1)^2 = [(2n+1)+(2n-1)][(2n+1)-(2n-1)] = 4n\cdot 2 = 8n$，是 8 的倍数。

</details>

**4.** 若 $x^2 - mx + 16$ 是完全平方式，求 $m$。

<details>
<summary>答案</summary>

$x^2 - mx + 16 = (x\pm 4)^2$，中间项 $\pm 8x$，所以 $m = \pm 8$。

</details>
