# 23.3 二次根式的加减

> **改编自：** 人教版八年级上册（五·四学制）23.3 节。上一课是 [23.2 二次根式的乘除](./radical-multiplication)。

现有一块长 $7.5\ \text{dm}$、宽 $5\ \text{dm}$ 的木板，能否截出两个面积分别是 $8\ \text{dm}^2$ 和 $18\ \text{dm}^2$ 的正方形木板？

两个正方形边长分别是 $\sqrt8 = 2\sqrt2$、$\sqrt{18} = 3\sqrt2$，并排放需要长 $2\sqrt2 + 3\sqrt2$。这就要会二次根式的加法。

---

## 一、合并同类二次根式

$2\sqrt2 + 3\sqrt2$ 就像 $2x + 3x = 5x$：

$$
2\sqrt2 + 3\sqrt2 = (2+3)\sqrt2 = 5\sqrt2 \approx 7.07 < 7.5 ,
$$

而宽 $3\sqrt2\approx 4.24 < 5$，所以能截出。

化成最简二次根式后，**被开方数相同**的二次根式叫做**同类二次根式**，可以合并（类比合并同类项）。

> **二次根式加减时，先将二次根式化成最简二次根式，再将被开方数相同的二次根式合并。**

### 例 1

$\sqrt{80} - \sqrt{20} = 4\sqrt5 - 2\sqrt5 = 2\sqrt5$；

$\sqrt{12} + \sqrt{27} = 2\sqrt3 + 3\sqrt3 = 5\sqrt3$。

### 例 2

$2\sqrt{12} - 6\sqrt{\frac13} + 3\sqrt{48} = 4\sqrt3 - 2\sqrt3 + 12\sqrt3 = 14\sqrt3$；

$(\sqrt{48} + \sqrt{20}) + (\sqrt{12} - \sqrt5) = 4\sqrt3 + 2\sqrt5 + 2\sqrt3 - \sqrt5 = 6\sqrt3 + \sqrt5$（不同类的不能合并）。

:::caution 不能这样加
$\sqrt2 + \sqrt3 \ne \sqrt5$！被开方数不同的二次根式不能把被开方数相加。（试试：$\sqrt9 + \sqrt{16} = 7$，而 $\sqrt{25} = 5$。）
:::

### 例 3　周长

一个三角形三边长分别为 $\sqrt{12}\ \text{cm}$、$\sqrt{27}\ \text{cm}$、$\sqrt{48}\ \text{cm}$，周长 $= 2\sqrt3 + 3\sqrt3 + 4\sqrt3 = 9\sqrt3\ \text{cm}$。

---

## 二、二次根式的混合运算

整式的运算律、乘法公式在二次根式里**照样适用**。

### 例 4

$(\sqrt8 + \sqrt3)\times\sqrt6 = \sqrt{48} + \sqrt{18} = 4\sqrt3 + 3\sqrt2$（分配律）；

$(4\sqrt2 - 6\sqrt3)\div 2\sqrt2 = 2 - 3\cdot\frac{\sqrt3}{\sqrt2} = 2 - \frac{3\sqrt6}{2}$。

### 例 5　用乘法公式

$(\sqrt2 + 3)(\sqrt2 - 5) = 2 - 5\sqrt2 + 3\sqrt2 - 15 = -13 - 2\sqrt2$；

$(\sqrt5 + \sqrt3)(\sqrt5 - \sqrt3) = 5 - 3 = 2$（平方差公式）；

$(\sqrt3 + 1)^2 = 3 + 2\sqrt3 + 1 = 4 + 2\sqrt3$（完全平方公式）。

:::tip 互为有理化因式
$(\sqrt5 + \sqrt3)(\sqrt5 - \sqrt3) = 2$ 没有根号了。所以分母是 $\sqrt5 + \sqrt3$ 时，分子分母同乘 $\sqrt5 - \sqrt3$ 就能有理化：$\frac{1}{\sqrt5 + \sqrt3} = \frac{\sqrt5 - \sqrt3}{2}$。
:::

## 阅读与思考：海伦—秦九韶公式

已知三角形三边长 $a$、$b$、$c$，记 $p = \frac{a+b+c}{2}$，则面积

$$
S = \sqrt{p(p-a)(p-b)(p-c)} .
$$

古希腊的海伦和我国南宋的秦九韶（《数书九章》中的「三斜求积术」）都给出了这个公式。

例如三边 $13$、$14$、$15$：$p = 21$，$S = \sqrt{21\times 8\times 7\times 6} = \sqrt{7056} = 84$。
