# 21.2 乘法公式

> **改编自：** 人教版八年级上册（五·四学制）21.2 节。上一课是 [21.1 整式的乘法与除法](./polynomial-multiplication)。

有些多项式相乘的结果特别整齐，把它们记成公式，计算就快多了。

---

## 一、平方差公式

算几个例子：

| 算式 | 展开 |
| --- | --- |
| $(x+1)(x-1)$ | $x^2 - x + x - 1 = x^2 - 1$ |
| $(m+2)(m-2)$ | $m^2 - 4$ |
| $(2x+1)(2x-1)$ | $4x^2 - 1$ |

中间两项总是互相抵消。一般地：

$$
(a+b)(a-b) = a^2 - b^2 .
$$

> **两个数的和与这两个数的差的积，等于这两个数的平方差。**

### 怎么认出 $a$ 和 $b$

两个括号里，**完全相同的那一项**是 $a$，**只差一个符号的那一项**是 $b$。

### 例 1

| 题目 | $a$ | $b$ | 结果 |
| --- | --- | --- | --- |
| $(3x+2)(3x-2)$ | $3x$ | $2$ | $9x^2 - 4$ |
| $(-x+2y)(-x-2y)$ | $-x$ | $2y$ | $x^2 - 4y^2$ |
| $(-2y + x)(x + 2y)$ | $x$ | $2y$ | $x^2 - 4y^2$ |

### 例 2　简便计算

$102\times 98 = (100+2)(100-2) = 100^2 - 2^2 = 9\,996$；

$(y+2)(y-2) - (y-1)(y+5) = y^2 - 4 - (y^2 + 4y - 5) = -4y + 1$。

## 二、完全平方公式

$$
(a+b)^2 = a^2 + 2ab + b^2,\qquad (a-b)^2 = a^2 - 2ab + b^2 .
$$

> **两个数的和（或差）的平方，等于它们的平方和，加上（或减去）它们的积的 2 倍。**

口诀：**首平方，尾平方，首尾两倍放中央。**

<SquareFormulaSimulator />

### 例 3

$(4m+n)^2 = (4m)^2 + 2\cdot 4m\cdot n + n^2 = 16m^2 + 8mn + n^2$；

$\left(y - \frac12\right)^2 = y^2 - y + \frac14$。

### 例 4　简便计算

$102^2 = (100+2)^2 = 10\,000 + 400 + 4 = 10\,404$；

$99^2 = (100-1)^2 = 10\,000 - 200 + 1 = 9\,801$。

:::caution 最常见的错
$(a+b)^2 \ne a^2 + b^2$！中间的 $2ab$ 一定不能漏。从面积图看：大正方形除了 $a^2$、$b^2$，还有两块 $ab$。

另外，$(-a-b)^2 = (a+b)^2$，$(-a+b)^2 = (a-b)^2$——先把符号整理好再套公式。
:::

## 三、添括号

去括号的反过来就是添括号：

> **添括号时，如果括号前面是正号，括到括号里的各项都不变符号；如果括号前面是负号，括到括号里的各项都改变符号。**

$a + b - c = a + (b - c)$；$a - b + c = a - (b - c)$。

### 例 5　运用乘法公式计算

$(x + 2y - 3)(x - 2y + 3) = [x + (2y-3)][x - (2y-3)] = x^2 - (2y-3)^2 = x^2 - 4y^2 + 12y - 9$；

$(a + b + c)^2 = [(a+b)+c]^2 = (a+b)^2 + 2(a+b)c + c^2 = a^2 + b^2 + c^2 + 2ab + 2bc + 2ac$。

技巧：通过添括号，把「看起来是三项」的式子变成公式里的 $a$、$b$。

### 阅读与思考：杨辉三角

$(a+b)^n$ 展开后各项的系数排成三角形：

| $n$ | 系数 |
| --- | --- |
| 1 | 1　1 |
| 2 | 1　2　1 |
| 3 | 1　3　3　1 |
| 4 | 1　4　6　4　1 |
| 5 | 1　5　10　10　5　1 |

每个数等于它肩上两个数之和。南宋数学家杨辉在 1261 年的著作里记载了这张图，比欧洲早约 400 年。
