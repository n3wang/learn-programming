# 小结：分式

> 第二十二章复习。前面的课：[22.1 分式](./fractions)、[22.2 分式的运算](./fraction-operations)、[22.3 分式方程](./fractional-equations)。

## 一、知识结构

| 主题 | 内容 |
| --- | --- |
| 分式的概念 | $\frac{A}{B}$，$B$ 含字母；有意义 $B\ne 0$；值为 0：$A = 0$ 且 $B\ne 0$ |
| 基本性质 | 分子分母同乘（除以）不为 0 的整式，值不变 → 约分、通分 |
| 运算 | 乘除（先分解再约分）、乘方、加减（先通分）、混合运算 |
| 整数指数幂 | $a^{-n} = \frac{1}{a^n}$，$a^0 = 1$；科学记数法 $a\times 10^{-n}$ |
| 分式方程 | 去分母 → 整式方程 → **检验** |

## 二、类比：分数 → 分式

| 分数 | 分式 |
| --- | --- |
| $\frac34 = \frac{6}{8}$ | $\frac{a}{b} = \frac{ac}{bc}$（$c\ne 0$） |
| 约分：约去最大公约数 | 约去公因式（先分解因式） |
| 通分：最小公倍数 | 最简公分母 |
| $\frac{a}{b}\pm\frac{c}{d} = \frac{ad\pm bc}{bd}$ | 同样 |

本章反复使用**类比**（分式 ↔ 分数）和**转化**（分式方程 → 整式方程）。

## 三、本章易错点

- 约分前不分解因式：$\frac{x+2}{x+4}$ 不能「约掉 $x$」——只能约**因式**，不能约「项」。
- 分式加减时，减号后面的分子没加括号。
- 解分式方程忘记检验，或去分母时漏乘不含分母的项。
- $a^{-n}$ 不是负数：$2^{-2} = \frac14$。

## 四、复习题 22

**1.** 先化简，再求值：$\left(1 - \frac{1}{x+1}\right)\div\frac{x}{x^2-1}$，其中 $x = 3$。

<details>
<summary>答案</summary>

$\frac{x}{x+1}\cdot\frac{(x+1)(x-1)}{x} = x - 1$。当 $x = 3$ 时，原式 $= 2$。注意 $x$ 不能取 $0$、$\pm 1$。

</details>

**2.** 甲、乙两人做某种机械零件，甲每小时比乙多做 6 个，甲做 90 个零件所用的时间与乙做 60 个零件所用的时间相等。求甲、乙每小时各做多少个。

<details>
<summary>答案</summary>

设乙每小时做 $x$ 个，$\frac{90}{x+6} = \frac{60}{x}$，$90x = 60x + 360$，$x = 12$。检验后符合题意。甲每小时 18 个，乙每小时 12 个。

</details>

**3.** 关于 $x$ 的方程 $\frac{2x + a}{x - 1} = 1$ 的解是正数，求 $a$ 的取值范围。

<details>
<summary>答案</summary>

去分母：$2x + a = x - 1$，$x = -1 - a$。要求 $x > 0$ 且 $x\ne 1$：$-1 - a > 0$ 得 $a < -1$；$-1 - a\ne 1$ 得 $a\ne -2$。所以 $a < -1$ 且 $a\ne -2$。

</details>
