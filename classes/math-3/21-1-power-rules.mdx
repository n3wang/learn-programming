# 21.1 幂的运算

> **改编自：** 人教版八年级上册（五·四学制）第二十一章 21.1 节（同底数幂的乘法、幂的乘方、积的乘方、同底数幂的除法）。

整式的乘法要从「幂」开始。$a^n$ 表示 $n$ 个 $a$ 相乘，$a$ 叫底数，$n$ 叫指数。

---

## 一、同底数幂的乘法

一种电子计算机每秒可进行 $10^{15}$ 次运算，它工作 $10^3$ 秒可进行多少次运算？

$$
10^{15}\times 10^3 = \underbrace{(10\times\cdots\times 10)}_{15\text{ 个}}\times\underbrace{(10\times 10\times 10)}_{3\text{ 个}} = 10^{18} .
$$

一般地，对于任意底数 $a$ 与任意正整数 $m$、$n$：

$$
a^m \cdot a^n = \underbrace{a\cdots a}_{m}\cdot\underbrace{a\cdots a}_{n} = a^{m+n} .
$$

> **同底数幂相乘，底数不变，指数相加。**

三个以上也一样：$a^m\cdot a^n\cdot a^p = a^{m+n+p}$。

### 例 1

| 题目 | 计算 |
| --- | --- |
| $x^2\cdot x^5$ | $= x^{2+5} = x^7$ |
| $a\cdot a^6$ | $= a^{1+6} = a^7$（$a$ 的指数是 1，别漏） |
| $(-2)\times(-2)^4\times(-2)^3$ | $= (-2)^{1+4+3} = (-2)^8 = 256$ |
| $x^m\cdot x^{3m+1}$ | $= x^{m+3m+1} = x^{4m+1}$ |

:::caution 易错
$a^3 + a^3 = 2a^3$（合并同类项，指数不变），而 $a^3\cdot a^3 = a^6$（相乘，指数相加）。不要混。
:::

---

## 二、幂的乘方

$(3^2)^3 = 3^2\cdot 3^2\cdot 3^2 = 3^{2+2+2} = 3^6$。一般地：

$$
(a^m)^n = \underbrace{a^m\cdot a^m\cdots a^m}_{n\text{ 个}} = a^{mn} .
$$

> **幂的乘方，底数不变，指数相乘。**

### 例 2

$(10^3)^5 = 10^{15}$；$(a^4)^4 = a^{16}$；$(a^m)^2 = a^{2m}$；$-(x^4)^3 = -x^{12}$（负号在乘方外面，照抄）。

---

## 三、积的乘方

$(ab)^2 = (ab)(ab) = (aa)(bb) = a^2b^2$。一般地：

$$
(ab)^n = a^nb^n .
$$

> **积的乘方，等于把积的每一个因式分别乘方，再把所得的幂相乘。**

### 例 3

| 题目 | 计算 |
| --- | --- |
| $(2a)^3$ | $= 2^3a^3 = 8a^3$ |
| $(-5b)^3$ | $= (-5)^3b^3 = -125b^3$ |
| $(xy^2)^2$ | $= x^2(y^2)^2 = x^2y^4$ |
| $(-2x^3)^4$ | $= (-2)^4(x^3)^4 = 16x^{12}$ |

系数也要乘方——$(2a)^3 = 8a^3$，不是 $2a^3$。

---

## 四、同底数幂的除法

$a^m\div a^n$（$a\ne 0$，$m>n$）：因为 $a^{m-n}\cdot a^n = a^m$，所以

$$
a^m\div a^n = a^{m-n} .
$$

> **同底数幂相除，底数不变，指数相减。**

当 $m = n$ 时，$a^m\div a^m = 1$，而按法则是 $a^0$。于是规定：

$$
a^0 = 1\quad(a\ne 0) .
$$

**任何不等于 0 的数的 0 次幂都等于 1。**（$0^0$ 没有意义。）

---

## 五、四条法则对照

| 运算 | 法则 | 例子 |
| --- | --- | --- |
| 同底数幂相乘 | 指数**相加** | $a^2\cdot a^3 = a^5$ |
| 幂的乘方 | 指数**相乘** | $(a^2)^3 = a^6$ |
| 积的乘方 | 每个因式分别乘方 | $(2a^2)^3 = 8a^6$ |
| 同底数幂相除 | 指数**相减** | $a^6\div a^2 = a^4$ |

法则也可以**反过来用**：$2^{m+n} = 2^m\cdot 2^n$，$a^{6} = (a^2)^3 = (a^3)^2$，$2^{10}\times 5^{10} = (2\times 5)^{10} = 10^{10}$。

---

## 练习

答案直接打字输入，例如 `a^7`、`-x^12`、`8a^3b^6`。结果要化简成一个单项式（同一个字母只写一次）。

<G8aPractice set="21.1.1" />

**补充：** 已知 $2^m = 3$，$2^n = 5$，求 $2^{m+n}$ 和 $2^{2m}$。

<details>
<summary>答案</summary>

$2^{m+n} = 2^m\cdot 2^n = 3\times 5 = 15$；$2^{2m} = (2^m)^2 = 9$。

</details>
