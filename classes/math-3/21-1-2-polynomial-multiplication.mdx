# 21.1 整式的乘法与除法

> **改编自：** 人教版八年级上册（五·四学制）21.1 节（整式的乘法、整式的除法）。上一课是 [21.1 幂的运算](./power-rules)。

有了幂的运算法则，就可以做整式的乘法：先是单项式乘单项式，再到单项式乘多项式、多项式乘多项式，最后是除法。

---

## 一、单项式乘单项式

光的速度约为 $3\times 10^5\ \text{km/s}$，太阳光照射到地球约需 $5\times 10^2\ \text{s}$，地球与太阳的距离约为

$$
(3\times 10^5)\times(5\times 10^2) = (3\times 5)\times(10^5\times 10^2) = 15\times 10^7 = 1.5\times 10^8\ (\text{km}) .
$$

把 $10$ 换成字母：$ac^5\cdot bc^2 = (a\cdot b)\cdot(c^5\cdot c^2) = abc^7$。

> **单项式与单项式相乘，把它们的系数、同底数幂分别相乘，对于只在一个单项式里含有的字母，则连同它的指数作为积的一个因式。**

### 例 4

$(-5a^2b)(-3a) = [(-5)\times(-3)](a^2\cdot a)b = 15a^3b$；

$(2x)^3(-5xy^2) = 8x^3\cdot(-5xy^2) = -40x^4y^2$（先算乘方）。

---

## 二、单项式乘多项式

一块长方形，宽 $m$、长 $a + b + c$，可以看成三块小长方形拼成：面积 $m(a+b+c) = ma + mb + mc$。

$m(a+b+c) = ma + mb + mc$——这就是乘法分配律。

> **单项式与多项式相乘，就是用单项式去乘多项式的每一项，再把所得的积相加。**

### 例 5

$(-4x^2)(3x+1) = (-4x^2)(3x) + (-4x^2)(1) = -12x^3 - 4x^2$；

$\left(\frac23 ab^2 - 2ab\right)\cdot\frac12 ab = \frac13 a^2b^3 - a^2b^2$。

**注意：** 每一项都要乘到，不要漏项；单项式带负号时，多项式的**每一项**都要变号。

---

## 三、多项式乘多项式

一块长方形菜地，长 $a\ \text{m}$、宽 $m\ \text{m}$，长和宽分别增加 $b\ \text{m}$、$n\ \text{m}$。扩大后的面积可以整体算 $(a+b)(m+n)$，也可以分四块算 $am + an + bm + bn$，所以

$$
(a+b)(m+n) = am + an + bm + bn .
$$

> **多项式与多项式相乘，先用一个多项式的每一项乘另一个多项式的每一项，再把所得的积相加。**

### 例 6

$(3x+1)(x+2) = 3x^2 + 6x + x + 2 = 3x^2 + 7x + 2$；

$(x-8y)(x-y) = x^2 - xy - 8xy + 8y^2 = x^2 - 9xy + 8y^2$；

$(x+y)(x^2-xy+y^2) = x^3 - x^2y + xy^2 + x^2y - xy^2 + y^3 = x^3 + y^3$。

两项乘两项会得到 **4** 个积，然后**合并同类项**。

---

## 四、整式的除法

### 单项式除以单项式

$12a^3b^2x^3\div 3ab^2 = 4a^2x^3$，因为 $4a^2x^3\cdot 3ab^2 = 12a^3b^2x^3$。

> **单项式相除，把系数与同底数幂分别相除作为商的因式，对于只在被除式里含有的字母，则连同它的指数作为商的一个因式。**

### 例 7

$28x^4y^2\div 7x^3y = 4xy$；$-5a^5b^3c\div 15a^4b = -\frac13 ab^2c$。

### 多项式除以单项式

> **多项式除以单项式，先把这个多项式的每一项分别除以单项式，再把所得的商相加。**

### 例 8

$(12a^3 - 6a^2 + 3a)\div 3a = 4a^2 - 2a + 1$（最后一项 $3a\div 3a = 1$，不能丢）；

$(21x^4y^3 - 35x^3y^2 + 7x^2y^2)\div(-7x^2y) = -3x^2y^2 + 5xy - y$。

---

## 练习

结果要去括号、合并同类项，写成多项式，例如 `3x^2+7x+2`、`-12x^3-4x^2`。

<G8aPractice set="21.1.2" />

**补充：** 先化简，再求值：$x(x-2) - (x+1)(x-1)$，其中 $x = \frac12$。

<details>
<summary>答案</summary>

原式 $= x^2 - 2x - (x^2 - 1) = -2x + 1$。当 $x = \frac12$ 时，原式 $= 0$。

</details>
