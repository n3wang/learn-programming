# 小结：轴对称

> 第二十章复习。前面的课：[20.1](./axial-symmetry)、[20.2](./drawing-symmetric-figures)、[20.3.1](./isosceles-triangle)、[20.3.2](./equilateral-triangle)、[20.4](./shortest-path)。

## 一、知识结构

| 主题 | 内容 |
| --- | --- |
| 轴对称 | 轴对称图形；两个图形成轴对称；对称轴垂直平分对应点的连线 |
| 垂直平分线 | 性质：线上的点到两端距离相等；判定：反过来也成立；尺规作图 |
| 画轴对称图形 | 先画特殊点的对称点；$(x,y)$ 关于 $x$ 轴 → $(x,-y)$，关于 $y$ 轴 → $(-x,y)$ |
| 等腰三角形 | 等边对等角；三线合一；等角对等边 |
| 等边三角形 | 三个角都是 60°；有一个角是 60° 的等腰三角形是等边三角形 |
| 30° 直角三角形 | 30° 角所对的直角边等于斜边的一半 |
| 最短路径 | 轴对称把同侧化异侧；平移去掉固定长度 |

## 二、回顾与思考

1. **轴对称和全等有什么关系？** 成轴对称的两个图形一定全等；全等的两个图形不一定成轴对称。
2. **研究等腰三角形用了什么方法？** 先折纸观察（轴对称），再用全等三角形证明。图形的变化（轴对称、平移）是研究几何的重要工具。
3. **「等边对等角」和「等角对等边」** 是互逆的两个命题，前者是性质，后者是判定。它们只在**同一个三角形**里成立。

## 三、本章易错点

- 角的对称轴是角平分线**所在的直线**，不是角平分线。
- 等腰三角形已知一个角或一条边时，要分「顶角 / 底角」「腰 / 底」讨论，并用三角形三边关系检验。
- 「30° 角所对的直角边等于斜边的一半」只在**直角三角形**里成立，而且是 **30° 角所对**的那条直角边。
- 关于 $x$ 轴对称，是**纵**坐标变号。

## 四、复习题 20

**1.** 如图，$AD$ 是 △ABC 的角平分线，$DE \perp AB$，$DF \perp AC$，垂足分别为 $E$、$F$。连接 $EF$，$EF$ 与 $AD$ 交于 $G$。$AD$ 与 $EF$ 垂直吗？

<details>
<summary>答案</summary>

角平分线上的点到角两边距离相等，$DE = DF$；Rt△ADE ≌ Rt△ADF（HL），$AE = AF$。于是 $A$、$D$ 都到 $E$、$F$ 距离相等，都在 $EF$ 的垂直平分线上，所以 $AD$ 垂直平分 $EF$，$AD \perp EF$。

</details>

**2.** 等腰三角形一腰上的高与另一腰的夹角为 $30^\circ$，求顶角的度数。

<details>
<summary>答案</summary>

分两种情况。顶角是锐角时，高在三角形内，顶角 $= 90^\circ - 30^\circ = 60^\circ$；顶角是钝角时，高在三角形外，顶角的邻补角 $= 60^\circ$，顶角 $= 120^\circ$。答案：$60^\circ$ 或 $120^\circ$。

</details>

**3.** △ABC 中，$AB = AC$，$\angle BAC = 120^\circ$，$AD \perp AC$ 交 $BC$ 于 $D$。求证 $BC = 3BD$。

<details>
<summary>答案</summary>

$\angle B = \angle C = 30^\circ$。Rt△ADC 中 $\angle C = 30^\circ$，$CD = 2AD$。$\angle BAD = 120^\circ - 90^\circ = 30^\circ = \angle B$，所以 $BD = AD$。于是 $BC = BD + CD = AD + 2AD = 3AD = 3BD$。

</details>
