# 20.1 轴对称

> **改编自：** 人教版《义务教育教科书·数学》八年级上册（五·四学制）第二十章 20.1 节。

窗花、蝴蝶、天安门、汉字「中」……生活里到处都是对称。把一张纸对折，剪一个图案再打开，折痕两边的图案完全一样——这就是这一节要研究的**轴对称**。

---

## 20.1.1 轴对称

### 轴对称图形

如果一个平面图形沿一条直线折叠，直线两旁的部分能够互相重合，这个图形就叫做**轴对称图形**，这条直线就是它的**对称轴**。这时也说这个图形关于这条直线（成轴）对称。

| 图形 | 是不是轴对称图形 | 对称轴条数 |
| --- | --- | --- |
| 线段 | 是 | 2（垂直平分线、它所在的直线） |
| 角 | 是 | 1（角平分线所在的直线） |
| 等腰三角形 | 是 | 1 |
| 等边三角形 | 是 | 3 |
| 长方形 | 是 | 2 |
| 正方形 | 是 | 4 |
| 圆 | 是 | 无数条（过圆心的每一条直线） |
| 平行四边形（一般的） | 不是 | 0 |

:::caution 对称轴是直线
角的对称轴是「角平分线**所在的直线**」，不是角平分线本身——角平分线是射线，而对称轴是直线。
:::

### 两个图形成轴对称

把一个图形沿着某一条直线折叠，如果它能够与**另一个**图形重合，就说这两个图形关于这条直线（成轴）对称，这条直线叫做对称轴，折叠后重合的点是对应点，叫做**对称点**。

| | 轴对称图形 | 两个图形成轴对称 |
| --- | --- | --- |
| 说的是 | **一个**图形自己 | **两个**图形之间的位置关系 |
| 对称点 | 在同一个图形上 | 分别在两个图形上 |
| 联系 | 把成轴对称的两个图形看成一个整体，就是一个轴对称图形；把一个轴对称图形沿对称轴分开，得到的两部分成轴对称 | |

成轴对称的两个图形**全等**。但反过来不成立：两个全等的三角形不一定关于某条直线对称（例如把一个三角形平移得到的另一个）。

沿 MN 折叠，点 A 与 A′ 重合，所以 $AP = PA'$，$\angle MPA = \angle MPA' = 90^\circ$。其他对应点也一样。

经过线段中点并且垂直于这条线段的直线，叫做这条线段的**垂直平分线**（也叫中垂线）。于是得到**轴对称的性质**：

> 如果两个图形关于某条直线对称，那么对称轴是任何一对对应点所连线段的垂直平分线。
> 类似地，轴对称图形的对称轴，是任何一对对应点所连线段的垂直平分线。

## 20.1.2 线段的垂直平分线的性质

直线 $l$ 垂直平分线段 $AB$，在 $l$ 上任取几个点 $P_1, P_2, P_3, \ldots$，量一量它们到 $A$、$B$ 的距离——总是相等。沿 $l$ 对折，$P_1A$ 与 $P_1B$ 重合，当然相等。

<PerpBisectorSimulator />

**性质：** 线段垂直平分线上的点与这条线段两个端点的距离相等。

用全等三角形也能证明。如下图，$l \perp AB$，垂足为 $C$，$AC = CB$，点 $P$ 在 $l$ 上：

<GeoFig
  width={240}
  points={{ A: [-2, 0], B: [2, 0], C: [0, 0], P: [0, 2.6] }}
  segments={['AB', { s: 'PA', color: '#2a9d8f' }, { s: 'PB', color: '#4a90d9' }]}
  lines={[{ through: ['C', 'P'], label: 'l', color: '#e0245e', dash: true }]}
  right={['A C P']}
  ticks={[['A C', 1], ['C B', 1]]}
  labelPos={{ C: 's', P: 'ne' }}
/>

$$
\left.\begin{aligned}
&AC = BC \\
&\angle PCA = \angle PCB = 90^\circ \\
&PC = PC
\end{aligned}\right\}
\Rightarrow \triangle PCA \cong \triangle PCB\ (\text{SAS}) \Rightarrow PA = PB
$$

反过来也成立（判定）：**与线段两个端点距离相等的点在这条线段的垂直平分线上。**

所以线段 $AB$ 的垂直平分线可以看成：**与 $A$、$B$ 两点距离相等的所有点的集合**。

### 例：垂直平分线与周长

在 △ABC 中，DE 是 AC 的垂直平分线，D 在 BC 上。因为 $DA = DC$，所以

$$
\triangle ABD\text{ 的周长} = AB + BD + DA = AB + BD + DC = AB + BC .
$$

「把一条线段换成和它相等的另一条」是这类题的关键。

## 尺规作图

### 作线段的垂直平分线

如果两个图形成轴对称，对称轴就是任何一对对应点所连线段的垂直平分线。所以只要会作垂直平分线，就能找到对称轴，也能找到线段的中点。

1. 分别以点 $A$ 和点 $B$ 为圆心，**大于 $\frac12 AB$** 的长为半径作弧，两弧相交于 $C$、$D$ 两点；
2. 作直线 $CD$。$CD$ 就是线段 $AB$ 的垂直平分线。

为什么？$CA = CB$，$DA = DB$，所以 $C$、$D$ 都在 $AB$ 的垂直平分线上；两点确定一条直线。半径要大于 $\frac12 AB$，否则两弧不相交。

### 例 1　过直线外一点作已知直线的垂线

已知直线 $AB$ 和 $AB$ 外一点 $C$。

1. 任意取一点 $K$，使 $K$ 和 $C$ 在 $AB$ 的两旁；
2. 以 $C$ 为圆心、$CK$ 长为半径作弧，交 $AB$ 于 $D$、$E$；
3. 分别以 $D$、$E$ 为圆心，大于 $\frac12 DE$ 的长为半径作弧，两弧交于 $F$；
4. 作直线 $CF$，它就是所求的垂线。

想一想：$CD = CE$，$FD = FE$，所以 $C$、$F$ 都在 $DE$ 的垂直平分线上——直线 $CF$ 垂直于 $DE$，也就是垂直于 $AB$。

## 练习

**1.** 公路 $l$ 边上有两个新小区 $A$、$B$，要在公路上建一个公交车站，使两个小区到车站的距离一样长。车站应建在哪里？

<details>
<summary>答案</summary>

连接 $AB$，作 $AB$ 的垂直平分线，与公路 $l$ 的交点就是车站的位置（垂直平分线上的点到 $A$、$B$ 距离相等）。

</details>

**2.** 在 △ABC 中，边 $AB$、$BC$ 的垂直平分线相交于点 $P$。求证 $PA = PB = PC$，并说明 $P$ 也在 $AC$ 的垂直平分线上。

<details>
<summary>答案</summary>

$P$ 在 $AB$ 的垂直平分线上，所以 $PA = PB$；$P$ 在 $BC$ 的垂直平分线上，所以 $PB = PC$。于是 $PA = PC$，由判定定理，$P$ 在 $AC$ 的垂直平分线上。结论：三角形三边的垂直平分线交于一点，这个点到三个顶点的距离相等。

</details>

**3.** 发射塔要建在 $S$ 区，到两个城镇 $A$、$B$ 的距离相等，到两条公路 $m$、$n$ 的距离也相等。塔应建在哪里？

<details>
<summary>答案</summary>

到 $A$、$B$ 距离相等 → 在线段 $AB$ 的垂直平分线上；到两条相交直线距离相等 → 在它们夹角的平分线上。两条线在 $S$ 区内的交点就是塔的位置。

</details>

## 小结

| 概念 | 要点 |
| --- | --- |
| 轴对称图形 | 一个图形，沿对称轴折叠两旁重合 |
| 成轴对称 | 两个图形，折叠后互相重合；它们全等 |
| 轴对称的性质 | 对称轴垂直平分对应点的连线 |
| 垂直平分线的性质 | 线上的点到线段两端距离相等 |
| 垂直平分线的判定 | 到线段两端距离相等的点在垂直平分线上 |
| 尺规作图 | 半径大于一半，两弧交两点，连成直线 |
