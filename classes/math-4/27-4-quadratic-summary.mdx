# 小结：一元二次方程

> 第二十七章复习。前面的课：[27.1](./quadratic-equations)、[配方法](./completing-the-square)、[公式法](./quadratic-formula)、[因式分解法](./factoring-method)、[根与系数](./vieta)、[实际问题](./quadratic-word-problems)。

## 一、知识结构

| 主题 | 内容 |
| --- | --- |
| 概念 | 一元、二次、整式方程；一般形式 $ax^2 + bx + c = 0\ (a\ne 0)$ |
| 解法 | 直接开平方、配方法、公式法、因式分解法——核心都是**降次** |
| 判别式 | $\Delta = b^2 - 4ac$：$>0$ 两个不等实根，$=0$ 两个相等实根，$<0$ 无实根 |
| 求根公式 | $x = \dfrac{-b\pm\sqrt{b^2-4ac}}{2a}\ (\Delta\ge 0)$ |
| 根与系数 | $x_1 + x_2 = -\frac ba$，$x_1x_2 = \frac ca$ |
| 应用 | 传播 / 比赛、增长率、面积；检验根是否符合实际 |

## 二、回顾与思考

1. **转化与降次**：二次方程 → 两个一次方程。配方法通过「完全平方」降次，因式分解法通过「积为 0」降次。
2. 公式法是配方法的「一般化」：对字母系数配方，一次得到所有方程的解。
3. 判别式与根与系数的关系让我们**不解方程**也能知道根的情况、根的和与积。

## 三、易错点

| 错误 | 正确 |
| --- | --- |
| $x^2 = 3x$ 两边除以 $x$，得 $x = 3$ | 移项分解：$x_1 = 0,\ x_2 = 3$ |
| 配方时只在左边加 $\left(\frac b2\right)^2$ | 两边都要加 |
| $2x^2 - 4x = 1$ 直接加 $4$ 配方 | 先把二次项系数化为 1 |
| 求 $b$ 时忘了符号 | 先化一般形式，系数带符号 |
| 关于 $x$ 的方程 $(k-1)x^2 + 2x + 1 = 0$ 有两个实根，只算 $\Delta\ge 0$ | 还要 $k - 1\ne 0$ |

## 四、复习题 27

**1.** 关于 $x$ 的方程 $kx^2 - 2x - 1 = 0$ 有两个不相等的实数根，求 $k$ 的取值范围。

<details>
<summary>答案</summary>

$k\ne 0$ 且 $\Delta = 4 + 4k > 0$，所以 $k > -1$ 且 $k\ne 0$。

</details>

**2.** 某超市 1 月份营业额为 200 万元，3 月份为 288 万元。求 2、3 月份营业额的月平均增长率。

<details>
<summary>答案</summary>

$200(1+x)^2 = 288$，$(1+x)^2 = 1.44$，$x = 0.2$（$x = -2.2$ 舍去），月平均增长率 20%。

</details>

**3.** 一个两位数，十位数字比个位数字小 3，个位数字的平方恰好等于这个两位数。求这个两位数。

<details>
<summary>答案</summary>

设个位数字为 $x$，十位为 $x - 3$：$x^2 = 10(x-3) + x$，$x^2 - 11x + 30 = 0$，$x = 5$ 或 $6$。两位数是 25 或 36（$5^2 = 25$，$6^2 = 36$）。

</details>
