# 25.1 平行四边形的性质

> **改编自：** 人教版八年级下册（五·四学制）第二十五章 25.1.1。

**两组对边分别平行的四边形叫做平行四边形。** 平行四边形 ABCD 记作「▱ABCD」，读作「平行四边形 ABCD」。

## 一、边与角

> **性质 1**　平行四边形的**对边相等**。
> **性质 2**　平行四边形的**对角相等**。

**证明：** 连接 $AC$。$AB\parallel CD$，$AD\parallel BC$，所以 $\angle 1 = \angle 2$，$\angle 3 = \angle 4$（内错角）；又 $AC = CA$，所以 $\triangle ABC \cong \triangle CDA$（ASA）。于是 $AB = CD$，$CB = AD$，$\angle B = \angle D$；同理 $\angle BAD = \angle BCD$。

由平行线还可以知道：平行四边形的**邻角互补**（$\angle A + \angle B = 180^\circ$）。

### 例 1

在 ▱ABCD 中，$DE \perp AB$，$BF \perp CD$，垂足分别为 $E$、$F$。求证 $AE = CF$。

<GeoFig width={260} points={{ A: [0, 0], B: [4, 0], C: [5.2, 2.2], D: [1.2, 2.2], E: [1.2, 0], F: [4, 2.2] }} segments={['AB', 'BC', 'CD', 'DA', { s: 'D E', dash: true }, { s: 'B F', dash: true }]} right={['A E D', 'C F B']} labelPos={{ A: 'sw', B: 'se', C: 'ne', D: 'nw', E: 's', F: 'n' }} />

**证明：** 四边形 ABCD 是平行四边形，$\angle A = \angle C$，$AD = CB$。又 $\angle AED = \angle CFB = 90^\circ$，所以 $\triangle ADE \cong \triangle CBF$（AAS），$AE = CF$。

### 平行线之间的距离

如果两条直线平行，那么一条直线上**所有的点**到另一条直线的距离都相等，这个距离叫做这两条**平行线之间的距离**。所以夹在两条平行线之间的平行线段相等，夹在两条平行线之间的**垂线段**也相等——平行四边形的高处处相等。

## 二、对角线

> **性质 3**　平行四边形的**对角线互相平分**。

**证明：** ▱ABCD 的对角线 $AC$、$BD$ 交于 $O$。$AB = CD$，$AB\parallel CD$，所以 $\angle ABO = \angle CDO$，$\angle BAO = \angle DCO$，$\triangle ABO \cong \triangle CDO$（ASA），$OA = OC$，$OB = OD$。

### 例 2

在 ▱ABCD 中，$AB = 10$，$AD = 8$，$AC \perp BC$。求 $BC$、$CD$、$AC$、$OA$ 的长和 ▱ABCD 的面积。

<GeoFig width={240} points={{ A: [1.2, 2.2], B: [0, 0], C: [1.2, 0], D: [2.4, 2.2], O: [1.2, 1.1] }} segments={['AB', 'BC', 'CD', 'DA', { s: 'A C', color: '#e0245e' }, { s: 'B D', dash: true }]} right={['A C B']} labelPos={{ O: 'e', C: 's' }} />

$BC = AD = 8$，$CD = AB = 10$；$AC = \sqrt{10^2 - 8^2} = 6$；$OA = \frac12 AC = 3$；$S = BC\cdot AC = 8\times 6 = 48$。
