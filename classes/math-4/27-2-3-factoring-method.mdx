# 27.2 因式分解法

> **改编自：** 人教版八年级下册（五·四学制）27.2.3。上一课是 [27.2 公式法](./quadratic-formula)。

根据物理学规律，以 10 m/s 的速度竖直上抛一个物体，$x$ s 后它离地面的高度约为 $10x - 4.9x^2$ m。物体经过多少秒落回地面？

$10x - 4.9x^2 = 0$ 的左边可以**因式分解**：$x(10 - 4.9x) = 0$。

**两个因式的积等于 0，那么至少有一个因式等于 0**：$x = 0$ 或 $10 - 4.9x = 0$，所以 $x_1 = 0$，$x_2 = \frac{100}{49} \approx 2.04$。物体约 2.04 s 后落回地面（$x = 0$ 是抛出的时刻）。

> 先因式分解，使方程化为两个一次式的乘积等于 0 的形式，再使这两个一次式分别等于 0，从而实现降次。这种解法叫做**因式分解法**。

---

## 例 3

**(1)** $x(x-2) + x - 2 = 0$

提公因式 $(x-2)$：$(x-2)(x+1) = 0$，$x_1 = 2$，$x_2 = -1$。

**(2)** $5x^2 - 2x - \frac14 = x^2 - 2x + \frac34$

移项、合并：$4x^2 - 1 = 0$；平方差：$(2x+1)(2x-1) = 0$，$x_1 = -\frac12$，$x_2 = \frac12$。

**(3)** $x^2 - 5x + 6 = 0$

找两个数，积为 6、和为 −5：$-2$、$-3$。$(x-2)(x-3) = 0$，$x_1 = 2$，$x_2 = 3$。

:::caution 不能两边同除以含未知数的式子
$x^2 = 3x$ 两边除以 $x$ 得 $x = 3$，**丢了根** $x = 0$。应移项：$x^2 - 3x = 0$，$x(x - 3) = 0$，$x_1 = 0$，$x_2 = 3$。
:::

---

## 三种解法的比较

| 方法 | 适用 | 特点 |
| --- | --- | --- |
| 直接开平方法 | $(x+n)^2 = p$ 型 | 最快 |
| 配方法 | 所有方程 | 一次项系数是偶数时方便；是推导公式的基础 |
| 公式法 | 所有方程 | 万能，先算 $\Delta$ |
| 因式分解法 | 能分解的方程 | 简便，适合右边为 0、左边易分解 |

选择顺序建议：能直接开平方 → 能因式分解 → 公式法。
