# 27.2 配方法

> **改编自：** 人教版八年级下册（五·四学制）27.2.1。上一课是 [27.1 一元二次方程](./quadratic-equations)。

解一元二次方程的基本思路：**降次**——把二次方程化成两个一次方程。

---

## 一、直接开平方法

一桶油漆可刷的面积为 1 500 dm²，李林用这桶油漆恰好刷完 10 个同样的正方体形状的盒子的全部外表面。盒子的棱长是多少？

设棱长为 $x$ dm：$10\times 6x^2 = 1500$，$x^2 = 25$，$x = \pm 5$。棱长不能为负，所以 $x = 5$。

> 如果方程能化成 $x^2 = p$ 或 $(mx + n)^2 = p\ (p \ge 0)$ 的形式，那么 $x = \pm\sqrt p$ 或 $mx + n = \pm\sqrt p$。

| $p$ | 根 |
| --- | --- |
| $p > 0$ | 两个不等的实数根 $\pm\sqrt p$ |
| $p = 0$ | 两个相等的实数根 $x_1 = x_2 = 0$ |
| $p < 0$ | 没有实数根（负数没有平方根） |

例：$(x+3)^2 = 5$，$x + 3 = \pm\sqrt5$，$x_1 = -3 + \sqrt5$，$x_2 = -3 - \sqrt5$。

## 二、配方法

$x^2 + 6x + 4 = 0$ 不能直接开平方。但 $x^2 + 6x + 9 = (x+3)^2$，于是

$$
x^2 + 6x = -4 \ \Rightarrow\ x^2 + 6x + 9 = -4 + 9 \ \Rightarrow\ (x+3)^2 = 5 .
$$

<CompleteSquareSimulator />

> 通过配成完全平方形式来解一元二次方程的方法，叫做**配方法**。配方的关键：方程两边都加上**一次项系数一半的平方**：
> $$x^2 + px + \left(\frac p2\right)^2 = \left(x + \frac p2\right)^2 .$$

### 例 1

**(1)** $x^2 - 8x + 1 = 0$

移项 $x^2 - 8x = -1$；配方 $x^2 - 8x + 4^2 = -1 + 16$，$(x-4)^2 = 15$；$x - 4 = \pm\sqrt{15}$，$x_1 = 4 + \sqrt{15}$，$x_2 = 4 - \sqrt{15}$。

**(2)** $2x^2 + 1 = 3x$

化成 $2x^2 - 3x + 1 = 0$，**两边除以 2**（二次项系数化为 1）：$x^2 - \frac32 x = -\frac12$；配方 $x^2 - \frac32 x + \left(\frac34\right)^2 = -\frac12 + \frac{9}{16}$，$\left(x - \frac34\right)^2 = \frac1{16}$；$x_1 = 1$，$x_2 = \frac12$。

**(3)** $3x^2 - 6x + 4 = 0$

除以 3：$x^2 - 2x = -\frac43$；配方 $(x-1)^2 = -\frac13 < 0$，**原方程无实数根**。

### 步骤

1. 化二次项系数为 1；
2. 移项，常数项移到右边；
3. 两边加上一次项系数一半的平方；
4. 化成 $(x + n)^2 = p$；
5. $p \ge 0$ 时开平方求解，$p < 0$ 时无实数根。
