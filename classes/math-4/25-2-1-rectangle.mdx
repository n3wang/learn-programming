# 25.2 矩形

> **改编自：** 人教版八年级下册（五·四学制）25.2.1。上一课是 [25.1 平行四边形的判定](./parallelogram-criteria)。

平行四边形木框，改变一个角：当这个角变成直角时，平行四边形就变成了长方形。**有一个角是直角的平行四边形叫做矩形**，也就是长方形。

矩形是特殊的平行四边形，它具有平行四边形的所有性质，还有自己特殊的性质。在 [平行四边形互动图](./parallelogram-properties) 里点「变矩形」，再看看对角线。

---

## 一、矩形的性质

> **性质 1**　矩形的四个角都是**直角**。
> **性质 2**　矩形的对角线**相等**。

**证明性质 2：** 在矩形 ABCD 中，$AB = DC$，$\angle ABC = \angle DCB = 90^\circ$，$BC = CB$，所以 $\triangle ABC \cong \triangle DCB$（SAS），$AC = DB$。

矩形是轴对称图形，有两条对称轴（对边中点连线所在的直线）。

### 直角三角形斜边上的中线

矩形 ABCD 的对角线交于 O，则 $OA = OB = OC = OD$。在 Rt△ABC 中，$BO$ 是斜边 $AC$ 上的中线，于是：

> **直角三角形斜边上的中线等于斜边的一半。**

### 例 1

矩形 ABCD 的对角线 AC、BD 相交于点 O，$\angle AOB = 60^\circ$，$AB = 4$。求对角线的长。

<GeoFig width={240} points={{ A: [0, 2], B: [0, 0], C: [3.46, 0], D: [3.46, 2], O: [1.73, 1] }} segments={['AB', 'BC', 'CD', 'DA', { s: 'A C', dash: true }, { s: 'B D', dash: true }, { s: 'O A', color: '#e0245e' }, { s: 'O B', color: '#e0245e' }]} arcs={[{ at: 'O', from: 'A', to: 'B', label: '60°' }]} labelPos={{ A: 'nw', B: 'sw', C: 'se', D: 'ne', O: 'e' }} />

$AC$、$BD$ 相等且互相平分，$OA = OB$；又 $\angle AOB = 60^\circ$，所以 △OAB 是等边三角形，$OA = AB = 4$，$AC = BD = 8$。

## 二、矩形的判定

| 判定 | |
| --- | --- |
| 有一个角是直角的**平行四边形** | 定义 |
| 对角线相等的**平行四边形** | 性质 2 的逆命题 |
| 有三个角是直角的**四边形** | 第四个角也必定是直角 |

### 例 2

在 ▱ABCD 中，对角线 AC、BD 相交于 O，$OA = OD$，$\angle OAD = 50^\circ$。求 $\angle OAB$。

$OA = OC = \frac12 AC$，$OB = OD = \frac12 BD$，又 $OA = OD$，所以 $AC = BD$，▱ABCD 是矩形，$\angle DAB = 90^\circ$，$\angle OAB = 90^\circ - 50^\circ = 40^\circ$。

:::caution 前提
「对角线相等的四边形是矩形」是**错**的——必须先是平行四边形（对角线互相平分）。等腰梯形的对角线也相等。
:::
