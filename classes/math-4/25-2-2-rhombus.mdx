# 25.2 菱形

> **改编自：** 人教版八年级下册（五·四学制）25.2.2。上一课是 [25.2 矩形](./rectangle)。

**有一组邻边相等的平行四边形叫做菱形。** 菱形的四条边都相等。

---

## 一、菱形的性质

> **性质 1**　菱形的四条边都**相等**。
> **性质 2**　菱形的两条对角线**互相垂直**，并且每一条对角线**平分一组对角**。

**证明性质 2：** 菱形 ABCD 中 $AB = AD$，$O$ 是 $BD$ 的中点，所以 $AO$ 是等腰 △ABD 底边上的中线，由三线合一，$AO \perp BD$，$AO$ 平分 $\angle BAD$。

菱形是轴对称图形，两条对角线所在的直线都是它的对称轴。

### 菱形的面积

对角线把菱形分成四个全等的直角三角形：

$$
S_{\text{菱形}} = \frac12 \times AC \times BD \qquad(\text{对角线乘积的一半}) .
$$

当然也可以用「底 × 高」。

### 例 3　菱形花坛

菱形花坛 ABCD 的边长为 20 m，$\angle ABC = 60^\circ$，沿两条对角线修建了小路 AC 和 BD。求两条小路的长和花坛的面积。

<GeoFig width={240} points={{ A: [0, 1], B: [-1.73, 0], C: [0, -1], D: [1.73, 0], O: [0, 0] }} segments={['AB', 'BC', 'CD', 'DA', { s: 'A C', dash: true }, { s: 'B D', dash: true }]} right={['A O D']} labelPos={{ O: 'se' }} />

$AC \perp BD$，$\angle ABO = \frac12\angle ABC = 30^\circ$。Rt△OAB 中 $AO = \frac12 AB = 10$，$BO = \sqrt{20^2 - 10^2} = 10\sqrt3$。

$AC = 20$ m，$BD = 20\sqrt3 \approx 34.64$ m，$S = \frac12\times 20\times 20\sqrt3 = 200\sqrt3 \approx 346.4\ \text{m}^2$。

## 二、菱形的判定

| 判定 | |
| --- | --- |
| 有一组邻边相等的**平行四边形** | 定义 |
| 对角线互相垂直的**平行四边形** | 性质 2 的逆命题 |
| 四条边相等的**四边形** | |

### 例 4

▱ABCD 的对角线 AC、BD 相交于点 O，$AB = 5$，$AO = 4$，$BO = 3$。求证 ▱ABCD 是菱形。

$AB^2 = 25 = AO^2 + BO^2$，由勾股定理的逆定理，$\angle AOB = 90^\circ$，$AC \perp BD$，所以 ▱ABCD 是菱形。
