# 24.1 勾股定理

> **改编自：** 人教版《义务教育教科书·数学》八年级下册（五·四学制）第二十四章 24.1 节。

我国古代把直角三角形中短的直角边叫做**勾**，长的直角边叫做**股**，斜边叫做**弦**。《周髀算经》记载，约公元前 11 世纪人们就知道「勾三、股四、弦五」。2002 年北京国际数学家大会的会徽，就是由我国古代数学家赵爽的**弦图**设计的。

---

## 一、勾股定理

观察方格纸上的等腰直角三角形：以两条直角边为边的两个小正方形，面积和正好等于以斜边为边的大正方形面积。一般的直角三角形也是这样吗？

<PythagorasSimulator />

> **勾股定理**　如果直角三角形的两条直角边长分别为 $a$、$b$，斜边长为 $c$，那么
> $$a^2 + b^2 = c^2 .$$

### 证明（赵爽弦图的思路）

把四个全等的直角三角形（直角边 $a$、$b$，斜边 $c$）拼成边长为 $a + b$ 的大正方形，中间空出一个边长为 $c$ 的正方形。大正方形的面积算两次：

$$
(a+b)^2 = 4\times\frac12 ab + c^2 \ \Longrightarrow\ a^2 + 2ab + b^2 = 2ab + c^2 \ \Longrightarrow\ a^2 + b^2 = c^2 .
$$

赵爽的拼法是另一种：四个三角形围在边长为 $c$ 的正方形里，中间空出边长为 $b - a$ 的小正方形：$c^2 = 4\times\frac12 ab + (b-a)^2 = a^2 + b^2$。

:::tip 变形
$c = \sqrt{a^2 + b^2}$，$a = \sqrt{c^2 - b^2}$，$b = \sqrt{c^2 - a^2}$。求**斜边**用加，求**直角边**用减。先弄清楚哪条是斜边（直角所对的边）！
:::

## 二、勾股定理的应用

### 例 1　木板能否通过门框

一个门框宽 1 m、高 2 m，一块长 3 m、宽 2.2 m 的长方形薄木板能否从门框内通过？

<GeoFig width={150} points={{ A: [0, 2], B: [0, 0], C: [1, 0], D: [1, 2] }} segments={['AB', 'BC', 'CD', 'DA', { s: 'A C', dash: true, color: '#e0245e' }]} />

木板横着、竖着都过不去，只能斜着试。门框对角线 $AC$ 是斜着能通过的最大长度：

$$
AC^2 = AB^2 + BC^2 = 2^2 + 1^2 = 5,\qquad AC = \sqrt5 \approx 2.24 .
$$

$2.24 > 2.2$，所以木板**能**通过。

### 例 2　梯子下滑

一架 2.6 m 长的梯子 $AB$ 斜靠在竖直的墙 $AO$ 上，$AO = 2.4$ m。如果梯子顶端 $A$ 沿墙下滑 0.5 m，底端 $B$ 也外移 0.5 m 吗？

<GeoFig width={220} points={{ A: [0, 2.4], O: [0, 0], B: [1, 0], C: [0, 1.9], D: [1.77, 0] }} segments={['A O', 'O D', { s: 'A B', color: '#4a90d9' }, { s: 'C D', color: '#e0245e', dash: true }]} right={['A O B']} labelPos={{ O: 'sw' }} />

$$
OB = \sqrt{2.6^2 - 2.4^2} = \sqrt{1} = 1 ,\qquad OD = \sqrt{2.6^2 - 1.9^2} = \sqrt{3.15} \approx 1.77 ,
$$

$BD = OD - OB \approx 0.77$ m。底端外移约 0.77 m，**不是** 0.5 m。

### 在数轴上画出表示 $\sqrt{13}$ 的点

$13 = 2^2 + 3^2$。在数轴上取 $OA = 3$，过 $A$ 作垂线 $AB = 2$，则 $OB = \sqrt{13}$；以 $O$ 为圆心、$OB$ 为半径画弧，交数轴正半轴于点 $C$，点 $C$ 就表示 $\sqrt{13}$。

<GeoFig width={300} points={{ O: [0, 0], A: [3, 0], B: [3, 2], C: [3.606, 0], E: [4.5, 0], F: [-0.5, 0] }} hide={['E', 'F']} segments={['F E', { s: 'O B', color: '#e0245e' }, 'A B']} right={['O A B']} labelPos={{ O: 's', A: 's', C: 'se' }} caption="OB = √(3² + 2²) = √13，再画弧到数轴上" />

用同样的方法，「把 $n$ 写成两个平方数的和」，就能在数轴上画出 $\sqrt2$、$\sqrt5$、$\sqrt{10}$……利用勾股定理可以画出长为 $\sqrt n$ 的线段。

### 阅读与思考：勾股定理的证明

勾股定理有几百种证法。美国第 20 任总统加菲尔德用两个全等直角三角形和一个等腰直角三角形拼成直角梯形：$\frac12(a+b)(a+b) = 2\times\frac12 ab + \frac12 c^2$，化简也得到 $a^2 + b^2 = c^2$。
