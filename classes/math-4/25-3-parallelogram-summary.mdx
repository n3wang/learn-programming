# 小结：平行四边形

> 第二十五章复习。前面的课：[性质](./parallelogram-properties)、[判定](./parallelogram-criteria)、[矩形](./rectangle)、[菱形](./rhombus)、[正方形](./square)。

## 一、知识结构

| | 定义 | 特有性质 | 判定 |
| --- | --- | --- | --- |
| 平行四边形 | 两组对边分别平行 | 对边相等，对角相等，对角线互相平分 | 五种（边、角、对角线） |
| 矩形 | 有一个角是直角的平行四边形 | 四个直角；对角线相等 | 一个直角的▱；对角线相等的▱；三个直角的四边形 |
| 菱形 | 一组邻边相等的平行四边形 | 四边相等；对角线垂直、平分对角 | 邻边相等的▱；对角线垂直的▱；四边相等的四边形 |
| 正方形 | 邻边相等且有一个直角的平行四边形 | 矩形 + 菱形的全部性质 | 邻边相等的矩形；一个直角的菱形 |

重要推论：**三角形中位线定理**；**直角三角形斜边上的中线等于斜边的一半**。

## 二、回顾与思考

1. 研究特殊平行四边形的路线：**定义 → 性质 → 判定**；判定往往是性质的逆命题（要证明）。
2. 平行四边形的问题常转化为**三角形**问题（连对角线，用全等、勾股定理）。
3. 特殊的平行四边形要在「一般」的基础上**加条件**；判定时一定看清前提是「四边形」还是「平行四边形」。

## 三、复习题 25

**1.** 矩形 ABCD 中，$AB = 3$，$BC = 4$，求对角线 AC 的长和点 B 到 AC 的距离。

<details>
<summary>答案</summary>

$AC = 5$。面积 $= AB\cdot BC = AC\cdot h$，$h = \frac{12}{5} = 2.4$。

</details>

**2.** 顺次连接矩形各边中点得到的四边形是什么？顺次连接菱形各边中点呢？

<details>
<summary>答案</summary>

中点四边形的边平行于原四边形的对角线、等于对角线的一半。矩形对角线相等 → 中点四边形四边相等 → **菱形**；菱形对角线垂直 → 中点四边形邻边垂直 → **矩形**。

</details>

**3.** 正方形 ABCD 中，E 是 BC 上一点，$AE$ 平分 $\angle BAC$ 吗？若 $\angle BAE = 22.5^\circ$，求证 $BE + AB = AC$。（提示：在 AC 上截取 $AF = AB$。）

<details>
<summary>答案</summary>

$\angle BAC = 45^\circ$，$\angle BAE = 22.5^\circ$，所以 AE 平分 ∠BAC。截取 $AF = AB$，△ABE ≌ △AFE（SAS），$EF = BE$，$\angle AFE = 90^\circ$。Rt△EFC 中 $\angle C = 45^\circ$，$FC = EF = BE$。所以 $AC = AF + FC = AB + BE$。

</details>
