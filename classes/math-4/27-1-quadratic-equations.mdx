# 27.1 一元二次方程

> **改编自：** 人教版八年级下册（五·四学制）第二十七章 27.1 节。

**问题 1** 要设计一座 2 m 高的人体雕像，使雕像的上部（腰以上）与下部（腰以下）的高度比，等于下部与全部的高度比。雕像的下部应设计为多高？

设下部高 $x$ m，上部 $(2 - x)$ m：$\frac{2-x}{x} = \frac{x}{2}$，整理得 $x^2 + 2x - 4 = 0$。

**问题 2** 有一块矩形铁皮，长 100 cm、宽 50 cm，在四个角各切去一个同样的正方形，做成一个无盖方盒，盒底面积为 3 600 cm²。切去的正方形边长 $x$ 满足 $(100 - 2x)(50 - 2x) = 3600$，即 $x^2 - 75x + 350 = 0$。

**问题 3** 要组织一次排球邀请赛，参赛的每两个队之间都要比赛一场，计划安排 28 场。设邀请 $x$ 个队：$\frac12 x(x-1) = 28$，即 $x^2 - x = 56$。

---

## 一、概念

> 等号两边都是整式，只含有**一个**未知数（一元），并且未知数的**最高次数是 2**（二次）的方程，叫做**一元二次方程**。

**一般形式：**

$$
ax^2 + bx + c = 0\qquad(a \ne 0) .
$$

$ax^2$ 是二次项，$a$ 是**二次项系数**；$bx$ 是一次项，$b$ 是**一次项系数**；$c$ 是**常数项**。

:::caution 注意
- $a \ne 0$ 是必须的（否则不是二次方程）；$b$、$c$ 可以为 0。
- 系数**包括前面的符号**：$3x^2 - 5x - 2 = 0$ 中 $b = -5$，$c = -2$。
- 先化成一般形式，再说系数：$x(x+3) = 2x - 1 \Rightarrow x^2 + x + 1 = 0$。
:::

| 方程 | 一元二次方程吗 | 原因 |
| --- | --- | --- |
| $x^2 = 0$ | 是 | $a = 1$，$b = c = 0$ |
| $x^2 + \frac1x = 2$ | 不是 | 不是整式方程 |
| $x^2 + y = 3$ | 不是 | 两个未知数 |
| $(x+1)^2 = x^2$ | 不是 | 整理后 $2x + 1 = 0$，是一次方程 |

---

## 二、一元二次方程的根

使一元二次方程左右两边相等的未知数的值，叫做一元二次方程的**解**，也叫做**根**。

例：$x^2 - x = 56$ 中，$x = 8$ 和 $x = -7$ 都是根；但问题 3 中队数是正整数，所以只能取 $x = 8$。

已知一个根求参数：把根**代入**方程。例：$x = 2$ 是 $x^2 + kx - 6 = 0$ 的根，$4 + 2k - 6 = 0$，$k = 1$。
