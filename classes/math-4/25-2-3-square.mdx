# 25.2 正方形

> **改编自：** 人教版八年级下册（五·四学制）25.2.3。上一课是 [25.2 菱形](./rhombus)。

**有一组邻边相等并且有一个角是直角的平行四边形叫做正方形。** 正方形既是矩形，又是菱形，所以它有矩形和菱形的**全部**性质。

---

## 一、正方形的性质

| 方面 | 性质 |
| --- | --- |
| 边 | 四条边都相等，对边平行 |
| 角 | 四个角都是直角 |
| 对角线 | 相等、互相垂直平分，每条对角线平分一组对角（与边成 45°） |
| 对称性 | 轴对称图形，有 4 条对称轴 |

### 例 5

求证：正方形的两条对角线把正方形分成四个全等的等腰直角三角形。

<GeoFig width={180} points={{ A: [0, 2], B: [0, 0], C: [2, 0], D: [2, 2], O: [1, 1] }} segments={['AB', 'BC', 'CD', 'DA', { s: 'A C', dash: true }, { s: 'B D', dash: true }]} right={['A O B']} labelPos={{ O: 'e' }} />

**证明：** 正方形 ABCD 中，$AC = BD$，$AC \perp BD$，$AO = BO = CO = DO$，所以 △ABO、△BCO、△CDO、△DAO 都是等腰直角三角形，并且 $AB = BC = CD = DA$，它们全等（SSS）。

边长为 $a$ 的正方形，对角线长 $\sqrt2\,a$，面积 $a^2 = \frac12 d^2$（$d$ 为对角线）。

---

## 二、正方形的判定

| 从矩形出发 | 从菱形出发 |
| --- | --- |
| 有一组邻边相等的矩形 | 有一个角是直角的菱形 |
| 对角线互相垂直的矩形 | 对角线相等的菱形 |

---

## 三、四边形之间的关系

| 四边形 | 平行四边形 | 矩形 | 菱形 | 正方形 |
| --- | --- | --- | --- | --- |
| 对边平行且相等 | ✓ | ✓ | ✓ | ✓ |
| 四边相等 | | | ✓ | ✓ |
| 四个直角 | | ✓ | | ✓ |
| 对角线互相平分 | ✓ | ✓ | ✓ | ✓ |
| 对角线相等 | | ✓ | | ✓ |
| 对角线互相垂直 | | | ✓ | ✓ |

**平行四边形** ──（一个角是直角）→ **矩形** ──（一组邻边相等）→ **正方形**；
**平行四边形** ──（一组邻边相等）→ **菱形** ──（一个角是直角）→ **正方形**。
