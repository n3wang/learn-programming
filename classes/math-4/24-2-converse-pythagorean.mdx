# 24.2 勾股定理的逆定理

> **改编自：** 人教版八年级下册（五·四学制）24.2 节。上一课是 [24.1 勾股定理](./pythagorean-theorem)。

古埃及人用一根打了 13 个等距结的绳子，以 3、4、5 个结间距为边拉成三角形，就得到一个直角——他们用这个方法定直角。为什么？

---

## 一、逆定理

> **勾股定理的逆定理**　如果三角形的三边长 $a$、$b$、$c$ 满足 $a^2 + b^2 = c^2$，那么这个三角形是直角三角形（$c$ 所对的角是直角）。

**证明思路：** 另画一个 Rt△A′B′C′，使直角边 $B'C' = a$，$C'A' = b$。由勾股定理，$A'B'^2 = a^2 + b^2 = c^2$，所以 $A'B' = c$。两个三角形三边对应相等（SSS），全等，于是 $\angle C = \angle C' = 90^\circ$。

### 例 1　判断是不是直角三角形

**方法：** 找出最大边，看**两条较小边的平方和**是否等于**最大边的平方**。

(1) $a = 15$，$b = 8$，$c = 17$：$15^2 + 8^2 = 225 + 64 = 289 = 17^2$，是直角三角形。

(2) $a = 13$，$b = 14$，$c = 15$：最大边是 15，$13^2 + 14^2 = 365 \ne 225$，不是直角三角形。

### 勾股数

能够成为直角三角形三条边长的三个**正整数**，称为**勾股数**。常见的有：

| 勾股数 | 规律 |
| --- | --- |
| 3, 4, 5 | |
| 5, 12, 13 | |
| 8, 15, 17 | |
| 7, 24, 25 | |
| 6, 8, 10　9, 12, 15 | 3, 4, 5 的倍数也是勾股数 |

## 二、互逆命题与互逆定理

两个命题中，如果第一个命题的题设是第二个命题的结论，而第一个命题的结论又是第二个命题的题设，那么这两个命题叫做**互逆命题**，其中一个叫做另一个的**逆命题**。

| 原命题 | 逆命题 | 逆命题对吗 |
| --- | --- | --- |
| 直角三角形两直角边的平方和等于斜边的平方 | 三边满足 $a^2+b^2=c^2$ 的三角形是直角三角形 | 对（逆定理） |
| 两直线平行，内错角相等 | 内错角相等，两直线平行 | 对 |
| 对顶角相等 | 相等的角是对顶角 | **不对** |
| 如果两个实数相等，那么它们的绝对值相等 | 绝对值相等的两个实数相等 | **不对**（$3$ 与 $-3$） |

一个命题是正确的，它的逆命题不一定正确。如果一个定理的逆命题经过证明也是正确的，它就是这个定理的**逆定理**。

## 三、例 2　航海问题

港口 $P$ 在东西方向的海岸线上。「远航」号、「海天」号同时离开港口，「远航」号每小时航行 16 海里，「海天」号每小时航行 12 海里。一个半小时后它们分别位于 $Q$、$R$，相距 30 海里。已知「远航」号沿东北方向航行，「海天」号沿哪个方向航行？

<GeoFig width={280} points={{ P: [0, 0], Q: [2.83, 2.83], R: [-2.12, 2.12], 北: [0, 3.4], 西: [-3.4, 0], 东: [3.4, 0] }} segments={[{ s: '西 东', color: 'var(--ifm-color-emphasis-500)' }, { s: 'P 北', dash: true, color: 'var(--ifm-color-emphasis-500)' }, { s: 'P Q', color: '#e0245e' }, { s: 'P R', color: '#4a90d9' }, { s: 'Q R', dash: true }]} right={['Q P R']} labelPos={{ P: 's', 北: 'n', 西: 'w', 东: 'e', Q: 'ne', R: 'nw' }} caption="Q：「远航」号（东北方向）；R：「海天」号" />

$PQ = 16\times 1.5 = 24$，$PR = 12\times 1.5 = 18$，$QR = 30$。

$24^2 + 18^2 = 576 + 324 = 900 = 30^2$，所以 $\angle QPR = 90^\circ$。

「远航」号沿东北方向（北偏东 45°），所以「海天」号沿**西北**方向航行。

### 阅读与思考：费马大定理

$x^2 + y^2 = z^2$ 有无穷多组正整数解（勾股数）。17 世纪法国数学家费马提出：当 $n > 2$ 时，$x^n + y^n = z^n$ 没有正整数解。这个猜想困扰了数学家 300 多年，1995 年才由英国数学家怀尔斯证明。
