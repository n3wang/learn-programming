# 25.1 平行四边形的判定

> **改编自：** 人教版八年级下册（五·四学制）25.1.2。上一课是 [25.1 平行四边形的性质](./parallelogram-properties)。

把性质「反过来」，就得到判定。

---

## 一、五种判定方法

| 判定 | 从哪里看 | 来源 |
| --- | --- | --- |
| 两组对边分别**平行** | 边 | 定义 |
| 两组对边分别**相等** | 边 | 性质 1 的逆命题 |
| 一组对边**平行且相等** | 边 | |
| 两组对角分别**相等** | 角 | 性质 2 的逆命题 |
| 对角线**互相平分** | 对角线 | 性质 3 的逆命题 |

**证明「对角线互相平分 → 平行四边形」：** $OA = OC$，$OB = OD$，$\angle AOD = \angle COB$（对顶角），所以 $\triangle AOD \cong \triangle COB$（SAS），$\angle OAD = \angle OCB$，于是 $AD \parallel BC$；同理 $AB \parallel DC$。

:::caution 不能判定
「一组对边**平行**，另一组对边**相等**」——等腰梯形就满足，它不是平行四边形。
「一组对边平行且相等」中，平行和相等必须是**同一组**对边。
:::

### 例 3

▱ABCD 的对角线 $AC$、$BD$ 相交于点 $O$，$E$、$F$ 是 $AC$ 上的两点，并且 $AE = CF$。求证：四边形 BFDE 是平行四边形。

<GeoFig width={260} points={{ A: [0, 0], B: [4, 0], C: [5.2, 2.2], D: [1.2, 2.2], O: [2.6, 1.1], E: [1.3, 0.55], F: [3.9, 1.65] }} segments={['AB', 'BC', 'CD', 'DA', { s: 'A C', dash: true }, { s: 'B D', dash: true }, { s: 'B F', color: '#e0245e' }, { s: 'F D', color: '#e0245e' }, { s: 'D E', color: '#e0245e' }, { s: 'E B', color: '#e0245e' }]} labelPos={{ A: 'sw', B: 'se', C: 'ne', D: 'nw', O: 's' }} />

**证明：** $AO = CO$，$BO = DO$；$AE = CF$，所以 $EO = AO - AE = CO - CF = FO$。四边形 BFDE 的对角线 $EF$、$BD$ 互相平分，所以它是平行四边形。

### 例 4

在 ▱ABCD 中，$E$、$F$ 分别是 $AB$、$CD$ 的中点。求证：四边形 EBFD 是平行四边形。

$AB = CD$ 且 $AB\parallel CD$，$EB = \frac12 AB$，$FD = \frac12 CD$，所以 $EB = FD$ 且 $EB\parallel FD$——一组对边平行且相等。

## 二、三角形的中位线

连接三角形两边中点的线段叫做**三角形的中位线**。

<MidlineSimulator />

> **三角形中位线定理**　三角形的中位线平行于三角形的第三边，并且等于第三边的一半。

**证明：** $D$、$E$ 是 $AB$、$AC$ 的中点。延长 $DE$ 到 $F$，使 $EF = DE$，连接 $FC$。$AE = CE$，$\angle AED = \angle CEF$，所以 $\triangle ADE \cong \triangle CFE$（SAS），$AD = CF$，$\angle ADE = \angle F$，于是 $BD\parallel CF$ 且 $BD = AD = CF$。四边形 DBCF 是平行四边形，$DF \parallel BC$，$DF = BC$，所以 $DE \parallel BC$，$DE = \frac12 BC$。

**应用：** A、B 两点被池塘隔开，在外面选一点 C，量出 AC、BC 的中点 M、N 之间的距离，$AB = 2MN$。
