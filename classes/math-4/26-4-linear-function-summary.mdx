# 小结：一次函数

> 第二十六章复习。前面的课：[函数](./functions)、[正比例函数](./proportional-functions)、[一次函数的图象与性质](./linear-functions)、[待定系数法与应用](./undetermined-coefficients)、[选择方案](./choosing-plans)。

## 一、知识结构

| 主题 | 内容 |
| --- | --- |
| 函数 | 变量、常量；自变量的每个值对应唯一的函数值；取值范围；三种表示方法 |
| 正比例函数 | $y = kx\ (k\ne 0)$，过原点的直线 |
| 一次函数 | $y = kx + b\ (k\ne 0)$，由 $y = kx$ 平移得到 |
| 性质 | $k>0$ 增，$k<0$ 减；$(0, b)$ 是与 $y$ 轴交点 |
| 求解析式 | 待定系数法：几个待定系数需要几个条件 |
| 与方程、不等式 | 交点 ↔ 方程（组）的解；图象在 $x$ 轴上方 / 下方 ↔ 不等式的解集 |
| 应用 | 分段函数；选择方案 |

## 二、回顾与思考

1. **数形结合**：解析式告诉我们「怎么算」，图象告诉我们「怎么变」。$k$、$b$ 的符号 ↔ 直线的位置。
2. **函数的观点**看方程与不等式：$kx + b = 0$ 不过是 $y = kx + b$ 中 $y = 0$ 时的情形。
3. 实际问题中，自变量的取值范围要使实际问题有意义。

## 三、复习题 26

**1.** 一次函数 $y = kx + b$ 的图象经过 $(2, 0)$ 和 $(0, -4)$。(1) 求解析式；(2) 求图象与坐标轴围成的三角形面积；(3) $x$ 取何值时 $y > 0$？

<details>
<summary>答案</summary>

(1) $b = -4$，$0 = 2k - 4$，$k = 2$，$y = 2x - 4$；(2) $S = \frac12\times 2\times 4 = 4$；(3) $k > 0$，$x > 2$。

</details>

**2.** 弹簧挂上物体后会伸长。测得一弹簧的长度 $y$（cm）与所挂物体质量 $x$（kg）的关系：挂 0 kg 时长 18 cm，每挂 1 kg 伸长 2 cm（不超过 10 kg）。写出 $y$ 与 $x$ 的函数关系式，并求挂 6 kg 时的长度。

<details>
<summary>答案</summary>

$y = 2x + 18\ (0\le x\le 10)$；$x = 6$ 时 $y = 30$ cm。

</details>

**3.** 直线 $y = -x + 4$ 与 $y = 3x$ 交于点 P，与 $x$ 轴交于 A，求 △OPA 的面积。

<details>
<summary>答案</summary>

$-x + 4 = 3x$，$x = 1$，$P(1, 3)$；$A(4, 0)$。$S = \frac12\times 4\times 3 = 6$。

</details>
