# 26.1 函数

> **改编自：** 人教版八年级下册（五·四学制）第二十六章 26.1 节。

时间推移、水位升降、气温变化……我们生活在一个变化的世界里。函数就是描述「一个量怎样随另一个量变化」的数学工具。

---

## 一、变量与常量

汽车以 60 km/h 的速度匀速行驶，行驶路程为 $s$ km，行驶时间为 $t$ h：$s = 60t$。在这个过程中，$s$、$t$ 的值在变化，60 不变。

> 在一个变化过程中，数值发生变化的量叫做**变量**，数值始终不变的量叫做**常量**。

---

## 二、函数

> 一般地，在一个变化过程中，如果有两个变量 $x$ 与 $y$，并且对于 $x$ 的**每一个确定的值**，$y$ 都有**唯一确定的值**与其对应，那么就说 $x$ 是**自变量**，$y$ 是 $x$ 的**函数**。
> 如果当 $x = a$ 时 $y = b$，那么 $b$ 叫做当自变量的值为 $a$ 时的**函数值**。

关键词：「每一个」「唯一」。例如 $y^2 = x$ 中，$x = 4$ 时 $y = \pm 2$，不唯一，所以 $y$ **不是** $x$ 的函数。

### 例 1　油箱里的油

汽车油箱中有汽油 50 L。如果不再加油，油量 $y$（L）随行驶路程 $x$（km）的增加而减少，耗油量为 0.1 L/km。

(1) $y = 50 - 0.1x$；

(2) 从式子看 $x$ 可以取任意实数，但 $x$ 是路程，$x \ge 0$；油量不能为负，$50 - 0.1x \ge 0$，$x \le 500$。所以 $0 \le x \le 500$；

(3) $x = 200$ 时，$y = 50 - 20 = 30$（L）。

### 自变量的取值范围

| 式子 | 要求 |
| --- | --- |
| 整式（如 $y = 2x + 1$） | 全体实数 |
| 分式（如 $y = \frac{1}{x-2}$） | 分母 $\ne 0$：$x \ne 2$ |
| 二次根式（如 $y = \sqrt{x-3}$） | 被开方数 $\ge 0$：$x \ge 3$ |
| 实际问题 | 还要使实际问题有意义（如路程、件数非负） |

用函数解析式表示函数关系的方法叫做**解析式法**。

---

## 三、函数的图象

对于一个函数，把自变量与函数的每对对应值分别作为点的横、纵坐标，在坐标平面内描出这些点，组成的图形就是这个函数的**图象**。

**描点法画图象：** 列表 → 描点 → 连线（按自变量从小到大的顺序，用平滑曲线连接）。

### 例 2　读图象

小明从家去食堂吃早餐，接着去图书馆读报，然后回家。下面是他离家的距离 $y$（km）与时间 $x$（min）的关系：

- 食堂到图书馆 $0.8 - 0.6 = 0.2$ km，用了 3 min；读报 $58 - 28 = 30$ min；

图象中**平行于 x 轴**的线段表示 $y$ 不变（停留）。

### 三种表示方法

| 方法 | 优点 |
| --- | --- |
| 列表法 | 直接看出对应的函数值 |
| 解析式法 | 准确、便于计算和研究 |
| 图象法 | 直观地看出变化趋势 |

### 例 4　水位

一个水库 5 h 内水位持续上涨，每小时上涨 0.3 m，初始水位 3 m：$y = 3 + 0.3t$（$0\le t\le 5$）。描出的点在一条直线上。若这种上涨规律再持续 2 h，$t = 7$ 时水位约 $5.1$ m。
