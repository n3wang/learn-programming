## 一、本章知识结构图

方程是含有未知数的等式。本章从概念走到一元一次方程，再用它解决实际问题。

```text
方程（含未知数的等式）
├─ 有关概念
│   ├─ 方程的解：使左右两边相等的未知数的值
│   ├─ 解方程：把方程逐步化成 x = m（常数）
│   └─ 检验：把解代回原方程或原问题
├─ 一元一次方程
│   ├─ 只含一个未知数，含未知数的式子都是整式，次数都是 1
│   ├─ 标准形式：ax + b = 0（a ≠ 0）
│   └─ 解法（化归）：去分母 → 去括号 → 移项 → 合并同类项 → 系数化为 1
│       依据：等式的性质与运算律
└─ 用方程解决实际问题
    实际问题 → 找相等关系、设未知数、列方程
    → 解方程得到数学结论 → 检验并解释实际问题
```

## 二、回顾与思考

方程是一种描述现实世界的重要数学模型。在本章，我们结合一些实际问题，学习了方程的有关概念，并重点研究了最基本的方程——一元一次方程，为进一步学习方程打下基础。

方程是含有未知数的等式，解方程就是求出方程中未知数的值。解以 $x$ 为未知数的方程，就是把方程逐步转化为 $x=m$（常数）的形式。

一元一次方程是只含有一个未知数，且含有未知数的式子都是整式，未知数的次数都是 1 的方程。一元一次方程都可以化为标准形式

$$
ax+b=0
$$

（其中 $x$ 是未知数，$a$、$b$ 是已知数，并且 $a\neq 0$）。

解一元一次方程，是使方程形式逐步化简，最终得出未知数的值。在此过程中，**化归**的思想起了重要作用，而等式的性质及运算律是化归的根据。

利用方程解决实际问题，应认真分析其中的数量关系，关键是要找出**相等关系**，由此设未知数、列方程，从而把实际问题转化为数学问题；然后通过解方程获得数学结论；最后用数学结论解释实际问题。这是一个「实际问题 — 数学问题 — 实际问题」的过程。今后，我们还将不断经历这个过程，认识更多类型的方程，解决更多实际问题。

:::tip 列方程前先问两句
1. 题目里哪两个量应当相等？
2. 设出未知数后，每一句条件能否写成含这个未知数的式子？
:::
