# 6.3 角

> **改编自：** 人教版《义务教育教科书·数学》七年级上册 第六章 6.3 节。角也是基本几何图形，研究的方法可以类比线段。上一课是 [6.2 直线、射线、线段](./lines-rays-segments)。

与线段一样，角也是一种基本的几何图形。这一节类比线段的研究内容和方法，研究角的概念和度量。

---

## 6.3.1 角的概念

日常生活里，角的实例随处可见。钟面上的时针与分针、棱锥相交的两条棱、三角尺两条相交的边线，都给我们以角的形象。

有公共端点的两条射线组成的图形叫作**角**（angle）。这个公共端点是角的**顶点**，这两条射线是角的两条**边**。

![图 6.3-2 角的表示，以及能否记作角 O](/img/math-6-3-2-notation.png)

角通常可以这样表示：

| 写法 | 什么时候用 |
| --- | --- |
| 角 AOB | 用三个字母，顶点字母写在中间。角 AOB 与角 BOA 是同一个角 |
| 角 O | 只有在顶点 O 处只有这一个角时，才可以用顶点字母表示 |
| 角 α、角 1 | 用一个希腊字母或数字标在角的内部 |

### 思考

角也可以看作由一条射线绕着它的端点旋转而形成的图形。射线 OA 绕端点 O 旋转，终止位置是 OB。

![图 6.3-3 射线绕端点旋转](/img/math-6-3-3-rotate.png)

<AngleRotationSimulator />

- 当终止位置 OB 和起始位置 OA **成一条直线**时，形成的是**平角**。
- 继续旋转，OB 和 OA **重合**时，形成的是**周角**。

今后如无特别说明，所说的角都是指还没有旋转成平角时所成的角。

### 角度制

常用量角器量角。度、分、秒是常用的角的度量单位。把一个周角 360 等分，每一份就是 1 度的角，记作 1°；把 1 度的角 60 等分，每一份叫作 1 分，记作 1′；把 1 分的角 60 等分，每一份叫作 1 秒，记作 1″。

<DegreeUnitFillSimulator />

角 α 的度数是 48 度 56 分 37 秒，记作 48°56′37″。

借助三角尺，可以画出 30°、45°、60°、90° 等特殊角；借助量角器，可以画出给定度数的角，例如 36°、108°。

以度、分、秒为单位的角的度量制，叫作**角度制**。以后还会学到以弧度为单位的弧度制。军事上还常用密位制。

:::tip 溯源
最早明确使用角度制的文字记载，见于希腊学者托勒密（Ptolemaeus，约 90—168）的《天文学大成》。他将圆周分为 360 等份，1 份记为 1°，并采用古巴比伦的六十进制，定义出度、分、秒。
:::

## 小结

| 概念 | 含义 |
| --- | --- |
| 角 | 有公共端点的两条射线。公共端点是顶点，两条射线是边 |
| 表示 | 角 AOB（顶点在中间）；顶点处只有一个角时，才可以写成角 O |
| 旋转 | 一条射线绕端点旋转形成角 |
| 平角 | 终边与始边成一条直线，180° |
| 周角 | 终边与始边重合，360° |
| 角度制 | 1 周角 = 360°，1 平角 = 180°，1° = 60′，1′ = 60″ |
