# 6.3.2 角的比较与运算

> **改编自：** 人教版《义务教育教科书·数学》七年级上册 第六章 6.3.2。比较角、求角的和与差，方法可以类比线段。上一课是 [6.3 角](./angles)。

已经知道怎样比较两条线段的长短。比较两个角，也可以用量角器量出度数，再比大小；也可以把它们的一条边叠合在一起，看另一条边落在哪里。

![图 6.3-6 至图 6.3-8 角的比较、和差，以及三角尺拼角](/img/math-6-3-2-compare.png)

<AngleCompareOverlapSimulator />

- 另一条边落在第二个角的内部，则角 AOB 小于角 A′O′B′。
- 两条边重合，则两个角相等。
- 另一条边落在第二个角的外部，则角 AOB 大于角 A′O′B′。

### 思考

类比两条线段的和与差。在图 6.3-7 中，射线 OB 在角 AOC 的内部。

- 角 AOC 是角 AOB 与角 BOC 的和，记作角 AOC = 角 AOB + 角 BOC。
- 角 AOB 是角 AOC 与角 BOC 的差，记作角 AOB = 角 AOC − 角 BOC。
- 同样，角 AOC − 角 AOB = 角 BOC。

### 探究

一副三角尺上有 30°、45°、60°、90°。把它们拼起来或叠起来，还能得到：

| 运算 | 度数 |
| --- | --- |
| 45° + 30° | 75° |
| 45° − 30° | 15° |
| 60° + 45° | 105° |
| 90° + 30° | 120° |
| 90° + 45° | 135° |
| 90° + 60° | 150° |

### 例 2

如图，O 是直线 AB 上一点，角 AOC = 53°17′，求角 BOC 的度数。

AB 是直线，角 AOB 是平角，等于 180°。角 BOC 与角 AOC 的和是这个平角。

进行角度的加、减时，度与度、分与分、秒与秒分别相加、减。分、秒相加时，满 60 要进位；相减时，如果不够减，要向前面借 1，1° 当作 60′。本题中应先把 180° 化成 179°60′，再减。

**3.** 计算：48°39′ + 67°31′；41°12′ − 11°27′。上面的计算器在书题目时就是这两道，以及例 2。

线段的中点把线段分成两条相等的线段。类似地，如果角 AOB = 角 BOC，那么射线 OB 把角 AOC 分成两个相等的角。这时角 AOC = 2 角 AOB，角 AOB = 角 BOC = 角 AOC 的一半。

从角的顶点出发，把这个角分成两个相等的角的射线，叫作这个角的**平分线**。类似地，还有角的三等分线。

仿照图 6.3-12，在半透明的纸上折纸作角的平分线：把角的两边折到重合，折痕就是平分线。

### 例 3

把一个周角 7 等分，每份是多少度的角？精确到分。

度、分、秒是六十进制的，不能整除时要把剩余的度数化成分。360° ÷ 7 = 51° + 3° ÷ 7 = 51° + 180′ ÷ 7 ≈ 51°26′。

## 小结

| 概念 | 含义 |
| --- | --- |
| 比较角 | 量度数，或一边重合后再看另一条边 |
| 角的和 | 角 AOC = 角 AOB + 角 BOC |
| 角的差 | 角 AOB = 角 AOC − 角 BOC |
| 角度加减 | 分满 60 进 1°；不够减时借 1° 作 60′ |
| 平角求差 | 先把 180° 写成 179°60′ |
| 角平分线 | 把角分成两个相等的角的射线 |
| 周角 7 等分 | 每份约 51°26′ |
