# 6.2 直线、射线、线段

> **改编自：** 人教版《义务教育教科书·数学》七年级上册 第六章 6.2 节。直线、射线、线段是基本几何图形，先分清它们的联系与区别，再学会用点和字母表示。上一课是 [6.1 几何图形](./geometric-figures)。

直线、射线、线段是基本的几何图形。小学里已经初步认识过它们。下面进一步看它们怎样确定、怎样表示，以及一个点在不在一条直线上。

---

## 6.2.1 直线、射线、线段

### 探究

经过一个点能画几条直线？经过两个点呢？

<TwoPointLineSimulator />

通过画图和思考，可以得到一个基本事实：

**经过两点有一条直线，并且只有一条直线。**

简单说成：**两点确定一条直线。**

日常生活和生产中常常用到这个事实。例如，砌墙时会在两个墙脚的位置分别固定一根木杆，然后拉一条直的参照线（图 6.2-1）；植树时，只要定出两个树坑的位置，就能使同一行树坑在一条直线上。

![图 6.2-1 至图 6.2-4 两点确定一条直线，以及点与直线的位置](/img/math-6-2-1-two-points.png)

因为两点确定一条直线，所以除了用一个小写字母表示直线（如直线 \(l\)），还经常用这条直线上的两个点来表示它（图 6.2-2）。

| 说法 | 也可以说成 |
| --- | --- |
| 点在直线上 | 这条直线经过这个点 |
| 点在直线外 | 这条直线不经过这个点 |

如图 6.2-2，直线 \(AB\) 或直线 \(l\)。如图 6.2-3，点 \(O\) 在直线 \(l\) 上，点 \(P\) 在直线 \(l\) 外。

如图 6.2-4，当两条不同的直线有一个公共点时，就称这两条直线**相交**（intersection），这个公共点叫作它们的**交点**。

### 线段、射线，以及延长

射线和线段都是直线的一部分。

| | 直线 | 射线 | 线段 |
| --- | --- | --- | --- |
| 端点 | 没有 | 1 个 | 2 个 |
| 延伸 | 两个方向都无限 | 向一个方向无限 | 不延伸，长度有限 |
| 表示 | 直线 \(l\)，或直线 \(AB\)（与直线 \(BA\) 相同） | 射线 \(OA\)（端点写在前面），或射线 \(l\) | 线段 \(AB\)（与线段 \(BA\) 相同），或线段 \(a\) |

![图 6.2-5 至图 6.2-8 线段、射线与延长](/img/math-6-2-1-ray-exercises.png)

- **连接** \(AB\)：画出以 \(A\)、\(B\) 为端点的线段。
- **延长线段** \(AB\)：按从端点 \(A\) 到 \(B\) 的方向延长（图 6.2-7）。
- **延长线段** \(BA\)：按从端点 \(B\) 到 \(A\) 的方向延长。也可以说**反向延长**线段 \(AB\)（图 6.2-8）。

:::tip 先看端点写在哪
射线 \(AB\) 的端点是 \(A\)，经过 \(B\) 再延伸。射线 \(BA\) 的端点是 \(B\)，不是同一条射线。线段 \(AB\) 和线段 \(BA\) 则是同一条。
:::

## 6.2.2 线段的比较与运算

不同于直线和射线，线段有长度，因而可以比较长短，并能进行一些运算。为了比较和运算，需要画一条线段等于已知线段。

画一条线段等于已知线段 \(AB\)，可以先用刻度尺量出 \(AB\) 的长度，再画一条等于这个长度的线段。也可以先用直尺画直线 \(l\)，再用圆规在直线 \(l\) 上截取 \(CD = AB\)（图 6.2-9）。数学里常限定用无刻度的直尺和圆规作图，这就是**尺规作图**。

![图 6.2-9 至图 6.2-11 尺规作图与线段比较](/img/math-6-2-2-compare.png)

### 探究

怎样比较两条线段的长短？从比身高上可以受到启发：把它们“叠”在一起看。还可以再举：比较两支铅笔、两根跳绳、课桌的两条边。

比较两条线段，可用刻度尺分别量出长度，或者把其中一条移到另一条上作比较。移动时，通常使它们的一个端点重合。

<SegmentCompareSimulator />

在图 6.2-11 中，点 \(A\) 与点 \(C\) 重合，点 \(B\) 落在点 \(C\)、\(D\) 之间，这时说线段 \(AB\) 小于线段 \(CD\)，记作 \(AB < CD\)。

- 若点 \(D\) 落在 \(C\)、\(B\) 之间，则 \(AB > CD\)。
- 若点 \(B\) 与点 \(D\) 重合，则 \(AB = CD\)。

### 两点之间，线段最短

从 \(A\) 地到 \(B\) 地有好几条道路。把这些道路看成软线拉直，线段 \(AB\) 最短。

![图 6.2-12 至图 6.2-15 最短道路与线段的和、差](/img/math-6-2-2-shortest-ops.png)

<ShortestPathSimulator />

**两点的所有连线中，线段最短。** 简单说成：**两点之间，线段最短。**

连接两点的线段的长度，叫作这两点间的**距离**（distance）。

### 线段的运算

在直线上作线段 \(AB = a\)，再在 \(AB\) 的延长线上作线段 \(BC = b\)，线段 \(AC\) 就是 \(a\) 与 \(b\) 的和，记作 \(AC = a + b\)。

设 \(a > b\)，如果在线段 \(AB\) 上作线段 \(BD = b\)，那么线段 \(AD\) 就是 \(a\) 与 \(b\) 的差，记作 \(AD = a - b\)。

**例** 已知线段 \(a\)、\(b\)，作一条线段，使它等于 \(2a - b\)。

作法：在直线上作 \(AB = a\)，再在延长线上作 \(BC = a\)，则 \(AC = 2a\)。在线段 \(AC\) 上截取 \(CD = b\)，则 \(AD = 2a - b\)。

点 \(M\) 把线段 \(AB\) 分成相等的两条线段 \(AM\) 与 \(MB\)，点 \(M\) 叫作线段 \(AB\) 的**中点**。类似地，还有三等分点、四等分点。在透明纸上画一条线段，折叠使两端点重合，折痕与线段的交点就是中点。

![图 6.2-16 中点与等分点，以及练习](/img/math-6-2-2-midpoint-exercises.png)

## 小结

| 概念 | 含义 |
| --- | --- |
| 两点确定一条直线 | 经过两个点有一条直线，并且只有一条 |
| 经过一个点 | 可以画无数条直线 |
| 直线 | 没有端点，两个方向都无限；直线 \(AB\) 与直线 \(BA\) 相同 |
| 射线 | 直线的一部分，有一个端点；射线 \(AB\) 与射线 \(BA\) 不同 |
| 线段 | 直线的一部分，有两个端点；线段 \(AB\) 与线段 \(BA\) 相同 |
| 点与直线 | 在直线上 = 直线经过该点；在直线外 = 直线不经过该点 |
| 相交 | 两条不同直线有一个公共点，这个点叫交点 |
| 延长 | 延长 \(AB\) 是从 \(A\) 向 \(B\) 的方向；反向延长 \(AB\) 就是延长 \(BA\) |
| 线段比较 | 量长度，或把一条移到另一条上，使一个端点重合 |
| 两点之间 | 线段最短；这条线段的长叫两点间的距离 |
| 线段运算 | \(AC = a + b\)，\(AD = a - b\)；中点把线段分成相等的两段 |
