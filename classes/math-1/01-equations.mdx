# 5.1 方程

> **改编自：** 人教版《义务教育教科书·数学》七年级上册 第五章 5.1 节——从「相等关系」出发认识方程，弄清未知数、解、检验这几个基本概念。

在小学里，我们已经用过「□ + 3 = 10」这类式子。进入初中后，把方框换成字母，就写成了**方程**。方程是描述相等关系的工具，也是后面解方程、列方程解应用题的基础。

---

## 从相等关系到方程

许多实际问题里都藏着「两边一样多」的关系。例如：

- 某数的 3 倍等于 15；
- 小明有 $x$ 元，又攒了 20 元，一共 50 元；
- 长方形的周长是 24，长是宽的 2 倍。

把这种相等关系用含有未知数的等式写出来，就得到方程。例如：

$$
3x = 15,\qquad x + 20 = 50,\qquad 2(2w + w) = 24.
$$

:::tip 方程是什么？
含有**未知数**的**等式**叫做方程。  
「含有未知数」和「是等式」这两个条件缺一不可：$x + 3$ 不是等式；$5 + 3 = 8$ 是等式但不含未知数，都不是方程。
:::

---

## 方程的解

使方程左右两边相等的未知数的值，叫做方程的**解**（也叫方程的根）。

例如，方程 $x + 20 = 50$：

- 当 $x = 30$ 时，左边 $30 + 20 = 50$，右边也是 50，左右相等，所以 $x = 30$ 是它的解；
- 当 $x = 25$ 时，左边 $25 + 20 = 45 \neq 50$，所以 $x = 25$ 不是它的解。

求方程的解的过程叫做**解方程**。下一课 [5.2 解一元一次方程](./solving-linear-equations) 会系统地练习怎么解。

## 一元一次方程（先认一认）

如果一个方程只含有**一个未知数**，并且未知数的次数都是 **1**（没有 $x^2$、$xy$ 等），就叫做**一元一次方程**。例如：

| 是一元一次方程 | 不是 |
| --- | --- |
| $2x + 3 = 11$ | $x^2 + 1 = 5$（次数不是 1） |
| $\dfrac{x}{2} - 1 = 3$ | $x + y = 5$（两个未知数） |
| $3(x - 1) = 2x + 4$ | $x + 3$（不是等式） |

本章后面两课会专门练「怎么解」和「怎么用方程解决实际问题」。

---

## 小结

| 概念 | 含义 |
| --- | --- |
| 方程 | 含有未知数的等式 |
| 解（根） | 使方程左右两边相等的未知数的值 |
| 解方程 | 求方程的解的过程 |
| 检验 | 把求得的值代回原方程，看是否成立 |
| 一元一次方程 | 只含一个未知数，且未知数次数都是 1 |
