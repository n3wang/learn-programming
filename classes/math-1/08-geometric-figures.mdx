# 6.1 几何图形

> **改编自：** 人教版《义务教育教科书·数学》七年级上册 第六章 6.1 节——从身边的图形出发，认识几何研究什么，以及什么是几何图形。

从古朴的特色民居到宏伟的城市建筑，从街头巷尾的交通标志到四通八达的立交桥，从古老的剪纸艺术到现代的城市雕塑，从自然界形态各异的生物到北京 2022 年冬奥会标志……图形世界多姿多彩。

这些事物看起来很不一样，但都可以从「形」的角度来观察。

---

## 几何研究什么？

各种各样的物体除了具有颜色、质量、材质等性质，还具有：

| 几何关心的方面 | 例子 |
| --- | --- |
| **形状** | 方的、圆的、三角的 |
| **大小** | 长度、面积、体积 |
| **位置关系** | 相交、垂直、平行 |

物体的形状、大小和位置关系，就是几何中研究的内容。颜色深浅、用什么材料做成，不是几何首先要回答的问题。

:::tip 先问这三句
看到一个物体，先暂时忘掉颜色和材质，问自己：它是什么形状？有多大？它和旁边的图形怎样摆放（相交、垂直还是平行）？
:::

---

## 什么是几何图形？

我们在小学学习过的点、线段、三角形、四边形、圆、长方体、圆柱、圆锥、球等，都是从形形色色的物体外形中抽象出来的。它们都是**几何图形**（geometric figure）。几何图形是数学研究的主要对象之一。

可以粗粗分成两类：

| 类型 | 例子 | 直觉 |
| --- | --- | --- |
| 平面图形 | 点、线段、三角形、四边形、圆 | 画在纸上，主要看周长、面积 |
| 立体图形 | 长方体、圆柱、圆锥、球 | 占据空间，还要看体积 |

冬奥会标志、交通标志、剪纸，常常先被看成平面图形；民居、立交桥、雕塑，则常常先被看成立体图形。同一件实物也可以从不同角度抽出不同的几何图形——例如一扇门可以看成长方形，门的边可以看成线段。

---

## 6.1.1 立体图形与平面图形

有些几何图形（如长方体、正方体、圆柱、圆锥、球等）的各部分**不都在同一平面内**，它们是**立体图形**。棱柱、棱锥也是常见的立体图形。

- 包装盒、储物盒等，常常给我们**棱柱**的形象：有两个互相平行的底面，侧面是长方形。
- 金字塔则给我们**棱锥**的形象：有一个多边形底面，侧面是三角形，交于一个顶点。

你还能再找出一些棱柱、棱锥的实例吗？例如粉笔盒、帐篷、屋顶、石碑。

有些几何图形（如线段、角、三角形、长方形、圆等）的各部分**都在同一平面内**，它们是**平面图形**。

| | 立体图形 | 平面图形 |
| --- | --- | --- |
| 是否都在同一平面内 | 不都在 | 都在 |
| 常见例子 | 长方体、正方体、圆柱、圆锥、球、棱柱、棱锥 | 线段、角、三角形、长方形、圆 |

虽然立体图形与平面图形是两类不同的几何图形，但它们是互相联系的。很多立体图形中的某些部分就是平面图形，例如长方体的侧面是长方形。

## 6.1.2 点、线、面、体

我们可以用简单图形构造出复杂图形，也可以把复杂图形转化为简单图形进行研究。构成图形的元素是什么？这些元素之间又存在着什么关系？

### 思考

图 6.1-11 是一个长方体。它有几个面？面和面相交的地方形成了几条棱？棱和棱相交成几个顶点？

<SolidElementCountSimulator />

长方体、正方体、圆柱、圆锥、球、棱柱、棱锥等都是**几何体**。几何体也简称**体**。

包围着体的是**面**。面有平的面和曲的面两种。平静的水面给我们以**平面**的形象，而一些建筑物的屋顶则给我们以**曲面**的形象。还可以再举：桌面、黑板面是平面；球面、圆柱侧面、漏斗侧面是曲面。

可以拖动下面的模型，切换「看面 / 看棱 / 看顶点」：

<SolidFigureGallery />

夜晚流星划过天空时留下一道明亮的光线，节日的焰火画出的曲线组成优美的图案，这些都给我们以**线**的形象。面和面相交的地方形成线。长方体 6 个面两两相交所成的 12 条棱（线）是直的，圆柱的侧面与底面相交所成的线是曲的（圆）。线和线相交的地方是**点**。长方体相邻的棱相交，得到 8 个顶点。

| 元素 | 怎样得到 | 长方体中 |
| --- | --- | --- |
| 体 | 由面围成 | 整个长方体 |
| 面 | 包围着体 | 6 个面（平面） |
| 线（棱） | 面和面相交 | 12 条直棱 |
| 点 | 线和线相交 | 8 个顶点 |

天上的星星、世界地图上的城市等，都给我们以**点**的形象。线和线相交的地方是点。

如图 6.1-14（1），笔尖可以看作一个点。这个点在纸上运动时，就形成线；节日的焰火也可以看成由点运动形成的。这可以说**点动成线**。清洁玻璃时，刮窗器在玻璃上形成一个面（图 6.1-14（2）），这可以说**线动成面**。长方形硬纸片绕它的一边旋转一周，形成一个圆柱体（图 6.1-14（3）），这可以说**面动成体**。

![图 6.1-14 点动成线、线动成面、面动成体，以及图 6.1-15](/img/math-6-1-14-point-motion.png)

几何图形都是由点、线、面、体组成的，点是构成图形的基本元素。一些庆祝活动的背景图案（图 6.1-15）也可以看作由点组成。

点、线、面、体经过运动变化，就能组合成各种各样的几何图形，形成多姿多彩的图形世界。

## 小结

| 概念 | 含义 |
| --- | --- |
| 几何研究的内容 | 物体的形状、大小和位置关系 |
| 几何图形 | 从物体外形中抽象出来的图形 |
| 立体图形 | 各部分不都在同一平面内，如长方体、圆柱、棱柱、棱锥、球 |
| 平面图形 | 各部分都在同一平面内，如线段、三角形、圆 |
| 二者的联系 | 立体图形的面，常常就是平面图形 |
| 点、线、面、体 | 构成图形的元素：面围成体，面交成线，线交成点 |
| 运动变化 | 点动成线，线动成面，面动成体 |
| 暂时不纳入几何的性质 | 颜色、质量、材质等 |
