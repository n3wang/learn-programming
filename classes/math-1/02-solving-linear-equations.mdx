# 5.2 解一元一次方程

> **改编自：** 人教版七年级上册 5.2 节。先认清解方程的基本步骤，再用随机练习把四类题型练熟。概念回顾见 [5.1 方程](./equations)；应用题见 [5.3 实际问题与一元一次方程](./practical-problems-linear-equations)。

解一元一次方程，通常按下面的顺序化简，直到求出未知数：

1. **去分母**（两边同乘分母的最小公倍数）
2. **去括号**（分配律）
3. **移项**（把含未知数的项移到一边，常数项移到另一边；移项要变号）
4. **合并同类项**
5. **系数化为 1**（两边同除以未知数的系数）

下面四类练习都能无限出新题。每道题都有独立的「显示解答」按钮；点「换一批」会重新出一整组。

## 一、移项与合并同类项

最基础的一类：把含未知数的项移到一边，常数项移到另一边，合并同类项，再把系数化为 1。

## 二、先去括号

遇到括号，先把括号前的系数（可能是正数、负数，也可能就是一个单独的正负号）分配到括号里的每一项，之后就和第一类完全一样了。

## 三、先去分母

分母不同的两个分数，两边同时乘以分母的最小公倍数，把分母都消掉——之后同样是移项、合并同类项、系数化为 1。注意分母也可以是负数。

## 四、列方程解应用题

这一类的难点不在"解"，而在"列"——把一句中文描述准确翻译成一个方程。翻译时可以把"的 n 倍"看作 ×n，"…的和"看作加法，"…的差"看作减法，"…的积"看作乘法，从左到右逐字对应着写下来。
