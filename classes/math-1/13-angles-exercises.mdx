## 小结

| 题 | 要点 |
| --- | --- |
| 1 | 以 OC 为边的角有 3 个：角 AOC、角 BOC、角 COD |
| 2 | (1)(2)(5) 错，(3)(4) 对 |
| 3 | 24′；0.2′；75°10′；102°24′；7.8° = 7°48′ |
| 4 | 这个角是 30°，余角是 60° |
| 5 | 从所说的一方，向偏的一方转过指定的度数 |
| 6 | 时针 30°/时，分针 6°/分；3 时 25 分夹角 47.5° |
| 7 | 角 AOB = 角 COD，都等于 90° 减去角 BOC |
| 8 | 角 AOB = 140° |
| 9 | 38° 或 102°，要看 OC 画在哪一侧 |
| 15 | 按同一方向取的这些角，和总是 360° |
