# 6.3.3 余角和补角

> **改编自：** 人教版《义务教育教科书·数学》七年级上册 第六章 6.3.3。上一课是 [6.3.2 角的比较与运算](./angle-comparison)。

一副三角尺里，每个三角尺都有一个 90° 的角，另外两个角的和也是 90°：30° + 60° = 90°，45° + 45° = 90°。

如果两个角的和等于 90°（直角），就说这两个角互为**余角**（complementary angle），简称这两个角互余。其中一个角是另一个角的余角。

如果两个角的和等于 180°（平角），就说这两个角互为**补角**（supplementary angle），简称这两个角互补。其中一个角是另一个角的补角。

![图 6.3-13、图 6.3-14 互余与互补](/img/math-6-3-3-complement-supplement.png)

图 6.3-13 中，角 1 与角 2 拼成直角，所以互余。图 6.3-14 中，角 3 与角 4 拼成平角，所以互补。

### 思考

角 1 与角 2、角 3 都互为余角。角 2 与角 3 的大小有什么关系？

因为角 2 = 90° − 角 1，角 3 = 90° − 角 1，所以角 2 = 角 3。由此得到：

**同角（或等角）的余角相等。**

补角也有同样的性质：

**同角（或等角）的补角相等。**

说明：若角 2 与角 3 都是角 1 的补角，则角 2 = 180° − 角 1，角 3 = 180° − 角 1，所以角 2 = 角 3。

## 小结

| 概念 | 含义 |
| --- | --- |
| 余角 | 两个角的和是 90° |
| 补角 | 两个角的和是 180° |
| 同角的余角 | 相等 |
| 同角的补角 | 相等 |
| 例 4 | 平角被两条平分线各取一半后，邻着顶点 C 的两半互余 |
