# 阅读与思考：初步认识数学模型

> **改编自：** 人教版七年级上册 第五章「阅读与思考」与随后的「数学活动」。先认识模型与方程，再用阶梯计价、杠杆平衡练习「抽象成方程 → 求解 → 回到实际」。

什么是模型呢？模型可以是按照一定比例缩小的实物，如建筑模型、船舶模型；也可以是从实际问题抽象出的数学式子或计算机程序。常见的有物理模型、数学模型、生物模型、计算机仿真模型等。

建立模型通常是为了用比较简单的方法去描述现实：通过研究**简化了的模型**，来把握现实世界的本质或规律。

具体到**数学模型**，就是要抽象出现实世界中事物或因素之间的关系，然后用数学来表示。常见形式有：

| 表示方式 | 例子 |
| --- | --- |
| 数学表达式 | 等式、不等式（数字、字母和符号组成） |
| 表格 | 两款空调的售价与年耗电量 |
| 图象 | 综合费用随使用年数变化的直线 |
| 框图 | 「设 → 列 → 解 → 检 → 答」 |
| 计算机程序 | 把同一套关系写成可反复计算的程序 |

## 方程是一类常见的数学模型

从初等数学里简单的代数方程（如一元一次方程），到高等数学中复杂的微分方程、积分方程，无论类型如何变化，方程模型本质上表示的都是一种**相等关系**：方程两边的式子，是对同一个事物从不同角度或不同方面的刻画。

因此，用方程模型解决现实问题时，关键是分析并找到现实问题中蕴含的相等关系。例如：

- 桌面木材与桌腿木材「刚好配成桌子」——两边件数配套；
- 降价后的「单价 × 销量」等于原来的销售总金额；
- 丢番图墓碑上各段年龄加起来等于他的寿命。

这些题的数字可以不同，模型结构是同一类。前面几课的练习，其实都是在建立并求解方程模型。

## 用数学模型解决实际问题的基本过程

我们已经知道如何利用一元一次方程解决实际问题。这个过程，也就是建立数学模型的基本过程：

1. **构造数学模型**  
   分析实际问题，明确其中蕴含的关系或规律，必要时作合理假设，把实际问题抽象成数学问题（数学模型）。

2. **求解数学模型**  
   解决数学问题本身——例如解出一个未知数，或找出两个一次式相等的交点。

3. **用数学结论解释实际问题**  
   结合实际意义检验解是否合理（必须是正数、必须是整数、必须落在题目规定的范围内……）。有时还要改进模型，才能得到真正能用的答案。

:::tip 和「设 → 列 → 解 → 检 → 答」对照
- **设、列**：构造模型（假设 + 抽象出相等关系）
- **解**：求解模型
- **检、答**：回到实际，检验并解释
:::

空调综合费用就是一个完整例子：先假设电价不变、年耗电量稳定，写出 $C = \text{售价} + \text{年电费}\times t$；再令两款费用相等求出交点；最后用「安全使用年限大约 10 年」解释：通常用超过 5 年，所以 1 级更划算。离开「年限」这个实际条件，单纯的方程解 $t=5$ 并不能单独回答「买哪款」。

### 活动 2：木杆挂重物问题

用一根质地均匀的木杆和一些等重的小物体，做下面的实验：

1. 在木杆中间处拴绳，将木杆吊起并使其左右平衡，吊绳处为木杆的支点；
2. 在木杆两端各悬挂一重物，看看左右是否保持平衡；
3. 在木杆左端小物体下加挂一重物，然后把这两个重物一起向右移动，直至左右平衡，记录此时支点与木杆左右两边挂重物处的距离；
4. 在木杆左端两小物体下再加挂一重物，然后把这三个重物一起向右移动，直至左右平衡，再记录距离；
5. 在木杆左边继续加挂重物，并重复以上操作和记录。

根据记录可以发现：左边重物个数与它到支点的距离的乘积保持不变，等于支点到右端的距离。

如图：木杆右端挂 1 个重物，支点左边挂 $n$ 个重物，并使左右平衡。设木杆长为 $l$ cm，支点在中点，支点与左边挂重物处的距离为 $x$ cm。把 $n$、$l$ 作为已知数，列出关于 $x$ 的一元一次方程。

## 小结

| 概念 | 含义 |
| --- | --- |
| 模型 | 用简化方式描述现实，便于研究本质或规律 |
| 数学模型 | 用表达式、表格、图象、框图或程序表示因素之间的关系 |
| 方程模型 | 用相等关系刻画同一事物的两个侧面 |
| 建模过程 | 抽象成数学问题 → 求解 → 结合实际检验并解释 |
