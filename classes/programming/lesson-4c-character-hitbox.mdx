本课用内置角色 **布鲁瑟（Brucer）** 的精灵表。你**不用画图**，需要完成：

1. **属性赠点**：在「待机 / 移动 / 跳跃」用 **＋/−** 分配 5 点（含跳跃高度、跳跃/攻击耗耐；减则退点）  
2. **体型**：在「待机」里对照剑士（Kenji）调整 **尺寸倍率**（可为小数，如 0.75），避免角色过大  
3. **伤害帧**：哪一帧真正打中对手（攻击 1 / 攻击 2）  
4. **伤害盒**：这一帧上覆盖「拳头 / 脚 / 刀光」的红色矩形  

下一课（4d）会复用同一组件，换成 **侠客** 精灵表，并支持 **三段攻击**。

## 体型（待机）

对照右侧剑士身高。自动对齐 200×200 后，用 **尺寸倍率**（0.40～1.20，可为 0.75 这类小数）再缩小。  
超过 100% 会标红——把倍率调低。

## 属性赠点

从游戏 **基础角色** 数值起步（生命 / 耐力 / 移速 / 恢复 / 攻击 / 跳跃 / 耗耐）。  
共 **5 点**可赠。**＋** 加强（耗耐项是变便宜）；**−** 可降到基础以下（最低 −3），多出的点可投到别的项。

## 保存

- **新名字** → 新建角色（进入游戏选人列表）  
- **已有名字** → 覆盖该角色  
- 不能覆盖经典 **武士** / **剑士**

## 怎么找伤害帧？

切到 **攻击 1 / 攻击 2**，播放或拖动「浏览帧」，看哪一帧攻击动作最完整。  
点 **将本帧设为伤害帧**。两次攻击都要各设一次。

## 怎么画伤害盒？

在预览画布上**拖拽**画出红色框，或用右侧滑条微调。  
框只要盖住会打到人的部位，不要框住整个人。

## 检查清单

- [ ] 保存（新名字=新建；同名=覆盖；不能覆盖武士/剑士）  
- [ ] 攻击 1：伤害帧 + 伤害盒  
- [ ] 攻击 2：伤害帧 + 伤害盒  
- [ ] 点「试玩」进训练场
