# 第 3 课 — 像素背景与站位线（tracks）

这节课你要为自己的对战地图做两件事：

1. **画 / 导出一张背景 PNG**
2. **定 track（站位线）** —— 角色脚站在哪一条水平线上

完成后把关卡上传到班级库，大家都能在格斗游戏里选用。

## 目标尺寸

| 项目 | 建议 |
| --- | --- |
| 画布 | **1024 × 576**（与游戏窗口一致） |
| 格式 | **PNG**（可透明，但单层背景一般不需要） |
| 风格 | 像素风更稳；避免过亮的纯白地面 |

## Track 是什么？

游戏里角色有一条（或两条）**地板 Y 坐标**：

- **1 track**：所有人站在同一层地面（最常见）
- **2 tracks**：前后两条道（像 Arena），可用 Shift 换道

Y 越大越靠画面下方。常见地面大约在 **300–400**。

下面的工作室里可以拖动滑条，黄/蓝线就是 track 预览。

## 步骤

1. 用 Aseprite / LibreSprite / Piskel 等画好背景，导出 PNG  
2. 设置齿轮登录为 **编程** 班学生  
3. 在下面上传：起名 → 选 PNG → 调 track → **Upload stage**  
4. 点 **Open in game**，选角色开打试站位  

后端离线时仍可玩内置地图；上传需要 Spring + 文件服务在线。
