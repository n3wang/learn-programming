单张背景（4b）整图一起跟着镜头走。**视差（parallax）** 把场景拆成多层：远景滚得慢、近景跟镜头，走起来更有纵深。

游戏里内置的 **小镇 / 森林** 就是三层宽图（`3072 × 576`）。

## 三层含义

| 层 | 角色 | 滚动 |
| --- | --- | --- |
| **z3 远景** | 天空、远山 | 最慢 |
| **z2 中景** | 树木、建筑 | 中速 |
| **z1 近景** | 地面站位层 | 跟镜头 |

## 画图约定

1. 打开 [Piskel](https://www.piskelapp.com/p/create/sprite/)（或其它像素编辑器）  
2. 尺寸建议：**宽 3072、高 576**（比画布 1024 更宽，才能左右走并看出视差）  
3. **分三张图**画：远 / 中 / 近；近景底部留出地面，方便调站位 Y  
4. 导出三张 PNG  

也可以先下载下方工坊里的 **小镇模板**（z3 / z2 / z1），改色或改造型后再上传。

## 上传与试玩

1. 学生身份登录（导航栏设置齿轮）  
2. 在工坊里上传 **z3 → z2 → z1**，起名，调站位 Y  
3. 「上传视差关卡」→ 班级画廊里 **打开**，左右移动看远近是否错开  

离线时无法上传，但仍可在游戏选关里玩内置小镇 / 森林看效果。

## 检查清单

- [ ] 三张宽图（模板或自创）已上传
