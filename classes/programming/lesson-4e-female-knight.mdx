本课用角色包 **女骑士（female_hero_knight）**，复用与 4c / 4d **同一套编辑器**。  
编辑器里一开始**没有图**。

1. 在编辑器**上方**的「素材下载」里，按动作点 **下载 …**  
2. 切到对应标签，只会出现 **上传** → 选刚下的 PNG  
3. 有图之后才能 **播放**、调帧、画伤害盒  


## 动作对照


上传后帧数按 宽度 ÷ 180 自动计算。

## 还要完成

1. **属性赠点**（待机 / 移动 / 跳跃）  
2. **体型**（待机对照剑士）  
3. **攻击 1 / 2**：伤害帧 + 伤害盒  
4. **保存**并试玩  

未全部上传前，保存 / 试玩会被拦住。

下一课（4f）同样先下载素材，再给 **武士 Mack** **换色**（例如蓝色）后上传。

## 检查清单

- [ ] 上方素材区八个都已下载，并上传进对应标签  
- [ ] 攻击 1：伤害帧 + 伤害盒  
- [ ] 攻击 2：伤害帧 + 伤害盒  
- [ ] 保存并「试玩」
