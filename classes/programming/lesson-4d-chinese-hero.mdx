本课用内置角色 **侠客（chinese_hero）** 的精灵表，复用与 4c **同一套编辑器**。  
你**不用画图**，需要完成：

1. **属性赠点**：在「待机 / 移动 / 跳跃」用 **＋/−** 分配 5 点  
2. **体型**：在「待机」对照剑士调整 **尺寸倍率**  
3. **三段攻击**：为 **攻击 1 / 2 / 3** 各设伤害帧与伤害盒  
4. **保存**后进训练场连按攻击，确认 1→2→3 衔接

与 4c 的差别：本角有 **三次攻击**（连段第三下伤害更高），精灵格为 **126×126**。

下一课（4e）同样用本编辑器，但精灵表需 **自行下载并上传**。

## 保存

- **新名字** → 新建角色  
- **已有名字** → 覆盖该角色  
- 不能覆盖经典 **武士** / **剑士**

## 检查清单

- [ ] 攻击 1：伤害帧 + 伤害盒  
- [ ] 攻击 2：伤害帧 + 伤害盒  
- [ ] 攻击 3：伤害帧 + 伤害盒  
- [ ] 保存并「试玩」连打三段
