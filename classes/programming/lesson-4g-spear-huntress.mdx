本课用 **女猎手（spear_huntress）** 作为起步模板，复用与 4c–4f **同一套编辑器**。  
编辑器一开始**没有图**。你可以：

- **走模板**：上方下载女猎手八张表 → 可改画 / 换色 → 上传  
- **完全自创**：用 [Piskel](https://www.piskelapp.com/p/create/sprite/) 等画自己的横向精灵表，再上传（格尺寸由**待机**那张的高度自动锁定）

## 精灵表约定

| 要求 | 说明 |
| --- | --- |
| 格式 | PNG，透明底 |
| 布局 | **横向**一排帧（Idle / Run / … 各一张表） |
| 格子 | **正方形**：高 = 一格边长；帧数 = 宽 ÷ 高 |
| 女猎手默认 | 格 **150×150**（Idle·Run·Death 8 帧 / Jump·Fall 2 / Attack1·2 5 / 受击 3） |

自创时先上传 **待机**，再传其它动作（其它表请与待机同一格边长）。

## 步骤（模板路径）

1. 上方「素材下载」→ 下载各动作 PNG  
2. （可选）在像素编辑器里改色 / 改造型  
3. 切到对应标签 → **上传**  
4. 有图后再 **播放**、调伤害帧与伤害盒  

## 还要完成

1. **属性赠点**（待机 / 移动 / 跳跃）  
2. **体型**（待机对照剑士）  
3. **攻击 1 / 2**：伤害帧 + 伤害盒  
4. 用**新名字**保存（不能覆盖 **武士** / **剑士**）并「试玩」  

未全部上传前，保存 / 试玩会被拦住。

## 检查清单

- [ ] 八个标签都已上传（模板或自创）  
- [ ] 攻击 1：伤害帧 + 伤害盒  
- [ ] 攻击 2：伤害帧 + 伤害盒  
- [ ] 新名字保存并「试玩」
