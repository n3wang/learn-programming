## Your first GDScript

Every sandbox script starts the same way: extend `SceneTree`, put code in `_init()`, then `quit()`.

```python
extends SceneTree

func _init():
    print("Hello Godot")
    quit()
```

## Printing

`print` writes to the output. Strings use double quotes. You can print several values in one call.

```python
print("score", 12)
print("a", "b", "c")
```

<summary>🧪 Try it</summary>

## Comments

`#` starts a comment to the end of the line.

```python
# This is a comment
print("still runs")  # trailing comment
```
