## Area2D vs bodies

| Node | Collides / blocks? | Typical use |
|---|---|---|
| `CharacterBody2D` / `RigidBody2D` | Solid (in real physics) | Walking, falling crates |
| `Area2D` | Detection only | Pickups, hurtboxes, triggers |

In the kit, `Area2DMock` (`Kit.make_area`) checks **circle overlap**. Detection is **one-way** like Godot: the area’s `collision_mask` must include the body’s `collision_layer` (the body does not need to “see” the area).

```python
var Kit = preload("res://game_kit.gd")
var hero = Kit.make_character(Vector2(0, 0))
var coin = Kit.make_area(Vector2(10, 0), 8.0)
print(coin.overlaps_body(hero))
```

## Collision layers and masks

Godot uses **bitmasks**:

- `collision_layer` — which layers this object **lives on**
- `collision_mask` — which layers it **looks for**

A **solid** body pair interacts only if both see each other:

```text
(A.mask & B.layer) != 0  AND  (B.mask & A.layer) != 0
```

An **Area2D** detecting a body only needs:

```text
(area.mask & body.layer) != 0
```

Kit helpers: `area.overlaps_body(body)`, `body.can_collide_with(other)`, `Kit.bodies_overlap(a, b)`.
