## Variables

Use `var` to store a value. Type annotations are optional but helpful in game code where `hp` should stay an `int`.

```python
var score = 10
var name: String = "Ada"
var ready: bool = true
```

You can reassign a `var`. That is how combat updates HP and inventory changes.

```python
var hp = 20
hp = hp - 5
hp -= 2  # same idea, shorter
```

## Common types

| Type | Example |
|---|---|
| `int` | `42` |
| `float` | `3.14` |
| `bool` | `true` / `false` |
| `String` | `"hello"` |

`str(x)` turns a value into a string. `%` formatting works like older Python — useful for HUD labels:

```python
var hp = 7
print("HP: %s" % hp)
print("%s has %s coins" % ["Ada", 3])
```

You can also build strings with `+` after converting numbers:

```python
var coins = 15
print("coins=" + str(coins))
```

## Constants

`const` values cannot be reassigned — good for caps like max HP or inventory slots.

```python
const MAX_HP := 100
```

`:=` infers the type from the value.
