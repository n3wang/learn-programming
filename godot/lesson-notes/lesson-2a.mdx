## Variables

Use `var` to store a value. Type annotations are optional but helpful.

```gdscript
var score = 10
var name: String = "Ada"
var ready: bool = true
```

## Common types

| Type | Example |
|---|---|
| `int` | `42` |
| `float` | `3.14` |
| `bool` | `true` / `false` |
| `String` | `"hello"` |

`str(x)` turns a value into a string. `%` formatting works like older Python:

```gdscript
var hp = 7
print("HP: %s" % hp)
print("%s has %s coins" % ["Ada", 3])
```

## Constants

`const` values cannot be reassigned.

```gdscript
const MAX_HP := 100
```

`:=` infers the type from the value.
