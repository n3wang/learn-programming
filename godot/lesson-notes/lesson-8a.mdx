## Put the pieces together

You now have:

- **Vector2** — real engine math
- **Player / Enemy** — simple actors
- **CharacterBody / RigidBody / StaticBody** — movement styles
- **Area2D** — triggers and pickups

This chapter is a short **arena** loop using the kit only (still mocked — no editor scene).

```python
var Kit = preload("res://game_kit.gd")
var game = Kit.make_game()
var foe = game.spawn_enemy(Vector2(80, 0))
var goal = Kit.make_area(Vector2(120, 0), 12.0)
# move, chase, check overlaps…
```

## Challenge: one chase step

Spawn an enemy at `x=100`, set its `speed = 25`, call `game.tick(1)`, print `int(enemy.position.x)`.

Player stays at origin. After one second of chasing toward the player, x should be `75`.

```
75
```

  heading="Challenge: one chase step"

<Exercise title="Kite the slime" anchor="exercise-kite-slime">

:::tip Activity: Kite the slime
Player at origin, `speed = 50`. Enemy at `(0, 0)` initially… wait — spawn at `Vector2(0, 80)` with `speed = 10`.

1. Move the player with `move(Vector2.RIGHT, 1)` (speed 50 → x becomes 50)
2. `game.tick(1)` so the slime chases one second
3. Print `true` if the slime is still **farther than 40** from the player (`not Kit.near(...)`)

After the tick, slime moves toward the new player position. Check distance carefully — print `true` when `not near(..., 40)`.

```
true
```
