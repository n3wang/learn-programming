## Records with dictionaries

A **dictionary** stores named fields — useful for items, enemies, and save data without writing a full class yet.

```python
var slime = {"name": "Slime", "hp": 30, "atk": 5}
print(slime["name"])
print(slime.hp)       # same field, dot form
slime.hp -= 10
print(slime.hp)
```

## Classes — fields and methods

A **class** groups data and functions that belong together. Methods are functions on the instance; they use `self` implicitly for fields.

```python
class Hero extends RefCounted:
    var name: String = "Ada"
    var hp: int = 20

    func take_hit(dmg: int) -> int:
        hp = maxi(0, hp - dmg)
        return hp

var h = Hero.new()
h.take_hit(7)
print(h.hp)  # 13
```

## Iterating over collections

Combine `for` with arrays of dicts or objects. Each pass binds one element.

```python
var party = [
    {"name": "Ada", "hp": 12},
    {"name": "Lin", "hp": 0},
    {"name": "Sam", "hp": 8},
]
var alive = 0
for member in party:
    if member.hp > 0:
        alive += 1
print(alive)  # 2
```

## Challenge: party HP total

Write `total_hp(party)` so it returns the sum of every member's `hp`.  
Each member is a dictionary with an `"hp"` field. Use a loop — do not hard-code a single sum.

Hidden tests send space-separated HP values; the wrap builds the party dicts for you.

Indent with **4 spaces**. Click **Reset** if an old draft looks flat.
:::
