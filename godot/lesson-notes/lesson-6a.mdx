## Body types in Godot 2D

In a real project you pick a **physics body** for how something should move:

| Godot class | Role | Kit mock |
|---|---|---|
| `CharacterBody2D` | Player / NPCs you move in code | `Kit.CharacterBody` / `make_character` |
| `StaticBody2D` | Walls, floors — never pushed | `Kit.StaticBody` / `make_static` |
| `RigidBody2D` | Boxes, barrels — engine integrates forces | `Kit.RigidBody` / `make_rigid` |

This sandbox has **no physics server**. The kit mocks share the same *ideas* (velocity, gravity, `move_and_slide`) so you can practice the APIs.

```python
var Kit = preload("res://game_kit.gd")
var hero = Kit.make_character(Vector2(0, 0), 0.0)  # floor at y=0
hero.velocity = Vector2(50, 0)
hero.move_and_slide(1.0)
print(hero.position, hero.is_on_floor())
```

## CharacterBody: velocity then slide

Pattern (same as Godot tutorials):

1. Set `velocity` (from input, AI, knockback)
2. Optionally `apply_gravity(delta)`
3. Call `move_and_slide(delta)`

Jump only works when `is_on_floor()` is true.

## StaticBody vs RigidBody

**Static** ignores velocity — good for platforms.

**Rigid** integrates gravity each `integrate(delta)` and can take `apply_impulse`.

<details>
<summary>🧪 Drop a rigid box</summary>

<PistonRunner
  lang="godot"
  filename="main.gd"
  height="320px"
  code={[
    'extends SceneTree',
    '',
    'func _init():',
    '    var Kit = preload("res://game_kit.gd")',
    '    var box = Kit.make_rigid(Vector2(0, -10), 1.0)',
    '    box.gravity = 10',
    '    box.integrate(1.0)',
    '    print(box.position.y > -10)',
    '    print(box.velocity.y > 0)',
    '    var wall = Kit.make_static(Vector2(0, 0))',

## Challenge: one second walk

Make a character on floor `y=0`, set `velocity = Vector2(25, 0)`, call `move_and_slide(1)`, print `int(position.x)`.

Expected: `25`.
