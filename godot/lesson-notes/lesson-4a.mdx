## Arrays

Arrays hold ordered values. Index from `0`.

```gdscript
var items = ["sword", "shield", "potion"]
print(items[0])
print(items.size())
items.append("key")
```

## for loops

`for x in collection` walks each element. `range(n)` counts `0 .. n-1`.

```gdscript
for i in range(3):
	print(i)

for name in ["Ada", "Lin"]:
	print(name)
```

## while loops
