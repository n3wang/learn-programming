## Why functions

A **function** packages a piece of work behind a name. Game code calls the same ideas often — damage, healing, formatting a HUD line — so you write them once and reuse them.

```python
func double(n: int) -> int:
    return n * 2

print(double(7))  # 14
```

## Anatomy

```python
func name(param: Type) -> ReturnType:
    # body
    return value
```

| Piece | Role |
|---|---|
| `func` | Starts a function |
| parameters | Inputs the caller passes in |
| `-> Type` | Optional return type (recommended in lessons) |
| `return` | Sends a result back to the caller |

Call a function with parentheses: `double(7)`. Without `()`, you only mention the function — you do not run it.

## Multiple parameters and defaults

Pass several values, separated by commas. Default arguments fill in when the caller omits them.

```python
func heal(hp: int, amount: int = 5, max_hp: int = 100) -> int:
    return mini(max_hp, hp + amount)

print(heal(90))        # 95 — amount defaults to 5
print(heal(90, 20))    # 100 — capped by max_hp
```

## Functions calling functions

Small helpers compose. Keep each function focused — one job is easier to test.

```python
func armor_block(dmg: int, armor: int) -> int:
    return maxi(0, dmg - armor)

func apply_hit(hp: int, dmg: int, armor: int) -> int:
    return maxi(0, hp - armor_block(dmg, armor))
```

## Challenge: apply hit

Write `apply_hit(hp, dmg, armor)` so it:

1. Reduces damage by `armor` (damage cannot go below `0`)
2. Subtracts that from `hp` (`hp` cannot go below `0`)
3. Returns the new HP

Example: `hp=20`, `dmg=8`, `armor=3` → blocked damage is `5` → result `15`.

Indent with **4 spaces**. Click **Reset** if an old draft looks flat.
:::
