## if / elif / else

Branch with `if`, `elif`, and `else`. Conditions are boolean expressions.

```python
var hp = 3
if hp <= 0:
    print("down")
elif hp < 5:
    print("low")
else:
    print("ok")
```

## Comparison operators

| Op | Meaning |
|---|---|
| `==` | equal |
| `!=` | not equal |
| `<` `<=` `>` `>=` | ordering |
| `and` `or` `not` | boolean logic |

```python
var alive = hp > 0 and not stunned
```

## Challenge: grade letter

Write `letter(score)` so it returns:

- `"A"` if score ≥ 90
- `"B"` if score ≥ 80
- `"C"` otherwise

Hidden tests call your function with different scores.

Indent with **4 spaces**. Click **Reset** if an old draft looks flat.
:::
