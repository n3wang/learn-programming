# MatPlot Studio

After [MatPlot Detective](./matplot-detective) and [MatPlot 3D Detective](./matplot3d-detective). This set is the **figure window**: zoom, save, print, menu options, subplot spacing, 3D rotate/scale, then the sliding-box beam.

改几乎写好的代码，再改一版，最后从核心自己画。 Open the **Data** tab — those arrays are loaded on Run.

This sandbox is Agg (no GUI). Map the window to code:

| Window | Code |
| --- | --- |
| Zoom in / out | `xlim` / `ylim` |
| File → Save | `savefig` (`png`, `pdf`, `svg`, `eps`) |
| File → Print | `savefig` (`pdf`, `ps`) |
| Grid / legend / layout | `grid`, `legend`, `tight_layout` |
| More space between plots | `subplots_adjust(hspace=..., wspace=...)` |
| Rotate / scale a surface | `view_init(elev, azim)`, `set_box_aspect` / `set_zlim` |

Beam (Landau-style): length `L = 10` m, weight `W = 400` N, supports `d = 2` m apart, box `Wb = 800` N starts above the left support and slides right at `v = 7` m/s.

- Put left support **A at 0**, right support **B at d**. Vertical force balance plus torque about A.
- Three supports: add **C at L**. Teaching model — the box is carried only by the two supports of the span it is on (lever rule). Split the beam weight at B: 80 N on AB (40 N each end) and 320 N on BC (160 N each end).
