`break` leaves a loop immediately.

```python
for i in range(100):
    print(i)
    if i == 3:
        break
```

## Challenge: stop at eight

Write `up_to_stop(stop)` so it prints `0` then `1` then ... then `stop`, each on its own line, then stops (do not print numbers after `stop`).

Expected for `2`:
```
0
1
2
```

<CodeExercise
  title="stop at eight"
  heading="Challenge: stop at eight"
  lang="python"
  filename="main.py"
  prompt="Print 0 through stop inclusive, then break."
  sampleLog={`(input) 2
0
1
2`}
  starter={`def up_to_stop(stop):
    for i in range(100):
        print(i)
        # TODO: break when i == stop
        pass
`}
  wrapSuffix={`
up_to_stop(int(input()))
`}
  tests={[
    { name: 'stop 2', stdin: '2', equals: '0\n1\n2' },
    { name: 'stop 0', stdin: '0', equals: '0' },
  ]}
/>

:::tip Activity: Find yes
You search tunnels. Each answer is `yes` or `no` on one line (space-separated).
Write `tunnels_until_yes(words)` so it returns how many tunnels you entered **including** the one with `yes`. If there is no `yes`, return the length of the list.

<CodeExercise
  title="Find yes"
  heading="exercise-find-yes"
  lang="python"
  filename="main.py"
  prompt="Count items until yes (inclusive)."
  sampleLog={`(input) no no yes no
3`}
  starter={`def tunnels_until_yes(words):
    count = 0
    for w in words:
        count = count + 1
        # TODO: if w == "yes": break
    return count
`}
  wrapSuffix={`
words = input().split()
print(tunnels_until_yes(words))
`}
  tests={[
    { name: 'yes third', stdin: 'no no yes no', equals: '3' },
    { name: 'yes first', stdin: 'yes no', equals: '1' },
