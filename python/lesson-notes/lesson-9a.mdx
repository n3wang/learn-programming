A **function** is a named block you can call. `def` defines it. `return` sends a value back to the caller.

```python
def greet(name):
    return "Hello, " + name

print(greet("Ada"))
```

## Parameters and return

Arguments fill parameters when you call the function. If you `print` inside the function, that is a **side effect**. Prefer `return` when you need a value for later math or tests.

```python
def add(a, b):
    return a + b

total = add(3, 5)
print(total)
```

## Default arguments and local variables

```python
def greet(name, punctuation="!"):
    return "Hi " + name + punctuation

print(greet("Lin"))
print(greet("Lin", "?"))
```

Variables created **inside** a function are local. They disappear when the function ends.
