This page is a **lab**, not a student chapter. It checks three ways to “chart” on Piston:

1. **Pandas tables** (already fast)
2. **ASCII bars** (testable, no image)
3. **matplotlib PNG** (needs longer CPU time + a `PISTON_PNG:` line)
4. **seaborn** (same PNG trick; seaborn sits on matplotlib)

Run with **batch mode** (`interactive` off) so the full PNG arrives in one response.

Print a PNG like this:

```python
print("PISTON_PNG:" + base64.b64encode(png_bytes).decode("ascii"))
```

The runner hides that line and shows the image.

Graded exams can check this output. No matplotlib.

  lang="python"
  interactive={false}

df = pd.DataFrame({"name": ["a", "b", "c"], "n": [3, 1, 5]})

def ascii_bars(frame, name_col, n_col):
    for _, row in frame.iterrows():
        print(str(row[name_col]), "#" * int(row[n_col]))

ascii_bars(df, "name", "n")
`}

## 3. matplotlib PNG

Uses Agg (no window). First import is slow; Piston CPU/time was raised for this.

<PistonRunner
  lang="python"
  interactive={false}
  height="360px"
  runTimeout={20000}
  runCpuTime={15000}
  code={`import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import pandas as pd
import base64
from io import BytesIO

df = pd.DataFrame({"x": [1, 2, 3, 4], "y": [2, 5, 3, 8]})
fig, ax = plt.subplots(figsize=(4, 2.5))
ax.bar(df["x"], df["y"], color="#5b6abf")
ax.set_title("sales")
ax.set_xlabel("day")
ax.set_ylabel("count")
fig.tight_layout()

buf = BytesIO()
fig.savefig(buf, format="png", dpi=90)
plt.close(fig)
print("rows", len(df))
print("PISTON_PNG:" + base64.b64encode(buf.getvalue()).decode("ascii"))
`}
/>

## 4. seaborn PNG

Same Agg backend. `sns.set_theme()` then a barplot.

<PistonRunner
  lang="python"
  interactive={false}
  height="380px"
  runTimeout={20000}
  runCpuTime={15000}
  code={`import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd
import base64
from io import BytesIO

sns.set_theme(style="whitegrid")
df = pd.DataFrame({
    "day": ["Mon", "Tue", "Wed", "Thu"],
    "sold": [4, 7, 3, 8],
})
fig, ax = plt.subplots(figsize=(4.2, 2.6))
sns.barplot(data=df, x="day", y="sold", ax=ax, color="#3d9b8f")
ax.set_title("seaborn barplot")
fig.tight_layout()

buf = BytesIO()
fig.savefig(buf, format="png", dpi=90)
plt.close(fig)
print("seaborn", sns.__version__)
print("PISTON_PNG:" + base64.b64encode(buf.getvalue()).decode("ascii"))
`}
/>
