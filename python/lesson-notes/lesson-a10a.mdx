You will build a **text Space Invaders**: a 2D grid printed each turn. That is the version that runs in this site’s Python sandbox.

## Why not pygame?

Piston runs Python **without a window**. There is no display, mouse, or speaker.

| Approach | Works here? | Notes |
|---|---|---|
| `pygame`, `turtle` window, OpenGL | No | Need a real screen / framebuffer |
| Pillow drawing PNGs | Possible later | Would need extra packages **and** a page that shows images |
| **ASCII grid + `print`** | Yes | Same idea as arcade: a 2D board, a player, aliens, a game loop |

So the “rendering library” is a handful of functions that fill a list-of-lists and print it. You already have lists and functions from chapters 8 and 9.

## A tiny draw library

A **cell** is one character. A **frame** is a rectangle of cells.

```python
EMPTY = "."
PLAYER = "A"
ALIEN = "M"
SHOT = "|"

def make_board(rows, cols):
    return [[EMPTY] * cols for _ in range(rows)]

def put(board, row, col, ch):
    if 0 <= row < len(board) and 0 <= col < len(board[0]):
        board[row][col] = ch

def draw(board):
    for row in board:
        print("".join(row))
```

## Game loop (one command per frame)

Each line of input is a command: `L` move left, `R` move right, `S` shoot (we will grade movement first).

```text
.....M.....
...........
...........
.....A.....
```

Player starts at the bottom, middle.

## Going further (optional)

If you later want **pixels**, options are:

1. **Keep ASCII** and add colors with ANSI codes in a real terminal (not required here).
2. **Bake Pillow into the Piston Python image** (`pip install pillow` at **package build** time) and print a base64 PNG — then a small site component could display it.
3. **Browser game** in JavaScript/canvas, with Python only scoring logic.

For class, stay on the grid: it is the same architecture as the arcade game (state, input, collide, redraw).
