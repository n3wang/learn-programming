A **list** is an ordered collection. Use square brackets. Indexing starts at `0`.

```python
scores = [90, 85, 100]
names = ["Ada", "Lin", "Grace"]
mixed = [1, "two", True]
empty = []
```

## Indexing and slicing

| Expression | Meaning |
|---|---|
| `items[0]` | First element |
| `items[-1]` | Last element |
| `items[1:3]` | From index 1 up to (not including) 3 |
| `len(items)` | How many elements |

## Changing a list

Common methods:

| Method | Effect |
|---|---|
| `items.append(x)` | Add `x` at the end |
| `items.pop()` | Remove and return the last item |
| `items.insert(i, x)` | Put `x` at index `i` |
| `items[i] = x` | Replace the value at index `i` |

## Looping through a list

```python
for item in names:
    print(item)

for i in range(len(names)):
    print(i, names[i])
```
