# 计算机工程

本模块深入介绍计算机工作的底层原理——从晶体管到操作系统。

理解这些知识能让你成为更优秀的工程师：写出更快的代码、清晰分析性能瓶颈，并理解系统行为背后的原因。

## 主题

| 主题 | 学习内容 |
|------|---------|
| [CPU 流水线阶段](./lesson-notes/cpu-pipeline) | 现代 CPU 如何通过流水线提升指令执行吞吐量 |
| [缓存层次结构](./lesson-notes/cache-hierarchy) | 内存延迟为何相差 10 万倍，以及 CPU 如何隐藏这一差距 |
| [分支预测](./lesson-notes/branch-prediction) | CPU 在知晓跳转路径之前如何推测性地取指 |

## 预备知识

- 对二进制 / 十六进制数有基本了解
- 熟悉任意编程语言中的变量和循环

无需先修硬件或汇编课程，所有页面均配有交互式模拟器。
