# Calculating the Determinant (Kraut method)

**Kraut** (often spelled **Crout**; CP-Algorithms uses “Kraut”) computes an **LU factorization** `A = L U` in **`O(N³)`**, then reads off

```text
det(A) = Πᵢ Uᵢᵢ
```

when `L` has a unit diagonal. This lesson follows [CP-Algorithms — Determinant (Kraut)](https://cp-algorithms.com/linear_algebra/determinant-kraut.html).

## Idea

- `L` = lower triangular, **`Lᵢᵢ = 1`**
- `U` = upper triangular
- `det(L) = 1`, so `det(A) = det(L)·det(U) = det(U) = product of diag(U)`

An invertible matrix has a unique LU factorization of this form **iff all leading principal minors are nonzero**. If a pivot `Uⱼⱼ` hits zero, you need **row pivoting** (partial pivoting) and must track the sign of each swap.

## Formulas

For each column `j = 1 … N` (1-based):

1. For `i = 1 … j`:

```text
Uᵢⱼ = Aᵢⱼ − Σ_{k=1}^{i−1} Lᵢₖ · Uₖⱼ
```

2. For `i = j+1 … N`:

```text
Lᵢⱼ = (1 / Uⱼⱼ) · ( Aᵢⱼ − Σ_{k=1}^{j−1} Lᵢₖ · Uₖⱼ )
```

Same formulas, 0-based, appear in the simulator and C++ demo.

## Compact storage & pivoting

In practice one matrix overwrites `A`:

- upper triangle (incl. diagonal) → `U`
- strict lower triangle → multipliers `Lᵢⱼ` (`L` diagonal stays implicit 1s)

The Java snippet on CP-Algorithms also:

- scales rows for pivot selection
- swaps rows for the largest scaled residual (`imax`)
- flips `sign` on each swap
- returns `sign · Π aᵢᵢ` rounded to an integer

Without pivoting the algorithm can fail or lose precision even when `det(A) ≠ 0`.

## Tiny instance

```text
A = [[ 2,  1, 1],
     [ 4, −6, 0],
     [−2,  7, 2]]
```

```text
L = [[ 1,  0, 0],
     [ 2,  1, 0],
     [−1, −1, 1]]

U = [[ 2,  1,  1],
     [ 0, −8, −2],
     [ 0,  0,  1]]
```

`det(A) = 2 · (−8) · 1 = −16`.

  code={`#include <iostream>
#include <vector>
#include <iomanip>
using namespace std;

int main() {
    const int N = 3;
    vector<vector<double>> A = {
        {2, 1, 1},
        {4, -6, 0},
        {-2, 7, 2}
    };
    vector<vector<double>> L(N, vector<double>(N, 0));
    vector<vector<double>> U(N, vector<double>(N, 0));
    for (int i = 0; i < N; i++) L[i][i] = 1;

    for (int j = 0; j < N; j++) {
        for (int i = 0; i <= j; i++) {
            double sum = 0;
            for (int k = 0; k < i; k++) sum += L[i][k] * U[k][j];
            U[i][j] = A[i][j] - sum;
        }
        for (int i = j + 1; i < N; i++) {
            double sum = 0;
            for (int k = 0; k < j; k++) sum += L[i][k] * U[k][j];
            L[i][j] = (A[i][j] - sum) / U[j][j];
        }
    }

    double det = 1;
    for (int i = 0; i < N; i++) det *= U[i][i];

    cout << fixed << setprecision(3);
    cout << "L:" << endl;
    for (auto &row : L) {
        for (double x : row) cout << setw(8) << x;
        cout << endl;
    }
    cout << "U:" << endl;
    for (auto &row : U) {
        for (double x : row) cout << setw(8) << x;
        cout << endl;
    }
    cout << "det = " << det << endl;
    return 0;
}
`}

## Complexity

Filling each of the `O(N²)` entries of `L`/`U` costs an `O(N)` sum → **`O(N³)`**, same order as Gaussian elimination. Determinant via Laplace expansion is factorial; LU is the practical cubic method.

## Cheat sheet

| Idea | Takeaway |
|---|---|
| Goal | `det(A)` via `A = L U` |
| Convention | `Lᵢᵢ = 1` (CP-Algorithms Kraut / Doolittle) |
| Formula | `det = Π Uᵢᵢ` (× `(−1)^{#swaps}` with pivoting) |
| Fill | Per column: `U` for `i≤j`, then `L` for `i>j` |
| Cost | `O(N³)` |
| Caveat | Need nonzero pivots / principal minors, or pivot |
