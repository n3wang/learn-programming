# Floyd's Linked List Cycle Finding

Given a linked list that may contain a cycle, detect the cycle and find its **entry** (node `C` where the loop begins).

**Floyd’s cycle algorithm** (tortoise and hare) does this in **`O(n)` time** and **`O(1)` extra memory**.

This lesson follows [CP-Algorithms — Floyd’s cycle finding](https://cp-algorithms.com/others/tortoise_and_hare.html).

Related: [Simulated Annealing](./29-simulated-annealing) (also uses a “ρ” / tortoise–hare idea in Pollard ρ — see [Integer Factorization](./12-integer-factorization)).

## Phase 1 — Does a cycle exist?

- `slow` and `fast` both start at `head`.
- Each step: `slow = slow.next`, `fast = fast.next.next`.
- If they ever point to the **same** node → cycle.
- If `fast` hits `null` → acyclic.

```java
public boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) return true;
    }
    return false;
}
```

Fast covers twice the distance of slow; the gap grows by 1 each iteration. Once both are in a cycle of length `L`, they meet after a finite number of steps (the lead is a multiple of `L` mod `L`).

## Phase 2 — Where does the cycle start?

After they meet at `G` inside the cycle:

1. Reset `slow = head` (leave `fast` at `G`).
2. Advance **both one step** at a time.
3. Their next meeting point is **`C`**, the cycle entry.

```java
// slow, fast already meet inside the cycle
slow = head;
while (slow != fast) {
    slow = slow.next;
    fast = fast.next;
}
return slow; // entry C
```

## Why phase 2 works

Let:

- `a` = steps from head to `C`
- `b` = steps from `C` to first meeting `G`
- `L` = cycle length

At the first meeting:

```text
slowDist = a + x L + b
fastDist = a + y L + b
fastDist = 2 · slowDist
```

⇒ `a = (y − 2x) L − b`

So walking `a` steps from head reaches `C`, and walking `a` steps from `G` (already `b` into the cycle) also wraps to `C`. Moving both one-by-one, they meet at the entry.

  code={`#include <iostream>
#include <vector>
using namespace std;

// next[i] = successor; -1 = null
// 0→1→2→3→4→5→3  (entry = 3)
int findCycleEntry(const vector<int>& nxt) {
    int slow = 0, fast = 0;
    auto step1 = [&](int x) { return x < 0 ? -1 : nxt[x]; };
    auto step2 = [&](int x) {
        x = step1(x);
        return x < 0 ? -1 : step1(x);
    };

    while (true) {
        slow = step1(slow);
        fast = step2(fast);
        if (fast < 0) return -1; // no cycle
        if (slow == fast) break;
    }

    slow = 0;
    while (slow != fast) {
        slow = step1(slow);
        fast = step1(fast);
    }
    return slow;
}

int main() {
    vector<int> nxt = {1, 2, 3, 4, 5, 3};
    cout << "entry = " << findCycleEntry(nxt) << endl;

    vector<int> line = {1, 2, 3, -1};
    cout << "acyclic -> " << findCycleEntry(line) << endl;
    return 0;
}
`}

## Cheat sheet

| Phase | Action |
|---|---|
| 1 | slow +1, fast +2 until equal or null |
| Meet | Proves a cycle; node is some `G` in the loop |
| 2 | `slow = head`; both +1 until equal → entry `C` |
| Why | `a ≡ −b (mod L)` from `fast = 2·slow` |
| Cost | `O(n)` time, `O(1)` memory |
