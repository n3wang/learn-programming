# Binary Search

Binary search speeds up a search by repeatedly **halving** the active interval. The classic use is looking up a value in a **sorted** array, but the same split idea powers lower/upper bounds, “binary search on the answer,” continuous root finding, and jump searches on trees.

This lesson follows [CP-Algorithms — Binary Search](https://cp-algorithms.com/num_methods/binary_search.html).

## Search in sorted arrays

Given a sorted array `A₀ ≤ A₁ ≤ … ≤ Aₙ₋₁`, is `k` present?

Linear scan is `O(n)` and ignores sortedness. Binary search keeps indices `L < R` with `A_L ≤ k ≤ A_R` (so if `k` appears at all, it lies in that range). Pick a midpoint `M` with `L < M < R`:

- if `A_L ≤ k ≤ A_M` → shrink to `[L, M]`
- if `A_M ≤ k ≤ A_R` → shrink to `[M, R]`

When `R = L + 1`, compare against the two endpoints. In the worst case you always keep the larger half, so choose

```text
M ≈ (L + R) / 2
```

to minimize `max(M−L, R−M)`. Each step halves the gap; after `h` steps ` (R−L) / 2ʰ ≈ 1 `, so `h ∈ O(log n)`.

For `n ≈ 10⁶ ≈ 2²⁰` that is ~20 probes instead of a million.

## Lower bound and upper bound

Often you want:

- **lower bound** of `k` — first index with `Aᵢ ≥ k`
- **upper bound** of `k` — first index with `Aᵢ > k`

Together they form the half-open range of elements equal to `k`. Presence check: find the lower bound and test equality.

## Implementation (half-open invariant)

Maintain `L < R` with **`A_L ≤ k < A_R`**. The active interval is `[L, R)`.

Sentinels: `L = -1`, `R = n`, imagining `A_{-1} = −∞` and `A_n = +∞`. Never read `A_L` or `A_R` while they are sentinels. Midpoint:

```text
m = ⌊(L + R) / 2⌋
```

```cpp
// a[0..n) sorted
int l = -1, r = n;
while (r - l > 1) {
    int m = l + (r - l) / 2; // safer than (l+r)/2
    if (k < a[m]) {
        r = m; // a[l] ≤ k < a[m] ≤ a[r]
    } else {
        l = m; // a[l] ≤ a[m] ≤ k < a[r]
    }
}
// l = last index with a[l] ≤ k (or -1)
// r = first index with a[r] > k (or n)  → upper bound
```

:::warning Midpoint overflow
`(l + r) / 2` can overflow for large positive `l` and `r` (infamous JDK bug). Prefer `l + (r - l) / 2`, or C++20 `std::midpoint(l, r)`.
:::

## Search on an arbitrary predicate

Let `f : {0,…,n−1} → {0,1}` be **monotone**: `f(0) ≤ f(1) ≤ … ≤ f(n−1)`.

Binary search finds the transition: largest `l` with `f(l)=0` and `f(l+1)=1` (if a flip exists). Same skeleton — replace `k < a[m]` with `f(m)`:

```cpp
int l = -1, r = n;
while (r - l > 1) {
    int m = l + (r - l) / 2;
    if (f(m)) {
        r = m; // f(l)=0, f(m)=1
    } else {
        l = m; // f(m)=0, f(r)=1
    }
}
```

Invariant: `f(l)=0`, `f(r)=1` (with sentinels for all-0 / all-1 edge cases).

Useful when evaluating `f` is expensive — you only pay `O(log n)` calls.

// Can we ship all weights with capacity mid in ≤ days trips?

        if (x > mid) return false;
        if (cur + x > mid) { used++; cur = 0; }
        cur += x;
    }

int main() {

        int mid = lo + (hi - lo) / 2;
        if (ok(weights, days, mid)) hi = mid;
        else lo = mid;

    cout << endl << "days = " << days << endl;

}

## Binary search on the answer

When you can only **check** “is the answer ≥ λ?” with a monotone predicate, binary-search λ.

Example idea: maximize a floored average over long enough subarrays. Checking “average ≥ λ” rewrites as “some subarray of `aᵢ − λ` has length ≥ x+1 and nonnegative sum” (prefix sums). Binary-search λ over the value domain.

## Continuous search

If `f` is continuous on `[L, R]` and (w.l.o.g.) `f(L) ≤ f(R)`, intermediate-value theorem says every `y ∈ [f(L), f(R)]` has some `x` with `f(x)=y`. Halve `[L, R]` by comparing `f(M)` to `y`. Accuracy `±δ` costs `O(log((R−L)/δ))` — **no monotonicity required**.

Classic: roots of odd-degree polynomials (`f → −∞` and `+∞` at the ends).

## Search with powers of 2

Instead of an interval, keep pointer `i` and exponent `k`. Test `i + 2ᵏ`; advance if the predicate is still 0, then decrease `k`. Common on trees (LCA, k-th ancestor) and Fenwick “find k-th nonzero.”

## Cheat sheet

| Situation | What to binary-search |
|---|---|
| Sorted array membership | Index interval with `a[l] ≤ k < a[r]` |
| First ≥ / first > | Lower / upper bound |
| Expensive monotone yes/no | Predicate `f` |
| Optimize a numeric answer | Feasibility check on λ |
| Continuous `f(x)=y` | Halve real interval to ±δ |
| Trees / Fenwick | Powers of two from a pointer |
