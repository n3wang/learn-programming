# Simulated Annealing

**Simulated Annealing (SA)** is a **randomized** metaheuristic that approximates a **global** optimum of an energy function `E(s)`. Randomness means the same input can yield different outputs.

It shines when the state space is **discrete** and `E` has many **local minima** — classic example: the **Travelling Salesman Problem (TSP)**.

This lesson follows [CP-Algorithms — Simulated Annealing](https://cp-algorithms.com/num_methods/simulated_annealing.html).

Related: [Knapsack](./knapsack) (exact DP vs heuristics), [Minimum Enclosing Circle](./minimum-enclosing-circle) (randomized incremental).

## Motivation (metallurgy → search)

Annealing heats a material then cools it so atoms settle into a low-energy arrangement. Early on, thermal noise lets the system **cross energy barriers**; later it **freezes** into a deep basin.

SA copies that:

1. Start at a random state with **high temperature** `T`.
2. Propose a **neighbor**; always take improvements; sometimes take **worse** moves (probability grows with `T`).
3. **Cool** `T` each step so escapes become rare and the search settles.

Track `s_best` across the whole run (the current `s` may wander).

## Building blocks

| Concept | TSP meaning |
|---|---|
| State `s` | A tour (permutation of cities) |
| Energy `E(s)` | Tour length (minimize) |
| Neighbor | Swap two cities (or 2-opt, …) |
| Temperature `T` | Willingness to accept worse tours |
| Decay `u < 1` | Cooling rate (`T ← T·u`) |

For **maximization**, minimize `−f` and flip the sign when reporting.

## Probability acceptance (Gibbs)

```text
P(E, E_next, T) = True  if  U[0,1] ≤ exp(−(E_next − E) / T)
                  False otherwise
```

If `E_next < E`, then `exp(…)` ≥ 1 → **always accept**. If worse, accept with probability `exp(−ΔE / T)`.

```cpp
bool P(double E, double E_next, double T, mt19937& rng) {
    double prob = exp(-(E_next - E) / T);
    if (prob >= 1) return true;
    bernoulli_distribution d(prob);
    return d(rng);
}
```

## Algorithm template

```cpp
pair<double, state> simAnneal() {
    state s = state();       // random start
    state best = s;
    double T = 10000;        // initial temperature
    double u = 0.995;        // decay
    double E = s.E(), E_best = E;
    mt19937 rng(...);
    while (T > 1) {
        state nxt = s.next();
        double E_next = nxt.E();
        if (P(E, E_next, T, rng)) {
            s = nxt;
            E = E_next;
            if (E < E_best) { best = s; E_best = E; }
        }
        T *= u;
    }
    return {E_best, best};
}
```

Fill in `state::next()` (neighbor) and `state::E()` (energy).

### Choosing `T` and `u`

- Wide space / many basins → slow cool, e.g. `u = 0.999` (or ≥ `0.998` if unsure).
- Narrower space → `u ≈ 0.99` may suffice.
- Iteration count with exponential cooling: `N ≈ ⌈ −log_u T ⌉` (from `T_final ≈ 1`), or pick `N` from TLE budget then `T = u^{−N}`.

Also common: **time-based** exit; other cooling schedules; change the base of the exponential (`pow(e, −ΔE/T)`) to sharpen/soften the preference for small `ΔE`.

<PistonRunner
  lang="c++"
  height="520px"
  code={`#include <iostream>
#include <vector>
#include <cmath>
#include <random>
#include <chrono>
#include <utility>
using namespace std;

bool accept_move(double E, double E_next, double T, mt19937& rng) {
    double prob = exp(-(E_next - E) / T);
    if (prob >= 1.0) return true;
    bernoulli_distribution d(prob);
    return d(rng);
}

struct State {
    vector<pair<double, double>> pts;
    mt19937* rng;

    State next() const {
        State s = *this;
        uniform_int_distribution<int> choose(0, (int)pts.size() - 1);
        int a = choose(*rng), b = choose(*rng);
        swap(s.pts[a], s.pts[b]);
        return s;
    }

    double E() const {
        double dist = 0;
        int n = (int)pts.size();
        for (int i = 0; i < n; i++) {
            auto [x1, y1] = pts[i];
            auto [x2, y2] = pts[(i + 1) % n];
            dist += hypot(x1 - x2, y1 - y2);
        }
        return dist;
    }
};

int main() {
    mt19937 rng(42);
    State s;
    s.rng = &rng;
    s.pts = {{0,0},{2,2},{0,2},{2,0},{0,1},{1,2},{2,1},{1,0}};

    State best = s;
    double T = 100.0;
    double u = 0.995;
    double E = s.E();
    double E_best = E;

    while (T > 1.0) {
        State nxt = s.next();
        double En = nxt.E();
        if (accept_move(E, En, T, rng)) {
            s = nxt;
            E = En;
            if (E < E_best) {
                best = s;
                E_best = E;
            }
        }
        T *= u;
    }

    cout << "best length ≈ " << E_best << endl;
    cout << "tour order:" << endl;
    for (auto [x, y] : best.pts) cout << x << " " << y << endl;
    return 0;
}
`}

## Cheat sheet

| Piece | Role |
|---|---|
| `E(s)` | Energy to minimize |
| Neighbor | Local transform of `s` |
| High `T` | Escape local minima |
| Cool `T·u` | Converge / exploit |
| PAF | `exp(−ΔE/T)` vs `U[0,1]` |
| `s_best` | Best state across the run |
| Params | Larger `u` → slower, often better |
