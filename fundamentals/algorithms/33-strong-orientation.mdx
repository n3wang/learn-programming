# Strong Orientation

A **strong orientation** of an undirected graph assigns a direction to every edge so the result is **strongly connected**: you can go from any vertex to any other along directed edges.

This lesson follows [CP-Algorithms — Strong orientation](https://cp-algorithms.com/graph/strong-orientation.html).

Related: [0-1 BFS](./bfs), [Centroid Decomposition](./centroid-decomposition).

## When is it possible?

A **bridge** can be crossed in only one direction after orientation, so you cannot return. Hence a graph with a bridge has **no** strong orientation.

**Robbins' theorem:** an undirected graph has a strong orientation **iff** it is **connected and bridgeless** (2-edge-connected).

## Construction (DFS)

On a bridgeless connected graph:

1. Run DFS; build a DFS tree.
2. Orient **tree edges** **away from the root**.
3. Orient every other edge **from descendant toward ancestor** (back / cross toward the tree).

Why it works: no bridges ⇒ after deleting any tree edge you can still climb using a path with a back edge. So every vertex can reach the root, and the root can reach every vertex via the tree → strongly connected.

## Minimal number of SCCs

Orient so the digraph has as few SCCs as possible.

- Handle each undirected **component** separately.
- Bridges cannot sit inside a strong piece: after removing bridges you get bridgeless chunks you **can** strongly orient.
- Orient bridges arbitrarily.

The algorithm below runs the same DFS orientation on each component: tree / back orientation plus bridge detection. Then

```text
min #SCCs = (#undirected components) + (#bridges)
```

(each bridge merges into the count as an irreversible cut between otherwise strong pieces).

## Implementation sketch

Bridge-finding DFS that also records an orientation when an edge is first used:

```cpp
// adj: (neighbor, edge_id); edges[id] = {a,b} as in input
// orient[id] = '>' if directed a→b, '<' if b→a
void find_bridges(int v) {
    low[v] = tin[v] = time++;
    for (auto [nv, id] : adj[v]) {
        if (edge_used[id]) continue;
        edge_used[id] = true;
        orient[id] = (v == edges[id].first) ? '>' : '<';
        if (tin[nv] == -1) {
            find_bridges(nv);
            low[v] = min(low[v], low[nv]);
            if (low[nv] > tin[v]) bridge_cnt++;
        } else {
            low[v] = min(low[v], tin[nv]);
        }
    }
}
// answer: comp_cnt + bridge_cnt, and orient string
```

You can also orient first, then run any SCC algorithm to verify the count.

#include <vector>
#include <string>
using namespace std;

struct Solver {
    int n, m;
    vector<vector<pair<int, int>>> adj;
    vector<pair<int, int>> edges;
    vector<int> tin, low;
    vector<char> orient;
    vector<char> edge_used;
    int timer = 0, bridge_cnt = 0;

    void dfs(int v) {
        low[v] = tin[v] = timer++;
        for (auto [nv, id] : adj[v]) {
            if (edge_used[id]) continue;
            edge_used[id] = 1;
            orient[id] = (v == edges[id].first) ? '>' : '<';
            if (tin[nv] == -1) {
                dfs(nv);
                low[v] = min(low[v], low[nv]);
                if (low[nv] > tin[v]) bridge_cnt++;
            } else {
                low[v] = min(low[v], tin[nv]);
            }
        }
    }

    void run() {
        tin.assign(n, -1);
        low.assign(n, -1);
        orient.assign(m, '?');
        edge_used.assign(m, 0);
        timer = bridge_cnt = 0;
        int comp = 0;
        for (int v = 0; v < n; v++) {
            if (tin[v] == -1) {
                comp++;
                dfs(v);
            }
        }
        cout << "min SCCs = " << comp + bridge_cnt << endl;
        cout << "orient = ";
        for (char c : orient) cout << c;
        cout << endl;
    }
};

int main() {
    // Cycle 0-1-2-3-0 (bridgeless)
    {
        Solver s;
        s.n = 4; s.m = 4;
        s.adj.assign(4, {});
        s.edges = {{0,1},{1,2},{2,3},{3,0}};
        for (int i = 0; i < 4; i++) {
            auto [a, b] = s.edges[i];
            s.adj[a].push_back({b, i});
            s.adj[b].push_back({a, i});
        }
        cout << "cycle:" << endl;
        s.run();
    }
    // Path 0-1-2 (one bridge)
    {
        Solver s;
        s.n = 3; s.m = 2;
        s.adj.assign(3, {});
        s.edges = {{0,1},{1,2}};
        for (int i = 0; i < 2; i++) {
            auto [a, b] = s.edges[i];
            s.adj[a].push_back({b, i});
            s.adj[b].push_back({a, i});
        }
        cout << "path:" << endl;
        s.run();
    }
    return 0;
}

## Cheat sheet

| Idea | Takeaway |
|---|---|
| Goal | Orient edges → strongly connected |
| Exists? | Connected + no bridges (Robbins) |
| How | DFS: tree ↓ from root, backs ↑ to ancestors |
| Min SCCs | `#components + #bridges` |
| Encode | `>` / `<` vs input endpoint order |
