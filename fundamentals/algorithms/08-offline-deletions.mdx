# Offline Deletions in $O(T(n)\log n)$

Suppose you have a structure that supports **insert** in true $O(T(n))$ (not amortized). You want **delete** as well, but only **offline**.

Trick: build a **segment tree over time**, place each element on the $O(\log n)$ nodes covering its lifetime, DFS the tree while inserting on enter and **rolling back** on leave.

Total: each insert/delete pair costs $O(T(n)\log n)$.

This lesson follows [CP-Algorithms — Deleting from a data structure in $O(T(n)\log n)$](https://cp-algorithms.com/data_structures/deleting_in_log_n.html).

## The idea

1. Every element is alive on one or more time intervals `[L, R)`.
2. Segment-tree the timeline of queries. Cover each lifetime with $O(\log T)$ nodes; store the element on those nodes.
3. Put “ask something” operations in the corresponding **leaves**.
4. DFS the segment tree:
   - **Enter** node → insert all elements stored there (push undo records).
   - **Leaf** → answer the query from the current structure.
   - Recurse to children.
   - **Leave** node → rollback exactly the inserts from this node.

If insert changes the structure in $O(T(n))$ and is **reversible**, rollback is also $O(T(n))$ via a change stack.

:::warning Amortized inserts break
Path compression, splay, etc. are amortized. After rollback you cannot rely on the amortized bound. Prefer **union by rank** without path compression for DSU-with-rollback.
:::

## Classic use: dynamic connectivity

Operations: add edge, remove edge, query number of connected components (or “are $u,v$ connected?”).

- DSU with **union by rank** + **rollback stack** (no path compression, or store full parent snapshots).
- Each edge’s lifetime `[add_time, remove_time)` goes onto the time segment tree.
- At each leaf that asks “how many components?”, read `dsu.comps`.

## DSU with rollbacks

```cpp
struct dsu_save {
    int v, rnkv, u, rnku;
};

struct dsu_with_rollbacks {
    vector<int> p, rnk;
    int comps;
    stack<dsu_save> op;

    dsu_with_rollbacks(int n) {
        p.resize(n);
        rnk.assign(n, 0);
        iota(p.begin(), p.end(), 0);
        comps = n;
    }

    int find_set(int v) {
        return v == p[v] ? v : find_set(p[v]); // no compression
    }

    bool unite(int v, int u) {
        v = find_set(v);
        u = find_set(u);
        if (v == u) return false;
        comps--;
        if (rnk[v] > rnk[u]) swap(v, u);
        op.push({v, rnk[v], u, rnk[u]});
        p[v] = u;
        if (rnk[u] == rnk[v]) rnk[u]++;
        return true;
    }

    void rollback() {
        auto x = op.top();
        op.pop();
        comps++;
        p[x.v] = x.v;
        rnk[x.v] = x.rnkv;
        rnk[x.u] = x.rnku;
    }
};
```

## Time segment tree (query tree)

```cpp
struct query {
    int v, u;
    bool united = false;
};

struct QueryTree {
    vector<vector<query>> t;
    dsu_with_rollbacks dsu;
    int T;

    QueryTree(int _T, int n) : T(_T), dsu(n) {
        t.resize(4 * T + 4);
    }

    void add_to_tree(int v, int l, int r, int ul, int ur, query q) {
        if (ul > ur) return;
        if (l == ul && r == ur) {
            t[v].push_back(q);
            return;
        }
        int mid = (l + r) / 2;
        add_to_tree(2 * v, l, mid, ul, min(ur, mid), q);
        add_to_tree(2 * v + 1, mid + 1, r, max(ul, mid + 1), ur, q);
    }

    void add_edge_lifetime(query q, int l, int r) {
        add_to_tree(1, 0, T - 1, l, r, q); // alive on [l, r]
    }

    void dfs(int v, int l, int r, vector<int>& ans) {
        for (query& q : t[v])
            q.united = dsu.unite(q.v, q.u);
        if (l == r)
            ans[l] = dsu.comps;
        else {
            int mid = (l + r) / 2;
            dfs(2 * v, l, mid, ans);
            dfs(2 * v + 1, mid + 1, r, ans);
        }
        for (query& q : t[v])
            if (q.united) dsu.rollback();
    }

    vector<int> solve() {
        vector<int> ans(T);
        dfs(1, 0, T - 1, ans);
        return ans;
    }
};
```

Complexity: `O((n + q) · T_dsu · log q)` with `T_dsu = O(log n)`.

## Beyond DSU

Same skeleton works whenever you can **insert + undo**:

| Structure | Offline deletes for… |
|---|---|
| DSU + rollback | Dynamic connectivity, bipartiteness |
| Convex hull / Li Chao (with undo) | Lines present on intervals |
| Segment tree / fenwick snapshots | Rare; usually rebuild |
| Linear basis with undo | XOR span over time |

The “alive interval → $O(\log)$ nodes” idea also appears outside DS problems (divide-and-conquer on time).

  hint="find without compression; stack stores (child, parent, old_rank_parent, old_comps)"
  solution={`def run(n, ops):
    p = list(range(n))
    rnk = [0] * n
    comps = n
    stack = []
    out = []

    def find(v):
        while v != p[v]:
            v = p[v]
        return v

    for op in ops:
        if op[0] == 'U':
            u, v = int(op[1]), int(op[2])
            u, v = find(u), find(v)
            if u == v:
                out.append('0')
                continue
            if rnk[u] > rnk[v]:
                u, v = v, u
            stack.append((u, v, rnk[v], comps))
            p[u] = v
            if rnk[u] == rnk[v]:
                rnk[v] += 1
            comps -= 1
            out.append('1')
        elif op[0] == 'R':
            if not stack:
                continue
            u, v, old_rank, old_comps = stack.pop()
            p[u] = u
            rnk[v] = old_rank
            comps = old_comps
        else:
            out.append(str(comps))
    return out
`}
  sourceChecks={[
    { name: 'has stack', pattern: 'stack|append|pop', must: true, hint: 'keep an undo stack' },

## Cheat sheet

| Step | Action |
|---|---|
| Lifetimes | Map each add/delete to `[L,R)` |
| Segment tree | Store element on $O(\\log T)$ nodes |
| DFS enter | Insert + push undo |
| Leaf | Answer query |
| DFS leave | Rollback |
| DSU | Rank + stack; no path compression |
