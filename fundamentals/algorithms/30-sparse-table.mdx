# Sparse Table

A **sparse table** answers **static** range queries on an immutable array. Most associative folds take **`O(log n)`** per query; for **range minimum / maximum** (idempotent ops) it answers in **`O(1)`**.

**Drawback:** if any `A[i]` changes, rebuild the whole structure (`O(n log n)`).

This lesson follows [CP-Algorithms — Sparse Table](https://cp-algorithms.com/data_structures/sparse-table.html).

Related: [Binary Search](./03-binary-search), [MEX](./18-mex).

## Intuition

Any positive length decomposes into **≤ ⌈log₂ length⌉** decreasing powers of two — same idea as binary digits. So any interval is a union of `O(log n)` dyadic blocks.

Precompute the answer for **every** range of length `2^i`. Answer a query by combining a few (or two overlapping) precomputed blocks.

## Precomputation

Store `st[i][j]` = answer on `[j, j + 2^i − 1]`. Layout `(K+1) × MAXN` with `K ≥ ⌊log₂ MAXN⌋` (often `K = 25`). Put the `MAXN` dimension second for cache-friendly scans.

```cpp
// st[0][j] = A[j]
for (int i = 1; i <= K; i++)
    for (int j = 0; j + (1 << i) <= N; j++)
        st[i][j] = f(st[i - 1][j], st[i - 1][j + (1 << (i - 1))]);
```

Each length-`2^i` block is the fold of two halves of length `2^{i−1}`. Build time **`O(N log N)`**.

`f` is `+` for sums, `min` for RMQ, etc.

## Range sum — `O(log n)`

Disjoint cover: from the largest `2^i ≤ remaining length`, add `st[i][L]` and advance `L`.

```cpp
long long sum = 0;
for (int i = K; i >= 0; i--) {
    if ((1 << i) <= R - L + 1) {
        sum += st[i][L];
        L += 1 << i;
    }
}
```

## Range minimum — `O(1)`

`min` is **idempotent**: processing an index twice does not change the answer. Cover `[L,R]` with **two overlapping** blocks of length `2^i` where `i = ⌊log₂(R−L+1)⌋`:

```text
min( st[i][L], st[i][R − 2^i + 1] )
```

Example: `[1,6]` → `[1,4] ∪ [3,6]`.

Precompute `lg[x] = ⌊log₂ x⌋`:

```cpp
lg[1] = 0;
for (int i = 2; i <= MAXN; i++)
    lg[i] = lg[i / 2] + 1;

int i = lg[R - L + 1];
int minimum = min(st[i][L], st[i][R - (1 << i) + 1]);
```

(`__builtin_clzll` / `std::bit_width` also work; a `lg[]` array can be slower from cache misses.)

This **O(1)** trick needs an **idempotent** semigroup (min, max, gcd, AND, OR, …). Sums / products need the disjoint `O(log n)` cover (or a [Disjoint Sparse Table](https://codeforces.com/blog/entry/66398) / Sqrt Tree for `O(1)` associative queries).

<PistonRunner
  lang="c++"
  height="520px"
  code={`#include <iostream>
#include <vector>
#include <algorithm>
#include <cmath>
using namespace std;

int main() {
    vector<int> A = {4, 2, 3, 7, 1, 5, 8, 6};
    int N = (int)A.size();
    int K = 0;
    while ((1 << K) <= N) K++;
    K--;

    vector<vector<int>> stMin(K + 1, vector<int>(N));
    vector<vector<long long>> stSum(K + 1, vector<long long>(N));
    for (int j = 0; j < N; j++) {
        stMin[0][j] = A[j];
        stSum[0][j] = A[j];
    }
    for (int i = 1; i <= K; i++) {
        for (int j = 0; j + (1 << i) <= N; j++) {
            stMin[i][j] = min(stMin[i - 1][j], stMin[i - 1][j + (1 << (i - 1))]);
            stSum[i][j] = stSum[i - 1][j] + stSum[i - 1][j + (1 << (i - 1))];
        }
    }

    vector<int> lg(N + 1);
    lg[1] = 0;
    for (int i = 2; i <= N; i++) lg[i] = lg[i / 2] + 1;

    auto rmq = [&](int L, int R) {
        int i = lg[R - L + 1];
        return min(stMin[i][L], stMin[i][R - (1 << i) + 1]);
    };

    auto rsq = [&](int L, int R) {
        long long sum = 0;
        for (int i = K; i >= 0; i--) {
            if ((1 << i) <= R - L + 1) {
                sum += stSum[i][L];
                L += 1 << i;
            }
        }
        return sum;
    };

    cout << "RMQ[1,6] = " << rmq(1, 6) << endl;
    cout << "RSQ[2,7] = " << rsq(2, 7) << endl;
    return 0;
}
`}

## Cheat sheet

| Topic | Takeaway |
|---|---|
| `st[i][j]` | Fold on `[j, j+2^i−1]` |
| Build | `O(n log n)` DP from halves |
| Sum / assoc. | Disjoint peel `O(log n)` |
| Min / max / gcd | Two overlaps `O(1)` |
| Updates | Rebuild everything |
| Related | Disjoint sparse table, Sqrt tree |
