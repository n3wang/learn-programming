# Sqrt Tree

Given an array `a[0..n)` and an **associative** operation `∘`

```text
(x ∘ y) ∘ z = x ∘ (y ∘ z)
```

(`+`, `min`, `max`, `gcd`, AND, OR, XOR, …), answer range folds

```text
q(l, r) = a[l] ∘ a[l+1] ∘ ⋯ ∘ a[r]
```

A **sqrt tree** does this in **`O(1)`** per query after **`O(n log log n)`** preprocess and memory — including ops that are **not** idempotent (unlike the two-overlap sparse-table RMQ trick).

This lesson follows [CP-Algorithms — Sqrt Tree](https://cp-algorithms.com/data_structures/sqrt-tree.html).

Related: [Sparse Table](./30-sparse-table).

## One level: sqrt decomposition

Split into `≈ √n` blocks of size `≈ √n`. In each block store:

- **`prefixOp`** — folds that start at the **block start**
- **`suffixOp`** — folds that end at the **block end**

Plus **`between[i][j]`** (`i ≤ j`) — fold of **full blocks** `i…j` (size `O((√n)²) = O(n)`).

All of that builds in **`O(n)`** for one layer.

**Example** (`∘ = +`, `a = {1..9}`): blocks `{1,2,3}`, `{4,5,6}`, `{7,8,9}`.

| Block | prefixOp | suffixOp |
|---|---|---|
| 0 | `{1,3,6}` | `{6,5,3}` |
| 1 | `{4,9,15}` | `{15,11,6}` |
| 2 | `{7,15,24}` | `{24,17,9}` |

```text
between = [[6, 21, 45],
           [0, 15, 39],
           [0,  0, 24]]
```

A query that **spans** blocks splits into three pieces:

```text
suffixOp (partial first block)  ∘  between[…]  ∘  prefixOp (partial last block)
```

Queries **inside one block** are not covered yet.

## Make a tree

Build the **same** structure **recursively inside each block** until length is `1` or `2` (answer in `O(1)`).

- Node for length `k` has `≈ √k` children.
- Height: `log √k = (log k)/2` → **`O(log log n)`** layers.
- Each index appears once per layer → build/memory **`O(n log log n)`**.

Naively walk down until the query no longer lies in a single child → **`O(log log n)`** per query.

## `O(1)` queries

Pad `n` to a power of two; force equal **power-of-two** block sizes on each layer.

Indices in one block of size `2^k` differ only in the **lowest `k` bits**. So `l` and `r` lie in the same block iff

```text
(l xor r) < 2^k
```

Precompute highest set bits / layer maps (`clz`, `onLayer`). For `q(l,r)` read the highest bit of `l xor r`, jump to a suitable layer, then combine `suffix ∘ between ∘ prefix` in **`O(1)`**.

## Updates

| Operation | Naive | Optimized |
|---|---|---|
| Point assign | Rebuild `between` on root → **`O(n)`** | Replace root `between` by an **unindexed** sqrt-tree **`index`** over block answers → point update **`O(√n)`**, queries still **`O(1)`** |
| Range assign | — | Lazy tags: (1) `massUpdate` **`O(√n log log n)`**, query **`O(1)`**; or (2) `massUpdate` **`O(√n)`**, query **`O(log log n)`** |

Indexed tree: only the **root** has `index`; deeper nodes keep `between`.

<PistonRunner
  lang="c++"
  height="480px"
  code={`#include <iostream>
#include <vector>
#include <cmath>
using namespace std;

struct SqrtLayer {
    int n, B, nb;
    vector<long long> a, pref, suf;
    vector<vector<long long>> between;

    SqrtLayer(const vector<long long>& arr) : a(arr) {
        n = (int)a.size();
        B = max(1, (int)sqrt(n));
        nb = (n + B - 1) / B;
        pref.assign(n, 0);
        suf.assign(n, 0);
        between.assign(nb, vector<long long>(nb, 0));
        for (int b = 0; b < nb; b++) {
            int L = b * B, R = min(n, L + B);
            pref[L] = a[L];
            for (int i = L + 1; i < R; i++) pref[i] = pref[i - 1] + a[i];
            suf[R - 1] = a[R - 1];
            for (int i = R - 2; i >= L; i--) suf[i] = a[i] + suf[i + 1];
        }
        vector<long long> blockSum(nb);
        for (int b = 0; b < nb; b++) {
            int L = b * B;
            blockSum[b] = suf[L];
        }
        for (int i = 0; i < nb; i++) {
            long long s = 0;
            for (int j = i; j < nb; j++) {
                s += blockSum[j];
                between[i][j] = s;
            }
        }
    }

    long long query(int l, int r) {
        int bl = l / B, br = r / B;
        if (bl == br) {
            long long s = 0;
            for (int i = l; i <= r; i++) s += a[i];
            return s;
        }
        long long ans = suf[l];
        if (bl + 1 <= br - 1) ans += between[bl + 1][br - 1];
        ans += pref[r];
        return ans;
    }
};

int main() {
    vector<long long> a = {1, 2, 3, 4, 5, 6, 7, 8, 9};
    SqrtLayer st(a);
    cout << "q(1,7) = " << st.query(1, 7) << endl;
    cout << "q(0,8) = " << st.query(0, 8) << endl;
    cout << "q(3,5) = " << st.query(3, 5) << endl;
    return 0;
}
`}
/>

</details>

## Cheat sheet

| Piece | Role |
|---|---|
| `prefixOp` / `suffixOp` | Intra-block ends |
| `between` / `index` | Full block ranges |
| Recursion | Handle in-block queries |
| Height | `O(log log n)` |
| Build | `O(n log log n)` |
| Query | `O(1)` with bit layer pick |
| Point update | `O(√n)` if indexed |
| vs sparse table | Works for non-idempotent `∘` |
