# Stars and Bars

**Stars and bars** counts ways to group **identical** objects into **labeled** boxes — equivalently, non-negative (or bounded) integer solutions to linear Diophantine equations.

This lesson follows [CP-Algorithms — Stars and bars](https://cp-algorithms.com/combinatorics/stars_and_bars.html).

Related: [Knapsack](./knapsack) (distributing capacity), [Polynomials & Series](./polynomials-series) (generating functions).

## Theorem

Number of ways to put **`n` identical** objects into **`k` labeled** boxes:

```text
C(n + k − 1, n)   =   C(n + k − 1, k − 1)
```

**Proof sketch:** write `n` stars (`★`) and `k−1` bars (`|`). Example for 5 objects / 4 boxes:

```text
★ | ★★ | | ★★   →   (1, 2, 0, 2)
```

Every partition ↔ every arrangement of `n` stars and `k−1` bars → binomial coefficient.

## Non-negative sums

Count solutions of

```text
x₁ + x₂ + ⋯ + xₖ = n,    xᵢ ≥ 0
```

Same bijection → **`C(n + k − 1, n)`**.

Example: `1 + 3 + 0 = 4` ↔ `★ | ★★★ |`.

## Positive sums

Now require `xᵢ ≥ 1`. Place `n` stars in a row; bars may occupy the **`n−1` gaps** between stars (at most one bar per gap, else an empty box). Choose `k−1` of those gaps:

```text
C(n − 1, k − 1)
```

(Equivalently `yᵢ = xᵢ − 1 ≥ 0` ⇒ `Σ y = n − k` ⇒ `C((n−k) + k − 1, n−k)`.)

## Lower bounds

For `xᵢ ≥ aᵢ`, set `xᵢ′ = xᵢ − aᵢ ≥ 0`:

```text
x₁′ + ⋯ + xₖ′ = n − Σ aᵢ
```

then apply the non-negative formula (if the right-hand side is negative, answer is `0`).

## Upper bounds

Caps `xᵢ ≤ bᵢ` need **inclusion–exclusion** (or generating functions). See [Upper-bound integer sums / IE](https://cp-algorithms.com/combinatorics/inclusion-exclusion.html#number-of-upper-bound-integer-sums) on CP-Algorithms.

  code={`#include <iostream>
using namespace std;

long long C(int n, int k) {
    if (k < 0 || k > n) return 0;
    if (k > n - k) k = n - k;
    long long r = 1;
    for (int i = 1; i <= k; i++) {
        r = r * (n - k + i) / i;
    }
    return r;
}

int main() {
    int n = 5, k = 4;
    cout << "non-neg x1+..+x4=5: " << C(n + k - 1, n) << endl;
    n = 5; k = 3;
    cout << "positive x1+..+x3=5: " << C(n - 1, k - 1) << endl;
    // lower: x>=(1,0,2), sum=6 → rem=3, k=3
    cout << "lower bounds rem=3,k=3: " << C(3 + 3 - 1, 3) << endl;

}

## Cheat sheet

| Case | Formula |
|---|---|
| Identical → `k` boxes | `C(n+k−1, n)` |
| `Σ x = n`, `x≥0` | same |
| `Σ x = n`, `x≥1` | `C(n−1, k−1)` |
| `xᵢ ≥ aᵢ` | `C(n−Σa + k−1, n−Σa)` |
| Upper bounds | Inclusion–exclusion |
