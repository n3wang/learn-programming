# Second Best Minimum Spanning Tree

A **minimum spanning tree** `T` of `G` connects all vertices with minimum total edge weight. A **second-best MST** `T'` is a spanning tree whose weight is the next-smallest among all spanning trees of `G`.

This lesson follows [CP-Algorithms — Second best MST](https://cp-algorithms.com/graph/second_best_mst.html).

Related: [Manhattan Distance](./manhattan-distance) (Manhattan MST), [0-1 BFS](./bfs).

## Observation

`T'` differs from `T` by **exactly one edge replacement**:

```text
T' = (T ∪ {e_new}) \ {e_old}
```

with `e_new ∉ T`, `e_old ∈ T`, and `T'` still a tree. Among all such swaps, minimize

```text
δ = weight(e_new) − weight(e_old)
```

(equivalently minimize the weight of `T'`). Proof sketch: see CLRS problem 23-1.

## Slow approach: exclude each MST edge

1. Sort edges `O(E log E)`, build MST with Kruskal `O(E α(V))`.
2. For each of the `V−1` MST edges, **forbid** it and rebuild an MST on the rest (`O(E)` with edges already sorted).
3. Take the lightest alternative tree.

Complexity: **`O(V E)`**.

## Fast approach: add each non-MST edge + LCA

Do the dual:

1. Build MST `T` (weight `res`).
2. For every `e = (u,v) ∉ T`, adding `e` creates a unique cycle through `LCA(u,v)` in the rooted tree.
3. Let `k` be the **heaviest** edge on that cycle except `e` (i.e. max weight on tree paths `u→LCA` and `v→LCA`).
4. Candidate weight = `res + w(e) − w(k)`. Keep the minimum.

With **binary lifting** that also stores path maxima (and optionally the second maximum when `w(k) = w(e)`), each query is `O(log V)`. Total **`O(E log V)`**.

Example (article intuition): add edge weight `36` → cycle `36–7–2–34` → drop `34` → `δ = 2`. Other non-tree edges give larger `δ`; the minimum `δ` tree is the second-best MST.

#include <vector>
#include <algorithm>
#include <numeric>
using namespace std;

struct Edge {
    int u, v, w;
};

int findp(vector<int>& p, int x) {
    return p[x] == x ? x : p[x] = findp(p, p[x]);
}

bool unite(vector<int>& p, int a, int b) {
    a = findp(p, a);
    b = findp(p, b);
    if (a == b) return false;
    p[b] = a;
    return true;
}

// max edge weight on unique tree path u..v
int max_on_path(const vector<vector<pair<int, int>>>& adj, int u, int v) {
    vector<int> par(adj.size(), -1), pw(adj.size(), 0);
    vector<int> st = {u};
    par[u] = u;
    while (!st.empty()) {
        int x = st.back();
        st.pop_back();
        for (auto [y, w] : adj[x]) {
            if (par[y] != -1) continue;
            par[y] = x;
            pw[y] = w;
            st.push_back(y);
        }
    }
    int mx = 0;
    while (v != u) {
        mx = max(mx, pw[v]);
        v = par[v];
    }
    return mx;
}

int main() {
    int n = 4;
    vector<Edge> edges = {
        {1, 2, 1}, {2, 3, 2}, {3, 4, 3},
        {1, 3, 4}, {2, 4, 5}, {1, 4, 10},
    };
    sort(edges.begin(), edges.end(),
         [](const Edge& a, const Edge& b) { return a.w < b.w; });

    vector<int> p(n + 1);
    iota(p.begin(), p.end(), 0);
    vector<vector<pair<int, int>>> adj(n + 1);
    vector<char> in_mst(edges.size(), 0);
    long long res = 0;
    for (int i = 0; i < (int)edges.size(); i++) {
        if (unite(p, edges[i].u, edges[i].v)) {
            adj[edges[i].u].push_back({edges[i].v, edges[i].w});
            adj[edges[i].v].push_back({edges[i].u, edges[i].w});
            in_mst[i] = 1;
            res += edges[i].w;
        }
    }
    cout << "MST weight = " << res << endl;

    long long ans = 1e18;
    for (int i = 0; i < (int)edges.size(); i++) {
        if (in_mst[i]) continue;
        int k = max_on_path(adj, edges[i].u, edges[i].v);
        long long cand = res + edges[i].w - k;
        cout << "add " << edges[i].u << "-" << edges[i].v
             << " w=" << edges[i].w << " drop " << k
             << " -> " << cand << endl;
        ans = min(ans, cand);
    }
    cout << "second best = " << ans << endl;
    return 0;
}
`}

## Binary lifting sketch

Root the MST. For each node store:

```text
up[v][j]  = 2ʲ-th ancestor
dp[v][j]  = (max, second_max) edge weights on the jump v → up[v][j]
```

`combine` merges two `(max, second_max)` pairs. Query `lca(u,v)` while folding `dp` along both ascent paths → heaviest (and second-heaviest) edge on the cycle when you add `(u,v)`.

When the strict maximum equals `w(e)` (degenerate), fall back to the second maximum.

```cpp
pair<int,int> combine(pair<int,int> a, pair<int,int> b) {
    // return top-two distinct values among {a.first,a.second,b.first,b.second}
}

pair<int,int> path_max(int u, int v); // lift + combine along u..v in the tree

// for each non-MST edge e=(s,e) with weight w:
auto rem = path_max(s, e);
int k = (rem.first != w) ? rem.first : rem.second;
ans = min(ans, res + w - k);
```

## Cheat sheet

| Idea | Takeaway |
|---|---|
| Structure | Second-best = MST with one edge swap |
| Slow | Forbid each MST edge, re-Kruskal → `O(V E)` |
| Fast | For each `e ∉ T`, drop max on cycle → `O(E log V)` with LCA |
| Tool | Binary lifting + path max (top-two) |
| Output | `res + min (w(e) − w(k))` |
