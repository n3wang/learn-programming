<Exercise title="9.5b.4 Bit reverse (3 bits)" anchor="exercise-cp-95-bitrev">

:::tip Activity: Reverse bits of 1
With 3 bits, bit-reverse of $1$ ($001$) is $4$ ($100$). Print that integer.

No input.

<CodeExercise
  title="Bit reverse 1 → 4"
  heading="exercise-cp-95-bitrev"
  lang="python"
  filename="main.py"
  prompt="3-bit reverse of 1; print the integer."
  sampleLog={`4`}
  starter={`x = 1
bits = 3
rev = 0
# TODO: reverse lowest bits of x
`}
  wrapSuffix={`
print(rev)
`}
  hint="Loop bits times: rev = (rev<<1) | (x&1); x >>= 1."
  solution={`x = 1
bits = 3
rev = 0
for _ in range(bits):
    rev = (rev << 1) | (x & 1)
    x >>= 1
`}
  sourceChecks={[
    {name: 'shifts', pattern: '<<|>>', must: true, hint: 'use bit shifts'},
  ]}
  tests={[
    {name: 'rev1', equals: '4'},
  ]}
/>

:::

</Exercise>

<Exercise title="9.5b.5 Full 0..7 bit-rev order" anchor="exercise-cp-95-order">

<CodeExercise
  title="Bit-rev permutation"
  heading="exercise-cp-95-order"
  lang="python"

  prompt="Print 3-bit reversed order of 0..7 as spaces."
  sampleLog={`0 4 2 6 1 5 3 7`}
  starter={`def bitrev(x, bits):
    rev = 0
    for _ in range(bits):
        rev = (rev << 1) | (x & 1)
        x >>= 1
    return rev

bits = 3
# TODO: build list / string for i in 0..7
out = ''
`}
  wrapSuffix={`
print(out)
`}
  hint="Join bitrev(i,3) for i in range(8)."
  solution={`def bitrev(x, bits):
    rev = 0
    for _ in range(bits):
        rev = (rev << 1) | (x & 1)
        x >>= 1
    return rev

bits = 3
out = ' '.join(str(bitrev(i, bits)) for i in range(8))
`}
  sourceChecks={[
    {name: 'joins eight', pattern: 'join|for', must: true, hint: 'map all eight indices'},

  ]}

</Exercise>
