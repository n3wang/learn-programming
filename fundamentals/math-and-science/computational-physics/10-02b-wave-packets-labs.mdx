<Exercise title="10.2b.3 Product vs $2\pi$" anchor="exercise-cp-102-prod">

<CodeExercise
  title="Product Δt Δω"

  filename="main.py"
  prompt="Print (N*2π/ω0)*(ω0/N) with 10 decimals."

  wrapSuffix={`

<Exercise title="10.2b.5 Uncertainty $C$" anchor="exercise-cp-102-C">

:::tip Activity: $C=\Delta t\Delta\omega/(2\pi)$
For the $N$-cycle estimates above, print $C$ with **10 decimals**.

No input.

<CodeExercise
  title="Uncertainty C"
  heading="exercise-cp-102-C"
  lang="python"
  filename="main.py"
  prompt="C = (Δt Δω)/(2π) for the N=6 burst; 10 decimals."
  sampleLog={`1.0000000000`}
  starter={`import math

N, omega0 = 6.0, 5.0
C = 0.0  # TODO
`}
  wrapSuffix={`
print(f"{C:.10f}")
`}
  hint="Product is exactly 2π → C=1."
  solution={`import math

N, omega0 = 6.0, 5.0
dt = N * 2.0 * math.pi / omega0
dw = omega0 / N
C = (dt * dw) / (2.0 * math.pi)
`}
  sourceChecks={[
    {name: 'divides 2pi', pattern: 'pi', must: true, hint: 'divide by 2π'},
  ]}
  tests={[
    {name: 'C', equals: '1.0000000000'},
  ]}
/>

:::

</Exercise>
