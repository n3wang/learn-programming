# 5.6b Mean-value and high-D labs

> **Source:** Lab ideas from *Computational Physics* (Landau, Páez, Bordeianu), §5.6. Rewritten as original drills. Continues [5.6 Mean-value theorem and high-D Monte Carlo](./05-06-mean-value-nd).

Practice the mean-value rule in 1D, then the 10D integral $I=\int_{[0,1]^{10}}(\sum x_i)^{2}\,d^{10}x=155/6$. Use the chapter LCG only.

:::note Fixed LCG
`r ← (1103515245 * r + 12345) % 2**31`, uniform `r / 2**31`. Advance before each draw.
:::
