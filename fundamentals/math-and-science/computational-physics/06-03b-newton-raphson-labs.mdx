# 6.3b Newton–Raphson labs

> **Source:** Lab ideas from *Computational Physics* (Landau, Páez, Bordeianu), §6.3. Rewritten as original drills — **not** textbook `NewtonCD.py`. Continues [6.3 Newton–Raphson search](./06-03-newton-raphson).

Implement Newton with a **forward-difference** derivative ($\delta x=10^{-6}$), apply it to the even square-well residual, compare iteration counts with bisection, and add backtracking.

**Newton convention for graded output:** start at $x_0$; each iteration evaluate $f(x)$; stop if $|f|<\varepsilon$; else $f'\leftarrow\bigl(f(x+\delta x)-f(x)\bigr)/\delta x$, $\Delta x\leftarrow -f/f'$, $x\leftarrow x+\Delta x$; also stop if $|\Delta x|<\varepsilon$. Use $\varepsilon=10^{-14}$. Count the iteration number $n$ of the successful stop (first $n$ with $|f|<\varepsilon$ or $|\Delta x|<\varepsilon$).

Even residual (same as §6.2b):

$$
g(E)=\sqrt{E}\,\cot\sqrt{V_0-E}-\sqrt{V_0-E},
\quad\cot\theta=\cos\theta/\sin\theta.
$$

  hint="Newton: for n in 1..maxit — check |f|, update, return n when done. Bisection: count each while-loop midpoint as in 6.2b."
  solution={`import math

def g(E, V0=10.0):
    ke = math.sqrt(E)
    kappa = math.sqrt(V0 - E)
    return ke * math.cos(kappa) / math.sin(kappa) - kappa

def newton_iters(f, x0, eps=1e-14, dx=1e-6, maxit=100):
    x = float(x0)
    for n in range(1, maxit + 1):
        fx = f(x)
        if abs(fx) < eps:
            return n
        dfdx = (f(x + dx) - fx) / dx
        step = -fx / dfdx
        x = x + step
        if abs(step) < eps:
            return n
    return maxit

def bisect_iters(f, a, b, eps=1e-14):
    fa = f(a)
    n = 0
    while (b - a) / 2 > eps:
        n += 1
        m = (a + b) / 2
        fm = f(m)
        if fa * fm <= 0:
            b = m
        else:
            a = m
            fa = fm
    return n
`}
  sourceChecks={[
    {name: 'counts both', pattern: 'for|while', must: true, hint: 'loop and return the iteration counters'},
  ]}
  tests={[
    {name: '5 vs 46', equals: '5 46'},
  ]}

<Exercise title="6.3b.6 Backtracking from a rough start" anchor="exercise-cp-newton-backtrack">

:::tip Activity: Backtracking from a rough start
Modify Newton: after computing $\Delta x$, if $|f(x+\Delta x)|^2>|f(x)|^2$ (or the trial leaves $(0.01,9.99)$), try $\Delta x/2$, $\Delta x/4$, … until $|f|$ does not grow. Start from $x_0=0.5$ on $V_0=10$ and print $E$ with 10 decimals.

No input.

<CodeExercise
  title="Backtracking from a rough start"

  filename="main.py"
  prompt="Newton with backtracking from 0.5; print E to 10 decimals."
  sampleLog={`8.5927852752`}
  starter={`import math

def g(E, V0=10.0):
    return 0.0

def newton_bt(f, x0, eps=1e-14, dx=1e-6, maxit=100, lo=0.01, hi=9.99):
    # TODO: Newton + shrink Δx while |f| grows
    return 0.0
`}
  wrapSuffix={`
print(f"{newton_bt(g, 0.5):.10f}")
`}
  hint="After step=-f/f′, set s=step; while trial out of (lo,hi) or |f(x+s)|²>|f|²: s*=0.5. Then x+=s."
  solution={`import math

def g(E, V0=10.0):
    ke = math.sqrt(E)
    kappa = math.sqrt(V0 - E)
    return ke * math.cos(kappa) / math.sin(kappa) - kappa

def newton_bt(f, x0, eps=1e-14, dx=1e-6, maxit=100, lo=0.01, hi=9.99):
    x = float(x0)
    for _ in range(maxit):
        fx = f(x)
        if abs(fx) < eps:
            return x
        dfdx = (f(x + dx) - fx) / dx
        step = -fx / dfdx
        s = step
        for _k in range(40):
            xn = x + s
            if lo < xn < hi and f(xn) * f(xn) <= fx * fx:
                break
            s *= 0.5
        x = x + s
        if abs(s) < eps:
            return x
    return x
`}
  sourceChecks={[
    {name: 'shrinks step', pattern: '0\\.5|\\/\\s*2|\\*=\\s*0\\.5', must: true, hint: 'halve Δx while |f| grows'},
  ]}

    {name: 'E_B from 0.5', equals: '8.5927852752'},
