<Exercise title="12.1b.1 Qubit dimension" anchor="exercise-cp-121-dim">

:::tip Activity: $2^n$
For $n=3$ qubits, print the Hilbert-space dimension.

No input.

<CodeExercise
  title="dim = 2**n"
  heading="exercise-cp-121-dim"
  lang="python"
  filename="main.py"
  prompt="2**3."
  sampleLog={`8`}
  starter={`n = 3
dim = 0  # TODO
`}
  wrapSuffix={`
print(dim)
`}
  hint="2 ** n."
  solution={`n = 3
dim = 2 ** n
`}
  sourceChecks={[
    {name: 'pow', pattern: '\\*\\*|pow', must: true, hint: 'power of two'},
  ]}
  tests={[
    {name: 'dim', equals: '8'},
  ]}
/>

:::

</Exercise>

<Exercise title="12.1b.2 |0⟩⟨0| entry" anchor="exercise-cp-121-proj">

:::tip Activity: Projector $(0,0)$
Print the $(0,0)$ entry of $|0\rangle\langle0|=\mathrm{diag}(1,0)$ with **10 decimals**.

No input.

<CodeExercise
  title="Projector 00"
  heading="exercise-cp-121-proj"
  lang="python"
  filename="main.py"
  prompt="1.0 with 10 decimals."
  sampleLog={`1.0000000000`}
  starter={`P00 = 0.0  # TODO top-left of |0><0|
`}
  wrapSuffix={`
print(f"{P00:.10f}")
`}
  hint="It's 1."
  solution={`P00 = 1.0
`}
  sourceChecks={[
    {name: 'one', pattern: '1', must: true, hint: 'top-left is 1'},
  ]}
  tests={[
    {name: 'P00', equals: '1.0000000000'},
  ]}
/>

:::

</Exercise>

<Exercise title="12.1b.3 Inner-product conjugate" anchor="exercise-cp-121-conj">

:::tip Activity: $\langle\phi\mid\psi\rangle=\langle\psi\mid\phi\rangle^{*}$
If $\langle\psi\mid\phi\rangle=2+3i$, print the real and imaginary parts of $\langle\phi\mid\psi\rangle$ space-separated with **10 decimals**.

No input.

<CodeExercise
  title="Conjugate bracket"
  heading="exercise-cp-121-conj"
  lang="python"
  filename="main.py"
  prompt="conj(2+3j) parts."
  sampleLog={`2.0000000000 -3.0000000000`}
  starter={`z = 2 + 3j
w = 0j  # TODO conjugate
`}
  wrapSuffix={`
print(f"{w.real:.10f} {w.imag:.10f}")
`}
  hint="w = z.conjugate()."
  solution={`z = 2 + 3j
w = z.conjugate()
`}
  sourceChecks={[
    {name: 'conj', pattern: 'conjugate|\\.real|conj', must: true, hint: 'complex conjugate'},
  ]}
  tests={[
    {name: 'w', equals: '2.0000000000 -3.0000000000'},
  ]}
/>

:::

</Exercise>

<Exercise title="12.1b.4 |0⟩ components" anchor="exercise-cp-121-ket0">

:::tip Activity: Column vector

No input.

<CodeExercise
  title="|0⟩"
  heading="exercise-cp-121-ket0"
  lang="python"

</Exercise>
