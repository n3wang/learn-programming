<Exercise title="10.6b.9 Largest eigenvalue" anchor="exercise-cp-106-smith-lam1">

For $C=\begin{bmatrix}a&b\\b&c\end{bmatrix}$:
$\lambda=\frac{a+c\pm\sqrt{(a+c)^2-4(ac-b^2)}}{2}$.

No input.

<CodeExercise
  title="Smith λ₁"
  heading="exercise-cp-106-smith-lam1"
  lang="python"
  filename="main.py"
  prompt="Larger eigenvalue of C; 10 decimals."
  sampleLog={`1.2840277122`}
  starter={`import math
raw = [
    [2.5, 2.4], [0.5, 0.7], [2.2, 2.9], [1.9, 2.2], [3.1, 3.0],
    [2.3, 2.7], [2.0, 1.6], [1.0, 1.1], [1.5, 1.6], [1.1, 0.9],
]
xs = [r[0] for r in raw]
ys = [r[1] for r in raw]
N = len(xs)
mx = sum(xs) / N
my = sum(ys) / N
a = sum((x - mx) ** 2 for x in xs) / (N - 1)
c = sum((y - my) ** 2 for y in ys) / (N - 1)
b = sum((xs[i] - mx) * (ys[i] - my) for i in range(N)) / (N - 1)
lam1 = 0.0  # TODO: (tr + sqrt(disc)) / 2
`}
  wrapSuffix={`

`}
  hint="tr=a+c; disc=tr²−4(ac−b²); take the + root."
  solution={`import math
raw = [
    [2.5, 2.4], [0.5, 0.7], [2.2, 2.9], [1.9, 2.2], [3.1, 3.0],
    [2.3, 2.7], [2.0, 1.6], [1.0, 1.1], [1.5, 1.6], [1.1, 0.9],
]
xs = [r[0] for r in raw]
ys = [r[1] for r in raw]
N = len(xs)
mx = sum(xs) / N
my = sum(ys) / N
a = sum((x - mx) ** 2 for x in xs) / (N - 1)
c = sum((y - my) ** 2 for y in ys) / (N - 1)
b = sum((xs[i] - mx) * (ys[i] - my) for i in range(N)) / (N - 1)
tr = a + c
disc = tr * tr - 4 * (a * c - b * b)
lam1 = (tr + math.sqrt(disc)) / 2
`}
