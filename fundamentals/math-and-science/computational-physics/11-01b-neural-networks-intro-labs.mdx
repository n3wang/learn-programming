<Exercise title="11.1b.1 Neuron count order" anchor="exercise-cp-111-neurons">

:::tip Activity: $10^{11}$
Print the approximate number of neurons in a human brain as an integer ($10^{11}$).

No input.

<CodeExercise
  title="10**11"
  heading="exercise-cp-111-neurons"
  lang="python"
  filename="main.py"
  prompt="Print 10**11."
  sampleLog={`100000000000`}
  starter={`n = 0  # TODO: 10**11
`}
  wrapSuffix={`
print(n)
`}
  hint="10 ** 11."
  solution={`n = 10 ** 11
`}
  sourceChecks={[
    {name: 'power', pattern: '\\*\\*|pow|e\\+|E\\+', must: true, hint: '10 to the 11'},
  ]}
  tests={[
    {name: 'n', equals: '100000000000'},
  ]}
/>

:::

</Exercise>

<Exercise title="11.1b.2 Pulse width midpoint" anchor="exercise-cp-111-ms">

:::tip Activity: Mid of $1$–$6\,\mathrm{ms}$
Print the midpoint of the $1$–$6\,\mathrm{ms}$ action-potential width range with **10 decimals**.

No input.

<CodeExercise
  title="Mid pulse width"
  heading="exercise-cp-111-ms"
  lang="python"
  filename="main.py"
  prompt="(1+6)/2; 10 decimals."
  sampleLog={`3.5000000000`}
  starter={`mid = 0.0  # TODO
`}
  wrapSuffix={`
print(f"{mid:.10f}")
`}
  hint="Average of endpoints."
  solution={`mid = (1.0 + 6.0) / 2.0
`}
  sourceChecks={[
    {name: 'avg', pattern: '\\+|/', must: true, hint: '(1+6)/2'},
  ]}
  tests={[
    {name: 'mid', equals: '3.5000000000'},
  ]}
/>

:::

</Exercise>

<Exercise title="11.1b.3 Excitatory vs inhibitory" anchor="exercise-cp-111-sign">

:::tip Activity: Net voltage
Three pulses contribute $+2$, $-1$, $+3$ (arbitrary units). Print the net sum with **10 decimals**.

No input.

<CodeExercise
  title="Integrate pulses"
  heading="exercise-cp-111-sign"
  lang="python"
  filename="main.py"
  prompt="2 + (-1) + 3; 10 decimals."
  sampleLog={`4.0000000000`}
  starter={`net = 0.0  # TODO
`}
  wrapSuffix={`
print(f"{net:.10f}")
`}
  hint="Just add."
  solution={`net = 2.0 + (-1.0) + 3.0
`}
  sourceChecks={[
    {name: 'sum', pattern: '\\+', must: true, hint: 'sum the pulses'},
  ]}
  tests={[
    {name: 'net', equals: '4.0000000000'},
  ]}
/>

:::

</Exercise>

<Exercise title="11.1b.4 Threshold fire" anchor="exercise-cp-111-thresh">

:::tip Activity: Binary fire
If net voltage is $4$ and threshold is $3$, print `1` if the neuron fires, else `0`.

No input.

<CodeExercise
  title="Threshold"
  heading="exercise-cp-111-thresh"
  lang="python"
  filename="main.py"
  prompt="fire = 1 if net>=thresh else 0."
  sampleLog={`1`}
  starter={`net, thresh = 4.0, 3.0
fire = 0  # TODO
`}
  wrapSuffix={`
print(fire)
`}
  hint="Compare net to thresh."
  solution={`net, thresh = 4.0, 3.0
fire = 1 if net >= thresh else 0
`}
  sourceChecks={[
    {name: 'compare', pattern: '>=|>|if', must: true, hint: 'threshold test'},
  ]}
  tests={[
    {name: 'fire', equals: '1'},
  ]}
/>

:::

</Exercise>
