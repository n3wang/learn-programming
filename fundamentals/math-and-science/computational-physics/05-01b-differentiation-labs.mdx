<Exercise title="5.1b.1 Forward difference" anchor="exercise-cp-diff-fd">

:::tip Activity: Forward difference
Given $t$, $h$, and coefficients for $y(t)=a+b t^{2}$, print the forward-difference estimate of $y'(t)$ with 6 decimals.

Input: `a b t h`.

<CodeExercise
  title="Forward difference"
  heading="exercise-cp-diff-fd"
  lang="python"
  filename="main.py"
  prompt="(y(t+h)-y(t))/h for y=a+b t²."
  sampleLog={`(input) 2 3 1.0 0.1
6.300000`}
  starter={`def y(a, b, t):
    return a + b * t * t

def forward(a, b, t, h):
    return 0.0
`}
  wrapSuffix={`
a, b, t, h = map(float, input().split())
print(f"{forward(a, b, t, h):.6f}")
`}
  hint="return (y(a,b,t+h)-y(a,b,t))/h"
  solution={`def y(a, b, t):
    return a + b * t * t

def forward(a, b, t, h):
    return (y(a, b, t + h) - y(a, b, t)) / h
`}
  sourceChecks={[
    {name: 'uses forward stencil', pattern: 't\\s*\\+\\s*h|t\\+h', must: true, hint: 'evaluate at t+h'},
  ]}
  tests={[
    {name: 'parabola bias', stdin: '2 3 1.0 0.1', equals: '6.300000'},
    {name: 'smaller h', stdin: '2 3 1.0 0.01', equals: '6.030000'},
  ]}
/>

:::

</Exercise>

<Exercise title="5.1b.2 Central difference" anchor="exercise-cp-diff-cd">

:::tip Activity: Central difference
Same $y=a+bt^{2}$. Print the central difference $(y(t+h/2)-y(t-h/2))/h$ with 6 decimals — should match the exact $2bt$.

Input: `a b t h`.

<CodeExercise
  title="Central difference"
  heading="exercise-cp-diff-cd"
  lang="python"
  filename="main.py"
  prompt="Central difference for y=a+b t²."
  sampleLog={`(input) 2 3 1.0 0.1
6.000000`}
  starter={`def y(a, b, t):
    return a + b * t * t

def central(a, b, t, h):
    return 0.0
`}
  wrapSuffix={`
a, b, t, h = map(float, input().split())
print(f"{central(a, b, t, h):.6f}")
`}
  hint="(y(t+h/2)-y(t-h/2))/h"
  solution={`def y(a, b, t):
    return a + b * t * t

def central(a, b, t, h):
    return (y(a, b, t + h / 2) - y(a, b, t - h / 2)) / h
`}
  sourceChecks={[
    {name: 'symmetric stencil', pattern: 'h\\s*/\\s*2|h/2', must: true, hint: 'use ±h/2'},
  ]}
  tests={[
    {name: 'exact on parabola', stdin: '2 3 1.0 0.1', equals: '6.000000'},
    {name: 'any h', stdin: '1 0.5 2.0 0.7', equals: '2.000000'},
  ]}
/>

:::

</Exercise>

  sampleLog={`(input) 0.1
4.293855e-02 2.250978e-04`}
  starter={`import math

def errors(h, t=1.0):
    # return (abs_fd_err, abs_cd_err)
    return 0.0, 0.0
`}
  wrapSuffix={`
h = float(input())
a, b = errors(h)
print(f"{a:.6e} {b:.6e}")
`}
  hint="fd=(sin(t+h)-sin(t))/h; cd=(sin(t+h/2)-sin(t-h/2))/h; compare to cos(t)."
  solution={`import math

def errors(h, t=1.0):
    exact = math.cos(t)
    fd = (math.sin(t + h) - math.sin(t)) / h
    cd = (math.sin(t + h / 2) - math.sin(t - h / 2)) / h
    return abs(fd - exact), abs(cd - exact)
`}
  sourceChecks={[
    {name: 'uses sin/cos', pattern: 'math\\.sin|math\\.cos', must: true, hint: 'differentiate sin numerically'},
  ]}
  tests={[
    {name: 'h=0.1', stdin: '0.1', equals: '4.293855e-02 2.250978e-04'},

<ProblemSet id="cp-51b-assess">
  <Problem
    type="concept"
    title="5.1b.W1"
    minWords={3}
    keywords={['cancel', 'epsilon', 'h']}
    prompt={`Why can making $h$ extremely small make a numerical derivative worse?`}
    answer={`y(t+h) and y(t) become so close that their difference is swamped by machine epsilon, while dividing by a tiny h amplifies that noise — truncation falls, round-off rises.`}
  />
  <Problem
    type="concept"
    title="5.1b.W2"
    minWords={3}
    keywords={['central', 'even', 'h2']}
    prompt={`Why does central difference beat forward difference for smooth $y$?`}
    answer={`The ±h/2 Taylor expansions cancel even powers of h, so the leading error is O(h²) instead of O(h). For a parabola, the central formula is even exact.`}
  />
  <Problem
    type="concept"
    title="5.1b.W3"
    minWords={2}
    keywords={['forward', 'neighbor']}
    prompt={`When might you still use a forward difference?`}
    answer={`When you only know the function to the right of t (end of a table, causal streaming) and cannot evaluate y(t−h/2).`}
  />
</ProblemSet>
