# 5.5b Monte Carlo integration labs

> **Source:** Lab ideas from *Computational Physics* (Landau, Páez, Bordeianu), §5.5. Rewritten as original drills. Continues [5.5 Monte Carlo integration](./05-05-monte-carlo-integration).

Estimate $\pi$ by stone throwing and $\int_0^1 e^{-x}\,dx$ by mean-value Monte Carlo. Graded randomness uses the **chapter LCG** only — not `random.random()`.

:::note Fixed LCG
`r ← (1103515245 * r + 12345) % 2**31`, then uniform `r / 2**31`. Default seed is `1` unless the prompt says otherwise. Advance the state **before** each draw (seed itself is not a sample).
:::

:::tip Activity: Stone-throw $\pi$ ($N=10000$)

## Explorers

```python
# mc_stone.py — chapter LCG stone throw (original sketch)
M = 2**31

def rnd(r):
    r = (1103515245 * r + 12345) % M
    return r, r / M

def pi_est(N, seed=1):
    r, hits = seed, 0
    for _ in range(N):
        r, u = rnd(r)
        r, v = rnd(r)
        x, y = 2 * u - 1, 2 * v - 1
        if x * x + y * y <= 1:
            hits += 1
    return 4 * hits / N
```
