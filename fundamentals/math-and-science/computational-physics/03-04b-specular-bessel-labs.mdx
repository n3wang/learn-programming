# 3.4b Specular and Bessel labs

> **Source:** Lab ideas from *Computational Physics* (Landau, Páez, Bordeianu), §§3.3.2–3.4.2. Rewritten as original drills. Continues [3.4 Specular reflection and Bessel theory](./03-04-specular-bessel-theory). Next: [4.1 Monte Carlo — random numbers](./04-01-monte-carlo-random).

Two tracks in one activity set: **specular rays** ($\theta\leftarrow\theta+2\phi$) and **spherical Bessel** $j_\ell(x)$ (upward vs Miller downward). Stubs fail until you write the logic. Explorers live at the bottom for reference while you work.

<Exercise title="3.4b.2 Four-digit round-off" anchor="exercise-cp-specular-round">

:::tip Activity: Four-digit round-off
Repeat the path with `round(·, digits)` applied to $\phi$ and to $\theta$ after every update. Report the **maximum** Euclidean distance between corresponding full-precision and rounded hit points (including the start).

Input: `phi bounces digits`. Output: one line, scientific notation with 6 digits (`:.6e`).

  prompt="Compare full vs round(φ,θ,digits) paths; print max chord error."
  sampleLog={`(input) 0.314159 200 4
1.639982e-02`}
  starter={`import math

def max_path_error(phi, bounces, digits):
    # return max Euclidean distance between full and rounded paths
    return 0.0
`}
  wrapSuffix={`
phi, bounces, digits = input().split()
print(f"{max_path_error(float(phi), int(bounces), int(digits)):.6e}")
`}
  hint="Build two paths. Rounded: φr=round(phi,digits); each step θ=round(θ+2*φr, digits). Track max hypot(dx,dy)."
  solution={`import math

def path(phi, bounces, digits=None):
    theta = 0.0
    pts = []
    for _ in range(bounces + 1):
        t = round(theta, digits) if digits is not None else theta
        pts.append((math.cos(t), math.sin(t)))
        step = 2.0 * (round(phi, digits) if digits is not None else phi)
        nxt = t + step
        theta = round(nxt, digits) if digits is not None else nxt
    return pts

def max_path_error(phi, bounces, digits):
    full = path(phi, bounces, None)
    rnd = path(phi, bounces, digits)
    return max(math.hypot(a[0] - b[0], a[1] - b[1]) for a, b in zip(full, rnd))
`}
  sourceChecks={[
    {name: 'uses round', pattern: 'round\\s*\\(', must: true, hint: 'round(·, digits) on φ and θ'},
    {name: 'uses hypot or distance', pattern: 'hypot|\\*\\*\\s*0\\.5|math\\.sqrt', must: true, hint: 'Euclidean distance between hit points'},
  ]}
  tests={[
    {
      name: 'drift at 4 digits',
      stdin: '0.314159 200 4',
      equals: '1.639982e-02',
    },
    {
      name: 'π/7 shorter',
      stdin: '0.448798950513 80 4',

<Exercise title="3.4b.3 Downward j_ℓ" anchor="exercise-cp-bessel-down">

:::tip Activity: Downward $j_\ell$
Miller downward recursion: seed $j_{L}=j_{L+1}=1$ at large `start`, recur

$j_{k-1}=\dfrac{2k+1}{x}j_k - j_{k+1}$,

then scale so $j_0=\sin x/x$. Return $j_\ell$.

Input: `x ell start`. Output: one float in `:.10e`.

<CodeExercise
  title="Downward j_ℓ"
  heading="exercise-cp-bessel-down"
  lang="python"
  filename="main.py"
  prompt="Miller downward recursion + normalize to sin(x)/x."
  sampleLog={`(input) 0.1 3 50
9.5185197209e-06`}
  starter={`import math

def j_down(x, ell, start=50):
    # Miller downward; return j_ell(x)
    return 0.0
`}
  wrapSuffix={`
x, ell, start = input().split()
print(f"{j_down(float(x), int(ell), int(start)):.10e}")
`}
  hint="Array j[0..start+1]; j[start]=j[start+1]=1; for k=start..1: j[k-1]=(2k+1)/x*j[k]-j[k+1]; scale=(sin(x)/x)/j[0]; return j[ell]*scale."
  solution={`import math

def j_down(x, ell, start=50):
    j = [0.0] * (start + 2)
    j[start] = 1.0
    j[start + 1] = 1.0
    for k in range(start, 0, -1):
        j[k - 1] = ((2.0 * k + 1.0) / x) * j[k] - j[k + 1]
    scale = (math.sin(x) / x) / j[0]
    return j[ell] * scale
`}
  sourceChecks={[
    {name: 'normalizes with sin', pattern: 'math\\.sin', must: true, hint: 'scale with sin(x)/x'},
    {name: 'downward loop', pattern: 'range\\s*\\([^)]+-\\s*1\\s*\\)|reversed', must: true, hint: 'recur from large ℓ downward'},
  ]}
  tests={[
    {name: 'table j3(0.1)', stdin: '0.1 3 50', equals: '9.5185197209e-06'},
    {name: 'table j5(1)', stdin: '1 5 50', equals: '9.2561158611e-05'},
    {name: 'table j8(10)', stdin: '10 8 50', equals: '1.2557802365e-01'},
  ]}
/>

<Exercise title="3.4b.4 Up vs down compare" anchor="exercise-cp-bessel-compare">

:::tip Activity: Up vs down
Compute $j_\ell$ by **upward** recurrence from $j_0,j_1$ and by **downward** Miller (`start` given). For $\ell=0..L_{\max}$ print

`ell status`

where `status` is `agree` if

$|j_{\mathrm{up}}-j_{\mathrm{down}}| / (|j_{\mathrm{up}}|+|j_{\mathrm{down}}|) < 10^{-6}$

and `disagree` otherwise (add $10^{-30}$ in the denominator if both vanish).

Input: `x Lmax start`. Output: $L_{\max}+1$ rows.

<CodeExercise
  title="Up vs down compare"
  heading="exercise-cp-bessel-compare"
  lang="python"
  filename="main.py"
  prompt="Print ℓ and agree/disagree for upward vs Miller downward."
  sampleLog={`(input) 0.1 8 50
0 agree
1 agree
2 agree
3 agree
4 disagree
5 disagree
6 disagree
7 disagree
8 disagree`}
  starter={`import math

def j0(x):
    return math.sin(x) / x

def j1(x):
    return math.sin(x) / x**2 - math.cos(x) / x

def j_up(x, ell):
    # upward from j0, j1
    return 0.0

def j_down(x, ell, start=50):
    return 0.0

def compare_row(x, ell, start, tol=1e-6):
    # return 'ell agree' or 'ell disagree'
    return f"{ell} disagree"
`}
  wrapSuffix={`
x, Lmax, start = input().split()
x = float(x)
Lmax = int(Lmax)
start = int(start)
for ell in range(Lmax + 1):
    print(compare_row(x, ell, start))
`}
  hint="up: start j0,j1; jp1=(2ℓ+1)/x*j-jm1. down: same as previous lab. rel=abs(u-d)/(abs(u)+abs(d)+1e-30); agree if rel<1e-6."
  solution={`import math

def j0(x):
    return math.sin(x) / x

def j1(x):
    return math.sin(x) / x**2 - math.cos(x) / x

def j_up(x, ell):
    if ell == 0:
        return j0(x)
    if ell == 1:
        return j1(x)
    jm1, j = j0(x), j1(x)
    for k in range(1, ell):
        jp1 = ((2.0 * k + 1.0) / x) * j - jm1
        jm1, j = j, jp1
    return j

def j_down(x, ell, start=50):
    j = [0.0] * (start + 2)
    j[start] = 1.0
    j[start + 1] = 1.0
    for k in range(start, 0, -1):
        j[k - 1] = ((2.0 * k + 1.0) / x) * j[k] - j[k + 1]
    scale = j0(x) / j[0]
    return j[ell] * scale

def compare_row(x, ell, start, tol=1e-6):
    u = j_up(x, ell)
    d = j_down(x, ell, start)
    rel = abs(u - d) / (abs(u) + abs(d) + 1e-30)
    return f"{ell} {'agree' if rel < tol else 'disagree'}"
`}
  sourceChecks={[
    {name: 'has upward', pattern: 'j_up', must: true, hint: 'implement upward recurrence'},
    {name: 'has downward', pattern: 'j_down', must: true, hint: 'implement Miller downward'},
    {name: 'agree/disagree', pattern: 'agree|disagree', must: true, hint: 'label each ℓ agree or disagree'},
  ]}
  tests={[
    {
      name: 'x=0.1 upward fails',
      stdin: '0.1 8 50',
      equals: '0 agree\n1 agree\n2 agree\n3 agree\n4 disagree\n5 disagree\n6 disagree\n7 disagree\n8 disagree',
    },
    {
      name: 'x=10 both stable',
      stdin: '10 8 50',
      equals: '0 agree\n1 agree\n2 agree\n3 agree\n4 agree\n5 agree\n6 agree\n7 agree\n8 agree',
    },
  ]}
/>
