<Exercise title="12.11b.1 Dipole H₀₀" anchor="exercise-cp-1211-h00">

:::tip Activity: $ZZ$ diagonal
For $H\propto XX+YY+ZZ-3ZZ$, the $|00\rangle$ diagonal entry of $XX+YY+ZZ-3ZZ$ equals $-2$ (from $ZZ-3ZZ=-2ZZ$ and $XX,YY$ zeros on that slot). Print that diagonal value with **10 decimals**.

No input.

<CodeExercise
  title="H00"
  heading="exercise-cp-1211-h00"
  lang="python"
  filename="main.py"
  prompt="-2"
  sampleLog={`-2.0000000000`}
  starter={`h00 = 0.0  # TODO
`}
  wrapSuffix={`
print(f"{h00:.10f}")
`}
  hint="−2 from the ZZ combination on |00⟩."
  solution={`h00 = -2.0
`}
  sourceChecks={[
    {name: 'neg', pattern: '-', must: true, hint: '-2'},
  ]}
  tests={[
    {name: 'h', equals: '-2.0000000000'},
  ]}
/>

</Exercise>

<Exercise title="12.11b.3 Grover R with N=16" anchor="exercise-cp-1211-R">

:::tip Activity: Use $N$, not $n$

No input.

<CodeExercise
  title="R"
  heading="exercise-cp-1211-R"
  lang="python"
  filename="main.py"
  prompt="4"

  starter={`import math

R = 0  # TODO ceil(pi*sqrt(16)/4)

`}
  hint="π ≈ 3.14 → ceil(3.14)=4. Do not use sqrt(4)."

`}
  sourceChecks={[
    {name: 'sqrt16', pattern: 'sqrt\\(16|16\\.0|\\*\\* *0\\.5', must: true, hint: '√16 not √4'},
  ]}
  tests={[
    {name: 'R', equals: '4'},
  ]}
/>

:::

</Exercise>
