<Exercise title="7.5b.2 Newton on the circle/line system" anchor="exercise-cp-75-newton">

:::tip Activity: 2D Newton
Solve $\mathbf f(x,y)=\mathbf 0$ with $f_1=x^{2}+y^{2}-1$, $f_2=3x-y-1$. Start at $(0.5,0.5)$. Use the analytic Jacobian

$$
J=\begin{pmatrix}2x&2y\\3&-1\end{pmatrix}
$$

and iterate until $\|\Delta\mathbf x\|$ is tiny. Print the root with 6 decimals as `x y`.

No input.

<CodeExercise
  title="Newton on the circle/line system"
  heading="exercise-cp-75-newton"
  lang="python"
  filename="main.py"
  prompt="2D Newton from (0.5,0.5) on f=[x²+y²−1, 3x−y−1]; print root 6 decimals."
  sampleLog={`0.600000 0.800000`}
  starter={`def newton2d(x0=0.5, y0=0.5, tol=1e-14, maxit=50):
    x, y = x0, y0
    # TODO: iterate J Δ = -f until converged; return (x, y)
    return x, y
`}
  wrapSuffix={`
x, y = newton2d()
print(f"{x:.6f} {y:.6f}")
`}
  hint="f=[x*x+y*y-1, 3*x-y-1]. Solve 2×2 J d = -f each step (Cramer or explicit inverse). Update x,y."
  solution={`def newton2d(x0=0.5, y0=0.5, tol=1e-14, maxit=50):
    x, y = x0, y0
    for _ in range(maxit):
        f1 = x * x + y * y - 1.0
        f2 = 3.0 * x - y - 1.0
        a, b, c, d = 2.0 * x, 2.0 * y, 3.0, -1.0
        u, v = -f1, -f2
        det = a * d - b * c
        dx = (u * d - b * v) / det
        dy = (a * v - u * c) / det
        x += dx
        y += dy
        if abs(dx) + abs(dy) < tol:
            break
    return x, y
`}
  sourceChecks={[
    {name: 'uses residual f', pattern: 'x\s*\\*\s*x|x\s*\\*\\*\s*2', must: true, hint: 'evaluate f1 = x²+y²−1'},
    {name: 'not hard-coded root', pattern: 'return\s+0\\.6\s*,\s*0\\.8', must: false, hint: 'iterate Newton, do not hard-code the root'},
  ]}
  tests={[
    {name: 'root 0.6 0.8', equals: '0.600000 0.800000'},
  ]}
/>

:::

```python
# string_newton_ref.py — 2D Newton on unit circle ∩ line (original sketch)
def newton2d(x=0.5, y=0.5, tol=1e-14):
    for _ in range(50):
        f1 = x * x + y * y - 1.0
        f2 = 3.0 * x - y - 1.0
        a, b, c, d = 2.0 * x, 2.0 * y, 3.0, -1.0
        u, v = -f1, -f2
        det = a * d - b * c
        dx = (u * d - b * v) / det
        dy = (a * v - u * c) / det
        x, y = x + dx, y + dy
        if abs(dx) + abs(dy) < tol:
            break
    return x, y
```
