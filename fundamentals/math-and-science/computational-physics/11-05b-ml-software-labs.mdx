<Exercise title="11.5b.1 Mass number" anchor="exercise-cp-115-A">

:::tip Activity: $A=Z+N$
For $Z=1$, $N=2$ print $A$ as an integer.

No input.

<CodeExercise
  title="A = Z + N"
  heading="exercise-cp-115-A"
  lang="python"
  filename="main.py"
  prompt="Z=1, N=2; print A."
  sampleLog={`3`}
  starter={`Z, N = 1, 2
A = 0  # TODO
`}
  wrapSuffix={`
print(A)
`}
  hint="Add protons and neutrons."
  solution={`Z, N = 1, 2
A = Z + N
`}
  sourceChecks={[
    {name: 'add', pattern: '\\+', must: true, hint: 'Z+N'},
  ]}
  tests={[
    {name: 'A', equals: '3'},
  ]}
/>

:::

</Exercise>
