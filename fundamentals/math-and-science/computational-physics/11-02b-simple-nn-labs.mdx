<Exercise title="11.2b.4 Hidden then output" anchor="exercise-cp-112-forward">

:::tip Activity: Identical neurons $w=(0,1)$
With $x_1=2$, $x_2=3$, bias $0$, and every neuron using weights $(0,1)$ and sigmoid $f$, print the network output $y$ with **10 decimals**.

$h=f(0\cdot x_1+1\cdot x_2)$, then $y=f(0\cdot h+1\cdot h)$.

No input.

<CodeExercise
  title="Forward 0.7216"
  heading="exercise-cp-112-forward"
  lang="python"
  filename="main.py"
  prompt="2-2-1 forward with w=(0,1); 10 decimals."
  sampleLog={`0.7216325610`}
  starter={`import math

def sigmoid(z):
    return 1.0 / (1.0 + math.exp(-z))

x1, x2 = 2.0, 3.0
h = 0.0  # TODO
y = 0.0  # TODO
`}
  wrapSuffix={`
print(f"{y:.10f}")
`}
  hint="h = sigmoid(3); y = sigmoid(h)."
  solution={`import math

def sigmoid(z):
    return 1.0 / (1.0 + math.exp(-z))

x1, x2 = 2.0, 3.0
h = sigmoid(0.0 * x1 + 1.0 * x2)
y = sigmoid(0.0 * h + 1.0 * h)
`}
  sourceChecks={[
    {name: 'sigmoid', pattern: 'sigmoid|exp', must: true, hint: 'use logistic sigmoid'},
  ]}
  tests={[
    {name: 'y', equals: '0.7216325610'},
  ]}
/>

:::

</Exercise>
