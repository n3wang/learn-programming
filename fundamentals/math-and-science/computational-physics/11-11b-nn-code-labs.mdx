<Exercise title="11.11b.1 Sigmoid neuron output" anchor="exercise-cp-1111-neuron">

:::tip Activity: Listing hand-check
$w=(-1,1)$, $b=0$, $x=(12,8)$. Print $\sigma(w\cdot x+b)$ with **10 decimals**.

No input.

<CodeExercise
  title="Neuron feedforward"
  heading="exercise-cp-1111-neuron"
  lang="python"
  filename="main.py"
  prompt="sigmoid(-4); 10 decimals."
  sampleLog={`0.0179862100`}
  starter={`import math

def sigmoid(z):
    return 1.0 / (1.0 + math.exp(-z))

y = 0.0  # TODO
`}
  wrapSuffix={`
print(f"{y:.10f}")
`}
  hint="Dot then sigmoid."
  solution={`import math

def sigmoid(z):
    return 1.0 / (1.0 + math.exp(-z))

y = sigmoid((-1.0) * 12.0 + (1.0) * 8.0)
`}
  sourceChecks={[
    {name: 'sig', pattern: 'exp|sigmoid', must: true, hint: 'logistic sigmoid'},
  ]}
  tests={[
    {name: 'y', equals: '0.0179862100'},
  ]}
/>

:::

</Exercise>

<Exercise title="11.11b.2 Shallow net output" anchor="exercise-cp-1111-net">

:::tip Activity: $w=(0,1)$ everywhere
$x=(2,3)$. Print network output with **10 decimals** (same as §11.2).

No input.

<CodeExercise
  title="2-2-1 sketch"
  heading="exercise-cp-1111-net"
  lang="python"
  filename="main.py"
  prompt="Identical Neuron([0,1]) stack; 10 decimals."
  sampleLog={`0.7216325610`}
  starter={`import math

def sigmoid(z):
    return 1.0 / (1.0 + math.exp(-z))

h = 0.0  # TODO
y = 0.0  # TODO
`}
  wrapSuffix={`
print(f"{y:.10f}")
`}
  hint="h=sigmoid(3); y=sigmoid(h)."
  solution={`import math

def sigmoid(z):
    return 1.0 / (1.0 + math.exp(-z))

h = sigmoid(0.0 * 2.0 + 1.0 * 3.0)
y = sigmoid(0.0 * h + 1.0 * h)
`}
  sourceChecks={[
    {name: 'sig', pattern: 'exp|sigmoid', must: true, hint: 'two sigmoid stages'},
  ]}
  tests={[
    {name: 'y', equals: '0.7216325610'},
  ]}
/>

:::

</Exercise>

<Exercise title="11.11b.3 KMeans feature row" anchor="exercise-cp-1111-row">
