# 7.4b Tests-before-use labs

> **Source:** Lab ideas from *Computational Physics* (Landau, Páez, Bordeianu), §7.4. Rewritten as original drills. Continues [7.4 Tests before use](./07-02-tests-before-use).

Pure-Python lists only (no NumPy). Reuse Gauss–Jordan / elimination ideas from [7.3b](./07-01b-matrices-in-python-labs). Stubs fail until filled; floats are locked below.

**Shared test matrix**

$$
A=\begin{pmatrix}4&-2&1\\3&6&-4\\2&1&8\end{pmatrix},\qquad
A^{-1}_{\mathrm{analytic}}=\frac{1}{263}\begin{pmatrix}52&17&2\\-32&30&19\\-9&-8&30\end{pmatrix}.
$$

<Exercise title="7.4b.1 Invert A (Gauss–Jordan)" anchor="exercise-cp-74-inv">

:::tip Activity: Invert $A$ by Gauss–Jordan
Augment $[A\mid I]$, reduce the left half to $I$, and read $A^{-1}$ from the right. Print the **first row** of the inverse with 10 decimals, space-separated.

No input.

<CodeExercise
  title="Invert A (Gauss–Jordan)"
  heading="exercise-cp-74-inv"
  lang="python"
  filename="main.py"
  prompt="Gauss–Jordan invert A; print first row of A⁻¹ with 10 decimals."
  sampleLog={`0.1977186312 0.0646387833 0.0076045627`}
  starter={`def invert(A):
    # TODO: Gauss–Jordan on [A|I]; return A^{-1} as list of lists
    n = len(A)
    return [[0.0] * n for _ in range(n)]

A = [[4.0, -2.0, 1.0], [3.0, 6.0, -4.0], [2.0, 1.0, 8.0]]
`}
  wrapSuffix={`
Ainv = invert(A)
print(' '.join(f"{v:.10f}" for v in Ainv[0]))
`}
  hint="Build n×2n augmented [A|I]. For each pivot row, scale and eliminate all other rows. Right half becomes A⁻¹."
  solution={`def invert(A):
    n = len(A)
    M = [row[:] + [1.0 if i == j else 0.0 for j in range(n)] for i, row in enumerate(A)]
    for i in range(n):
        piv = M[i][i]
        for k in range(2 * n):
            M[i][k] /= piv
        for j in range(n):
            if j == i:
                continue
            f = M[j][i]
            for k in range(2 * n):
                M[j][k] -= f * M[i][k]
    return [row[n:] for row in M]

A = [[4.0, -2.0, 1.0], [3.0, 6.0, -4.0], [2.0, 1.0, 8.0]]
`}
  sourceChecks={[
    {name: 'augments identity', pattern: '1\\.0\s+if|==\s*j|range\\(2\s*\\*\s*n\\)|2\s*\\*\s*n', must: true, hint: 'work on an [A|I] augmented matrix'},
    {name: 'not hard-coded first row', pattern: 'return\s+\\[\\[0\\.1977', must: false, hint: 'compute the inverse, do not hard-code the printed row'},
  ]}
  tests={[
    {name: 'first row of Ainv', equals: '0.1977186312 0.0646387833 0.0076045627'},
  ]}
/>

:::tip Activity: Residual $\max\|AA^{-1}-I\|$

No input.

<CodeExercise
  title="Residual max|AA⁻¹−I|"
  heading="exercise-cp-74-resid-i"
  lang="python"
  filename="main.py"
  prompt="Print max|AA⁻¹−I| as :.6e after Gauss–Jordan invert."
  sampleLog={`2.220446e-16`}
  starter={`def invert(A):
    n = len(A)
    return [[0.0] * n for _ in range(n)]

def matmul(A, B):
    n = len(A)
    return [[0.0] * n for _ in range(n)]

A = [[4.0, -2.0, 1.0], [3.0, 6.0, -4.0], [2.0, 1.0, 8.0]]
`}
  wrapSuffix={`
Ainv = invert(A)
P = matmul(A, Ainv)
n = len(A)
mx = 0.0
for i in range(n):
    for j in range(n):
        mx = max(mx, abs(P[i][j] - (1.0 if i == j else 0.0)))
print(f"{mx:.6e}")
`}
  hint="Reuse Gauss–Jordan invert and a true matrix product; subtract the identity and take the max abs entry."
  solution={`def invert(A):
    n = len(A)
    M = [row[:] + [1.0 if i == j else 0.0 for j in range(n)] for i, row in enumerate(A)]
    for i in range(n):
        piv = M[i][i]
        for k in range(2 * n):
            M[i][k] /= piv
        for j in range(n):
            if j == i:
                continue
            f = M[j][i]
            for k in range(2 * n):
                M[j][k] -= f * M[i][k]
    return [row[n:] for row in M]

def matmul(A, B):
    n = len(A)
    return [[sum(A[i][k] * B[k][j] for k in range(n)) for j in range(n)] for i in range(n)]

A = [[4.0, -2.0, 1.0], [3.0, 6.0, -4.0], [2.0, 1.0, 8.0]]
`}
  sourceChecks={[
    {name: 'uses matmul of A and Ainv', pattern: 'matmul\s*\\(|A\\[i\\]\\[k\\]\s*\\*\s*', must: true, hint: 'form the product AA⁻¹'},
  ]}

<Exercise title="7.4b.4 Solve Ax=b → (1,−2,4)" anchor="exercise-cp-74-solve1">

:::tip Activity: Solve $A\mathbf x=\mathbf b$ for $\mathbf b=(12,-25,32)$
Use Gaussian elimination (not the inverse). Print $\mathbf x$ with 10 decimals.

No input.

<CodeExercise
  title="Solve Ax=b → (1,−2,4)"
  heading="exercise-cp-74-solve1"
  lang="python"
  filename="main.py"
  prompt="Solve Ax=b for b=[12,-25,32]; print x with 10 decimals."
  sampleLog={`1.0000000000 -2.0000000000 4.0000000000`}
  starter={`def solve(A, b):
    n = len(b)
    return [0.0] * n

A = [[4.0, -2.0, 1.0], [3.0, 6.0, -4.0], [2.0, 1.0, 8.0]]
b = [12.0, -25.0, 32.0]
`}
  wrapSuffix={`
x = solve(A, b)
print(' '.join(f"{v:.10f}" for v in x))
`}
  hint="Forward elimination to upper-triangular, then back-substitution — same pattern as 7.3b.4."
  solution={`def solve(A, b):
    n = len(b)
    A = [row[:] for row in A]
    b = b[:]
    for i in range(n):
        piv = A[i][i]
        for j in range(i + 1, n):
            f = A[j][i] / piv
            for k in range(n):
                A[j][k] -= f * A[i][k]
            b[j] -= f * b[i]
    x = [0.0] * n
    for i in range(n - 1, -1, -1):
        s = b[i]
        for k in range(i + 1, n):
            s -= A[i][k] * x[k]
        x[i] = s / A[i][i]
    return x

A = [[4.0, -2.0, 1.0], [3.0, 6.0, -4.0], [2.0, 1.0, 8.0]]
b = [12.0, -25.0, 32.0]
`}
  sourceChecks={[
    {name: 'elimination solve', pattern: 'A\\[j\\]\\[k\\]\s*-=|back', must: true, hint: 'use Gaussian elimination, not a hard-coded vector'},
    {name: 'not hard-coded', pattern: 'return\s+\\[1\\.0,\s*-2\\.0,\s*4\\.0\\]', must: false, hint: 'compute x by elimination'},
  ]}
  tests={[
    {name: 'exact rhs', equals: '1.0000000000 -2.0000000000 4.0000000000'},
  ]}
/>

<Exercise title="7.4b.6 Eigenvector residual" anchor="exercise-cp-74-eig">

:::tip Activity: Verify $A_3\mathbf x_1=5\mathbf x_1$
With

$$
A_3=\begin{pmatrix}-2&2&-3\\2&1&-6\\-1&-2&0\end{pmatrix},\quad
\mathbf x_1=\frac{(-1,-2,1)^{\mathsf T}}{\sqrt{6}},
$$

print $\max\|A_3\mathbf x_1-5\mathbf x_1\|$ as `:.6e`.

No input.

<CodeExercise
  title="Eigenvector residual"
  heading="exercise-cp-74-eig"
  lang="python"
  filename="main.py"
  prompt="Print max|A3@x1 − 5*x1| as :.6e."
  sampleLog={`0.000000e+00`}
  starter={`import math

def matvec(A, x):
    return [0.0] * len(x)

A3 = [[-2.0, 2.0, -3.0], [2.0, 1.0, -6.0], [-1.0, -2.0, 0.0]]
s = math.sqrt(6.0)
x1 = [-1.0 / s, -2.0 / s, 1.0 / s]
`}
  wrapSuffix={`
Ax = matvec(A3, x1)
mx = max(abs(Ax[i] - 5.0 * x1[i]) for i in range(3))

`}

def matvec(A, x):

s = math.sqrt(6.0)
x1 = [-1.0 / s, -2.0 / s, 1.0 / s]
`}
  sourceChecks={[
    {name: 'matvec sum', pattern: 'A\\[i\\]\\[j\\]\s*\\*\s*x\\[j\\]|sum\\(', must: true, hint: 'compute A3 @ x1 with a row-times-vector sum'},
