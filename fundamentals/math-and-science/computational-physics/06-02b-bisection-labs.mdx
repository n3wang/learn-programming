# 6.2b Bisection labs

> **Source:** Lab ideas from *Computational Physics* (Landau, Páez, Bordeianu), §6.1–6.2. Rewritten as original drills — **not** textbook `Bisection.py`. Continues [6.2 Bisection search](./06-02-bisection-search).

Implement interval halving, probe the even square-well residual, and lock $E_{B}$. Stubs fail until filled in.

Use

$$
g(E)=\sqrt{E}\,\cot\sqrt{V_0-E}-\sqrt{V_0-E}
$$

with $\cot\theta=\cos\theta/\sin\theta$ (`math.sin` / `math.cos`). Hint only: guard against $\sin\kappa\approx 0$ if you leave the safe bracket.

**Bisection convention for graded output:** while $(b-a)/2>\varepsilon$ with $\varepsilon=10^{-14}$, set $m=(a+b)/2$; if $f(a)\,f(m)\le 0$ then $b\leftarrow m$, else $a\leftarrow m$ (update the stored $f(a)$). Return the final midpoint $(a+b)/2$.

def bisect(f, a, b, eps=1e-14):

<Exercise title="6.2b.3 Even bound energy" anchor="exercise-cp-bisect-well">

:::tip Activity: Even bound energy
Bisect $g(E)=0$ for $V_0=10$ on $[8.0,8.8]$ with $\varepsilon=10^{-14}$. Print $E$ with 10 decimals.

No input.

Expected: $E_{B}\approx 8.5927852752$.

<CodeExercise
  title="Even bound energy"
  heading="exercise-cp-bisect-well"
  lang="python"
  filename="main.py"
  prompt="Bisect g(E)=0 on [8.0, 8.8]; print E to 10 decimals."
  sampleLog={`8.5927852752`}
  starter={`import math

def g(E, V0=10.0):
    return 0.0

def bisect(f, a, b, eps=1e-14):
    return 0.0
`}
  wrapSuffix={`
print(f"{bisect(g, 8.0, 8.8):.10f}")
`}
  hint="Same loop as 6.2b.1; g uses √E cot√(10−E)−√(10−E). Guard sin≈0 only if you leave the bracket."
  solution={`import math

def g(E, V0=10.0):
    ke = math.sqrt(E)
    kappa = math.sqrt(V0 - E)
    return ke * math.cos(kappa) / math.sin(kappa) - kappa

def bisect(f, a, b, eps=1e-14):
    fa = f(a)
    while (b - a) / 2 > eps:
        m = (a + b) / 2
        fm = f(m)
        if fa * fm <= 0:
            b = m
        else:
            a = m
            fa = fm
    return (a + b) / 2
`}
  sourceChecks={[
    {name: 'implements g', pattern: 'cot|cos\\s*\\(|math\\.cos', must: true, hint: 'evaluate the even residual'},
    {name: 'bisects', pattern: 'while|for', must: true, hint: 'loop until the half-width is < eps'},
  ]}
  tests={[
    {name: 'E_B', equals: '8.5927852752'},
  ]}
/>

:::

</Exercise>
