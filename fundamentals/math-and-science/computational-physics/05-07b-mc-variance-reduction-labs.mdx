# 5.7b Variance-reduction labs

> **Source:** Lab ideas from *Computational Physics* (Landau, Páez, Bordeianu), §5.7. Rewritten as original drills. Continues [5.7 Monte Carlo variance reduction](./05-07-mc-variance-reduction).

Control variate on $[0,1]$ for $f(x)=e^{-x}$, $g(x)=1-x$, $J=1/2$. Exact value $I=1-e^{-1}$. Use the chapter LCG only.

:::note Fixed LCG
`r ← (1103515245 * r + 12345) % 2**31`, then uniform `r / 2**31`. Default seed `1`. Advance the state **before** each draw.
:::

<Exercise title="5.7b.1 Plain mean-value MC" anchor="exercise-cp-cv-plain">

:::tip Activity: Plain mean-value MC
Estimate $I=\int_0^1 e^{-x}\,dx$ by

$$
I\simeq\frac{1}{N}\sum_{i=1}^{N} e^{-x_i},\qquad x_i\sim U[0,1),
$$

with the chapter LCG, seed $1$, $N=1000$. Print with **10** decimals.

No input.

<Exercise title="5.7b.2 Control-variate estimate" anchor="exercise-cp-cv-est">

:::tip Activity: Control-variate estimate
Same samples as 5.7b.1, but use $g(x)=1-x$ and $J=1/2$:

$$
I\simeq\frac{1}{N}\sum_{i=1}^{N}\bigl(e^{-x_i}-(1-x_i)\bigr)+\frac{1}{2}.
$$

Print with **10** decimals. At this $N$ and seed the CV estimate should beat plain MC in absolute error vs $1-e^{-1}$.

No input.

<Exercise title="5.7b.3 Both estimates and |err|" anchor="exercise-cp-cv-compare">

:::tip Activity: Both estimates and $|$err$|$

  hint="One loop: accumulate sum f and sum (f−g); exact = 1 - exp(-1)."
  solution={`import math

def compare(N, seed=1):
    M = 2**31
    r = seed
    s_f = 0.0
    s_res = 0.0
    for _ in range(N):
        r = (1103515245 * r + 12345) % M
        x = r / M
        fx = math.exp(-x)
        s_f += fx
        s_res += fx - (1.0 - x)
    plain = s_f / N
    cv = s_res / N + 0.5
    exact = 1.0 - math.exp(-1.0)
    return plain, cv, abs(plain - exact), abs(cv - exact)
`}
  sourceChecks={[
