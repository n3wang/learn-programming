# 7.8 Code-listing sketches

> **Source:** Structural ideas from *Computational Physics* (Landau, Páez, Bordeianu), §7.8 listings. **Original sketches only** — not a paste of `NewtonNDanimate.py` or `Hyperfine.py` (those depend on VPython / SymPy GUIs outside this sandbox).

## Multidimensional Newton for two masses on a string

Section [7.5](./07-03-string-problem) reduced the statics lesson to a 2D Newton toy. The full two-mass / three-string problem is a **9-unknown** residual $F(\mathbf x)=\mathbf 0$ with components that encode:

- horizontal / vertical length closures with $\sin\theta_i$, $\cos\theta_i$,
- force balance with tensions,
- three circle constraints $\sin^{2}\theta_i+\cos^{2}\theta_i=1$.

A practical solver:

1. Evaluate $F(\mathbf x)$.
2. Build the Jacobian by **central differences** in each coordinate (step $h\sim 10^{-4}$).
3. Solve $J\,\Delta\mathbf x=-F$ (Gaussian elimination / `linalg.solve` when NumPy is available).
4. Update $\mathbf x\leftarrow\mathbf x+\Delta\mathbf x$; stop when $\|\Delta\mathbf x\|$ and $\|F\|$ are tiny.
5. Optionally redraw the geometry each iteration (any plotting toolkit — VPython is one historical choice).

Prefer $\cos\theta_i=+\sqrt{1-\sin^{2}\theta_i}$ when the sketch needs $\cos>0$ (see [7.5](./07-03-string-problem)).

## Jacobian by central differences

For residual $F:\mathbb{R}^n\to\mathbb{R}^n$, build $J$ by central differences (and check the zero-field hyperfine spectrum). Pick the column formula and the $\{W,W,W,-3W\}$ spectrum among lookalikes.

<GuidedChoiceExplanation preset="matrix-code-sketches" />

Use $h\sim 10^{-4}$ (or scaled $h\sim 10^{-4}\max(1,|x_j|)$). Analytic $\partial F_i/\partial x_j$ is nicer when you have it; finite differences keep the physics code short and are fine for the string toy.

### When $J$ is singular (or nearly so)

Newton needs a solvable $J\,\Delta\mathbf x=-F$. Failure modes (same spirit as 1D Newton traps in Fig. 6.3):

![Figure 6.3 — Newton can stall when the derivative vanishes or the update jumps.](/img/computational-physics/fig-6-3-newton-failures.svg)

| Symptom | Likely cause | Mitigation |
| --- | --- | --- |
| `linalg.solve` / GE blows up | $\det J\approx 0$ (redundant constraints, bad branch of $\cos$) | Restart from a better $\mathbf x_0$; enforce $\cos>0$ |
| $\|\Delta\mathbf x\|$ huge while $\|F\|$ barely drops | Ill-conditioned $J$ | Smaller $h$ or damping: $\mathbf x\leftarrow\mathbf x+\lambda\Delta\mathbf x$ with $\lambda<1$ |
| Oscillating iterates | Bracket / geometry inconsistent | Check length closures before trusting the step |

If $J$ is singular, **do not** trust the update — fix the residual definition or the initial guess first.

## Hyperfine matrix with a computer-algebra assist

Section [7.6](./07-04-hyperfine) already builds

$$
V=W\begin{pmatrix}1&0&0&0\\0&-1&2&0\\0&2&-1&0\\0&0&0&1\end{pmatrix}
$$

by hand. A symbolic package can print `eigenvals()` of $V$ and of $V+V_{\mathrm{mag}}(B)$ when an external field couples $\mu_e,\mu_p$.
