# 5.9 Integration reference sketches

> **Source:** Concepts from *Computational Physics* (Landau, Páez, Bordeianu), §§5.3–5.8. **Original** modern Python stubs only — not textbook listings (`TrapMethods.py`, `IntegGauss.py`, `vonNeuman.py`). Graded work lives in the labs linked below.

Use these as memory aids while coding the exercises. They deliberately omit full tables, production edge cases, and copyrighted program text.

## Trapezoid (reminder)

Composite trapezoid on $[a,b]$ with $N$ panels ($h=(b-a)/N$):

```python
# original stub — not TrapMethods.py
def trap(f, a, b, N):
    h = (b - a) / N
    s = 0.5 * (f(a) + f(b))
    for i in range(1, N):
        s += f(a + i * h)
    return s * h
```

## Gauss map (reminder)

Legendre nodes/weights live on $[-1,1]$. Map onto $[a,b]$:

$$
x=\frac{b+a}{2}+\frac{b-a}{2}y,\qquad
w_x=\frac{b-a}{2}w_y.
$$

```python
# original stub — not IntegGauss.py
def gauss_map(nodes, weights, a, b):
    mid = 0.5 * (a + b)
    half = 0.5 * (b - a)
    xs = [mid + half * y for y in nodes]
    ws = [half * w for w in weights]
    return xs, ws
```

## Rejection sampler (reminder)

Box height $w_0\ge w(x)$; throw $(x,W)=(U,w_0 V)$; accept if $W\le w(x)$.

```python
# original stub — not vonNeuman.py
def reject_sample(w, w0, a, b, n_want, rnd):
    """rnd() → U[0,1). Return n_want accepted abscissae ~ w on [a,b]."""
    out = []
    while len(out) < n_want:
        x = a + (b - a) * rnd()
        W = w0 * rnd()
        if W <= w(x):
            out.append(x)
    return out
```
