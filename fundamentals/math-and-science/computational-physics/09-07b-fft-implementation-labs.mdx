<Exercise title="9.6b.7 Round-trip residual" anchor="exercise-cp-96-roundtrip">

:::tip Activity: FFT∘iFFT error scale
For $y=[1,2,3,4]$ (real→complex), run a length-4 radix-2 FFT then inverse (divide by $N$ on the way back). Print the max $|\Delta|$ over the four samples with **10 decimals** (should be $\sim 0$ in float).

No input.

<CodeExercise
  title="N=4 round-trip max err"
  heading="exercise-cp-96-roundtrip"
  lang="python"
  filename="main.py"
  prompt="FFT then iFFT on [1,2,3,4]; print max |err| 10 decimals."
  sampleLog={`0.0000000000`}
  starter={`import math
import cmath

def bitrev(x, bits):
    rev = 0
    for _ in range(bits):
        rev = (rev << 1) | (x & 1)
        x >>= 1
    return rev

def fft(x, inverse=False):
    a = list(x)
    N = len(a)
    bits = int(math.log2(N))
    for i in range(N):
        j = bitrev(i, bits)
        if j > i:
            a[i], a[j] = a[j], a[i]
    sign = 1 if inverse else -1
    length = 2
    while length <= N:
        half = length // 2
        wlen = cmath.exp(sign * 2j * math.pi / length)
        for i in range(0, N, length):
            w = 1 + 0j
            for j in range(half):
                u = a[i + j]
                v = a[i + j + half] * w
                a[i + j] = u + v
                a[i + j + half] = u - v
                w *= wlen
        length *= 2
    if inverse:
        a = [v / N for v in a]
    return a

y = [1 + 0j, 2 + 0j, 3 + 0j, 4 + 0j]
# TODO: Y = fft(y); y2 = fft(Y, inverse=True); mx = max abs err
mx = 1.0
`}
  wrapSuffix={`
print(f"{mx:.10f}")
`}
  hint="Reuse the provided fft(); take max |y2[k]-y[k]|."
  solution={`import math
import cmath

def bitrev(x, bits):
    rev = 0
    for _ in range(bits):
        rev = (rev << 1) | (x & 1)
        x >>= 1
    return rev

def fft(x, inverse=False):
    a = list(x)
    N = len(a)
    bits = int(math.log2(N))
    for i in range(N):
        j = bitrev(i, bits)
        if j > i:
            a[i], a[j] = a[j], a[i]
    sign = 1 if inverse else -1
    length = 2
    while length <= N:
        half = length // 2
        wlen = cmath.exp(sign * 2j * math.pi / length)
        for i in range(0, N, length):
            w = 1 + 0j
            for j in range(half):
                u = a[i + j]
                v = a[i + j + half] * w
                a[i + j] = u + v
                a[i + j + half] = u - v
                w *= wlen
        length *= 2
    if inverse:
        a = [v / N for v in a]
    return a

y = [1 + 0j, 2 + 0j, 3 + 0j, 4 + 0j]
Y = fft(y)
y2 = fft(Y, inverse=True)
mx = max(abs(y2[k] - y[k]) for k in range(4))
`}
  sourceChecks={[
    {name: 'calls fft', pattern: 'fft\\s*\\(', must: true, hint: 'forward and inverse fft'},
    {name: 'inverse True', pattern: 'inverse\\s*=\\s*True|True', must: true, hint: 'inverse=True on the return trip'},
  ]}
  tests={[
    {name: 'roundtrip', equals: '0.0000000000'},
  ]}
/>
