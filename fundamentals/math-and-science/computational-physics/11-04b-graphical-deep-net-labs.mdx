<Exercise title="11.4b.3 Active vs inactive" anchor="exercise-cp-114-active">

:::tip Activity: Fire if nonzero

No input.

<CodeExercise
  title="Nonzero gate"
  heading="exercise-cp-114-active"
  lang="python"
  filename="main.py"
  prompt="1 if s!=0 else 0 for s=0 and s=2."
  sampleLog={`0 1`}

    return 0  # TODO
`}
  wrapSuffix={`

`}
  hint="Compare to zero."
  solution={`def active(s):
    return 1 if s != 0 else 0
`}
  sourceChecks={[
    {name: 'test', pattern: 'if|!=|==', must: true, hint: 'nonzero test'},

  tests={[
    {name: 'flags', equals: '0 1'},
  ]}
/>

:::

</Exercise>

<Exercise title="11.4b.5 Linear separator for pairs" anchor="exercise-cp-114-sep">

:::tip Activity: Score $=w_L L+w_R R$
With $(w_L,w_R)=(1,-1)$, print scores for $(L,R)=(1,0)$ and $(0,1)$ space-separated with **10 decimals**.

No input.

<CodeExercise
  title="Pair scores"
  heading="exercise-cp-114-sep"
  lang="python"
  filename="main.py"
  prompt="1*L + (-1)*R for (1,0) and (0,1)."
  sampleLog={`1.0000000000 -1.0000000000`}
  starter={`wL, wR = 1.0, -1.0
s10 = 0.0  # TODO for L,R = 1,0
s01 = 0.0  # TODO for L,R = 0,1
`}
  wrapSuffix={`
print(f"{s10:.10f} {s01:.10f}")
`}
  hint="Dot weights with the two bits."
  solution={`wL, wR = 1.0, -1.0
s10 = wL * 1.0 + wR * 0.0
s01 = wL * 0.0 + wR * 1.0
`}
  sourceChecks={[
    {name: 'dot', pattern: '\\*', must: true, hint: 'weighted sum'},
  ]}
  tests={[
    {name: 'scores', equals: '1.0000000000 -1.0000000000'},
  ]}
/>

:::

</Exercise>
