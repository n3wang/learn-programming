<Exercise title="5.8b.1 Rejection accepted count" anchor="exercise-cp-rej-count">

:::tip Activity: Rejection accepted count
On $[0,1]$, take $w(x)=2x$ and box height $w_0=2$. For each of `Nthrows` trials: draw uniforms $U,V$ from the chapter LCG; set $x=U$, $W=w_0 V$; accept if $W\le w(x)$. Print the **accepted count** (integer).

Input: `Nthrows`.

With $N=1000$, seed $1$, the accepted count is fixed by the LCG stream.

<CodeExercise
  title="Rejection accepted count"
  heading="exercise-cp-rej-count"
  lang="python"
  filename="main.py"
  prompt="w(x)=2x, w0=2; print accepted count for Nthrows throws, seed 1."
  sampleLog={`(input) 1000
497`}
  starter={`def accepted_count(Nthrows, seed=1, w0=2.0):
    return 0
`}
  wrapSuffix={`
N = int(input())
print(accepted_count(N))
`}
  hint="Two LCG draws per throw: x=U, W=w0*V; accept if W <= 2*x."
  solution={`def accepted_count(Nthrows, seed=1, w0=2.0):
    M = 2**31
    r = seed
    hits = 0
    for _ in range(Nthrows):
        r = (1103515245 * r + 12345) % M
        x = r / M
        r = (1103515245 * r + 12345) % M
        W = w0 * (r / M)
        if W <= 2.0 * x:
            hits += 1
    return hits
`}
  sourceChecks={[
    {name: 'fixed LCG', pattern: '1103515245', must: true, hint: 'chapter LCG'},
    {name: 'no random module', pattern: 'random\\.random', must: false, hint: 'deterministic LCG only'},
  ]}
  tests={[
    {name: 'N=1000 seed 1', stdin: '1000', equals: '497'},
    {name: 'N=100 seed 1', stdin: '100', equals: '49'},
  ]}
/>

:::

</Exercise>

<Exercise title="5.8b.2 Importance via inverse CDF" anchor="exercise-cp-imp-inv">

:::tip Activity: Importance via inverse CDF
Take $w(x)=2(1-x)$ on $[0,1]$. Sample by inversion: $u\sim U[0,1)$, $x=1-\sqrt{1-u}$. Estimate
$I\simeq\frac{1}{N}\sum_{i=1}^{N}\frac{e^{-x_i}}{w(x_i)}$.
Use the chapter LCG, seed $1$, $N=1000$. Print with **10** decimals.

No input.

<CodeExercise
  title="Importance via inverse CDF"
  heading="exercise-cp-imp-inv"
  lang="python"
  filename="main.py"
  prompt="x=1−√(1−u); average e^{-x}/w(x) with w=2(1−x); N=1000 seed 1."
  sampleLog={`0.6287247601`}
  starter={`import math

def importance_exp(N, seed=1):
    return 0.0
`}
  wrapSuffix={`
print(f"{importance_exp(1000):.10f}")
`}
  hint="One uniform per sample; x=1-sqrt(1-u); w=2*(1-x); accumulate exp(-x)/w."
  solution={`import math

def importance_exp(N, seed=1):
    M = 2**31
    r = seed
    s = 0.0
    for _ in range(N):
        r = (1103515245 * r + 12345) % M
        u = r / M
        x = 1.0 - math.sqrt(1.0 - u)
        w = 2.0 * (1.0 - x)
        s += math.exp(-x) / w
    return s / N
`}
  sourceChecks={[
    {name: 'fixed LCG', pattern: '1103515245', must: true, hint: 'chapter LCG'},
    {name: 'inverse CDF', pattern: 'sqrt', must: true, hint: 'x = 1 − √(1−u)'},
    {name: 'no random module', pattern: 'random\\.random', must: false, hint: 'deterministic LCG only'},
  ]}
  tests={[
    {name: 'N=1000 seed 1', stdin: '', equals: '0.6287247601'},
  ]}
/>

:::

</Exercise>

```python
# rejection_importance.py — original sketches
M = 2**31

def reject_w2x(Nthrows, seed=1):
    r, hits = seed, 0
    for _ in range(Nthrows):
        r = (1103515245 * r + 12345) % M
        x = r / M
        r = (1103515245 * r + 12345) % M
        if 2.0 * (r / M) <= 2.0 * x:
            hits += 1
    return hits

def importance_inv(N, seed=1):
    import math
    r, s = seed, 0.0
    for _ in range(N):
        r = (1103515245 * r + 12345) % M
        u = r / M
        x = 1.0 - math.sqrt(1.0 - u)
        s += math.exp(-x) / (2.0 * (1.0 - x))
    return s / N
```
