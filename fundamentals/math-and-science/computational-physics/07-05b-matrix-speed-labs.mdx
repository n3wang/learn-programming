# 7.7b Matrix-speed labs

> **Source:** Lab ideas from *Computational Physics* (Landau, Páez, Bordeianu), §7.7–7.7.2. Rewritten as original drills (list sandbox — no NumPy). Continues [7.7 Speeding up matrix computing](./07-05-matrix-speed).

Practice vector-style list ops, **stride-aware** nestings, and both matmul loop orders. Graded outputs lock *correctness* (same sums / same $C$ / same derivatives). Use `time.perf_counter()` locally to *feel* the speed gap — wall-clock is too noisy to grade.

## Explorers

```python
# matrix_speed_ref.py — stride / matmul nestings (original sketch)
import time

def sos_row(M):
    return sum(M[i][j] * M[i][j] for i in range(len(M)) for j in range(len(M[0])))

def sos_col(M):
    n, m = len(M), len(M[0])
    return sum(M[i][j] * M[i][j] for j in range(m) for i in range(n))

def time_call(fn, *args, repeats=5):
    samples = []
    for _ in range(repeats):
        t0 = time.perf_counter()
        fn(*args)
        samples.append(time.perf_counter() - t0)
    samples.sort()
    return samples[len(samples) // 2]
```

Time `sos_row` vs `sos_col` (and both matmul nestings) for growing $N$ on your machine.
