# 12.4 Logic gates

> **Source:** Ideas from *Computational Physics* (Landau, Páez, Bordeianu), §12.4. Rewritten in original wording. Continues [12.3b](./12-03b-entanglement-labs). Next: [12.4b](./12-04b-logic-gates-labs).

Classical computers combine **logic gates** on bits. Quantum computers use **unitary** gates on qubits (probability-preserving). This lesson starts with classical wiring labs (`NodeLab`, same canvas as [schema design](/fundamentals/data-science/lesson-11-schema-design) / [digital logic](/fundamentals/electronics/lesson-1-digital-logic)), then maps to 1-, 2-, and 3-qubit quantum gates.

## Classical gates (warm-up)

Six basics: **AND, NAND, NOT, OR, NOR, XOR**. Truth tables define outputs. A **half-adder** uses XOR for the sum bit and AND for the carry.

## 1-qubit quantum gates

Unitary $U|\psi_{\mathrm{in}}\rangle=|\psi_{\mathrm{out}}\rangle$ preserves norms.

| Gate | Matrix / action |
| --- | --- |
| **X** (NOT) | $\begin{bmatrix}0&1\\1&0\end{bmatrix}$, flips $\|0\rangle\leftrightarrow\|1\rangle$ |
| **Y** | $\begin{bmatrix}0&-i\\i&0\end{bmatrix}$ |
| **Z** | $\begin{bmatrix}1&0\\0&-1\end{bmatrix}$, $Z\|z\rangle=(-1)^z\|z\rangle$ |
| **H** | $\frac1{\sqrt2}\begin{bmatrix}1&1\\1&-1\end{bmatrix}$, $\|0\rangle\mapsto\|+\rangle$, $\|1\rangle\mapsto\|-\rangle$ |
| **$R_\varphi$** (phase / P) | $\mathrm{diag}(1,e^{i\varphi})$ |
| **S**, **T** | $R_{\pi/2}$, $R_{\pi/4}$ |
| **$R_x,R_y,R_z$** | $e^{-i\alpha\sigma/2}$ Bloch rotations |
| Measure | Not unitary — collapses to classical bits |

**Bloch checks:** H takes $\|0\rangle$ to $(\|0\rangle+\|1\rangle)/\sqrt2$; a $\pi/2$ phase on that state yields $(\|0\rangle+i\|1\rangle)/\sqrt2$; X (or $R_x(\pi)$ up to global phase) flips $\|0\rangle\to\|1\rangle$.

## 2-qubit gates

- **SWAP:** $\|01\rangle\leftrightarrow\|10\rangle$.
- **Controlled-$U$:** $CU|c\rangle|t\rangle=|c\rangle U^c|t\rangle$.
- **CNOT:** control 0 → target unchanged; control 1 → flip target. $\mathrm{CNOT}|10\rangle=|11\rangle$.
- **CZ:** flips the sign of $\|11\rangle$ only.

## 3-qubit gates

Three-qubit basis states are tensor products

$$
|ijk\rangle=|i\rangle\otimes|j\rangle\otimes|k\rangle,
$$

eight of them: $|000\rangle,\ldots,|111\rangle$. In the computational ordering used here, $|110\rangle$ is the unit vector with a $1$ in the seventh slot (0-based index $6$), and $|111\rangle$ is index $7$. Gates on this space are $8\times 8$ unitaries.

**Toffoli / CCNOT** extends CNOT: flip the **target** (third qubit) if and only if **both controls** are $|1\rangle$:

$$
T|110\rangle=|111\rangle,\qquad T|111\rangle=|110\rangle,
$$

and leave every other basis ket unchanged. (Equivalently: the $8\times 8$ matrix swaps rows/columns $6$ and $7$.) That is the quantum analogue of a classical AND on the controls driving an XOR into the target — the building block for reversible adders in the next lesson.

## Takeaway

| Classical | Quantum |
| --- | --- |
| AND / XOR / … | Unitary $X,Y,Z,H,R_\varphi,\ldots$ |
| Half-adder | CNOT / CZ / SWAP |
| — | H+CNOT → Bell |
| — | Toffoli on 3 qubits |
