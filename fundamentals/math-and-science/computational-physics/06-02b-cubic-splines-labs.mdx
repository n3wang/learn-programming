<Exercise title="6.5.2b.1 Estimate g'' by forward difference" anchor="exercise-cp-spline-gpp">

:::tip Activity: Estimate g'' by forward difference
Implement the endpoint second-derivative estimate

$$
g''(x_2)\simeq\frac{[g(x_3)-g(x_2)]/[x_3-x_2]-[g(x_2)-g(x_1)]/[x_2-x_1]}{[x_3-x_1]/2}.
$$

Input: `x1 g1 x2 g2 x3 g3`. Print with 6 decimals.

<Exercise title="6.5.2b.2 Solve the natural spline system" anchor="exercise-cp-spline-solve">

:::tip Activity: Solve the natural spline system
Given $n$ tabulated points, solve for the second derivatives $M_i=g''(x_i)$ of the **natural** cubic spline ($M_1=M_n=0$). The interior equations are

$$
h_{i-1}M_{i-1}+2(h_{i-1}+h_i)M_i+h_i M_{i+1}=6\left(\frac{g_{i+1}-g_i}{h_i}-\frac{g_i-g_{i-1}}{h_{i-1}}\right),
\qquad h_i=x_{i+1}-x_i.
$$

Solve the resulting tridiagonal system with plain Gaussian elimination (no numpy).

Input: first line `n`, then `n` lines of `x_i g_i`. Print all $n$ values of $M_i$ on one line, space-separated, 6 decimals each.

<CodeExercise
  title="Solve the natural spline system"
  heading="exercise-cp-spline-solve"
  lang="python"
  filename="main.py"
  prompt="Solve for natural-spline second derivatives M_i."
  sampleLog={`(input) 4
0 -12
1 -12
2 -24
4 -60
0.000000 -17.217391 -3.130435 0.000000`}
  starter={`def natural_spline_M(xs, ys):
    n = len(xs)
    return [0.0] * n
`}
  wrapSuffix={`
n = int(input())
xs, ys = [], []
for _ in range(n):
    x, y = map(float, input().split())
    xs.append(x)
    ys.append(y)
M = natural_spline_M(xs, ys)
print(' '.join(f"{m:.6f}" for m in M))
`}
  hint="Build the n x n tridiagonal matrix with rows 0 and n-1 forcing M=0, then Gaussian-eliminate."
  solution={`def natural_spline_M(xs, ys):
    n = len(xs)
    h = [xs[i + 1] - xs[i] for i in range(n - 1)]
    A = [[0.0] * n for _ in range(n)]
    b = [0.0] * n
    A[0][0] = 1.0
    A[n - 1][n - 1] = 1.0
    for i in range(1, n - 1):
        A[i][i - 1] = h[i - 1]
        A[i][i] = 2.0 * (h[i - 1] + h[i])
        A[i][i + 1] = h[i]
        b[i] = 6.0 * ((ys[i + 1] - ys[i]) / h[i] - (ys[i] - ys[i - 1]) / h[i - 1])

    for i in range(n):
        piv = A[i][i]
        for j in range(i + 1, n):
            f = A[j][i] / piv
            for k in range(n):
                A[j][k] -= f * A[i][k]
            b[j] -= f * b[i]

    M = [0.0] * n
    for i in range(n - 1, -1, -1):
        s = b[i]
        for k in range(i + 1, n):
            s -= A[i][k] * M[k]
        M[i] = s / A[i][i]
    return M
`}
  sourceChecks={[
    {name: 'natural boundary', pattern: 'A\\[0\\]\\[0\\]\\s*=\\s*1|A\\[n\\s*-\\s*1\\]', must: true, hint: 'force M[0]=M[n-1]=0 with A[0][0]=1, A[n-1][n-1]=1'},
  ]}
  tests={[
    {
      name: 'book 4-point table',
      stdin: '4\n0 -12\n1 -12\n2 -24\n4 -60',
      equals: '0.000000 -17.217391 -3.130435 0.000000',
    },
  ]}
/>

<Exercise title="6.5.2b.3 Evaluate the spline" anchor="exercise-cp-spline-eval">

:::tip Activity: Evaluate the spline
Given nodes, values, and the second derivatives $M_i$ (from the previous exercise), evaluate the spline at a query $x$ using

$$
g(x)=A\,g_i+B\,g_{i+1}+\bigl[(A^3-A)M_i+(B^3-B)M_{i+1}\bigr]\frac{h^2}{6},
\qquad A=\frac{x_{i+1}-x}{h},\ B=\frac{x-x_i}{h},\ h=x_{i+1}-x_i,
$$

where $[x_i,x_{i+1}]$ is the bracketing interval.

Input: first line `n`, then `n` lines of `x_i g_i`, then one line with `x`. Print the spline value with 6 decimals. (You may hard-code the $M_i$ solver from 6.5.2b.2, or copy it in.)

```python
# spline_ref.py — natural cubic spline: solve, evaluate, integrate (original sketch)
def natural_spline_M(xs, ys):
    n = len(xs)
    h = [xs[i + 1] - xs[i] for i in range(n - 1)]
    A = [[0.0] * n for _ in range(n)]
    b = [0.0] * n
    A[0][0] = 1.0
    A[n - 1][n - 1] = 1.0
    for i in range(1, n - 1):
        A[i][i - 1] = h[i - 1]
        A[i][i] = 2.0 * (h[i - 1] + h[i])
        A[i][i + 1] = h[i]
        b[i] = 6.0 * ((ys[i + 1] - ys[i]) / h[i] - (ys[i] - ys[i - 1]) / h[i - 1])
    for i in range(n):
        piv = A[i][i]
        for j in range(i + 1, n):
            f = A[j][i] / piv
            for k in range(n):
                A[j][k] -= f * A[i][k]
            b[j] -= f * b[i]
    M = [0.0] * n
    for i in range(n - 1, -1, -1):
        s = b[i]
        for k in range(i + 1, n):
            s -= A[i][k] * M[k]
        M[i] = s / A[i][i]
    return M
```
