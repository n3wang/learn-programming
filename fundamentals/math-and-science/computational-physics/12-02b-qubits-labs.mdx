<Exercise title="12.2b.1 Normalize check" anchor="exercise-cp-122-norm">

:::tip Activity: $|u|^2+|v|^2$
For $u=3/5$, $v=4/5$, print the norm squared with **10 decimals**.

No input.

<CodeExercise
  title="Norm²"
  heading="exercise-cp-122-norm"
  lang="python"
  filename="main.py"
  prompt="(3/5)**2+(4/5)**2; 10 decimals."
  sampleLog={`1.0000000000`}
  starter={`u, v = 3 / 5, 4 / 5
n2 = 0.0  # TODO
`}
  wrapSuffix={`
print(f"{n2:.10f}")
`}
  hint="u*u + v*v."
  solution={`u, v = 3 / 5, 4 / 5
n2 = u * u + v * v
`}
  sourceChecks={[
    {name: 'sq', pattern: '\\*|\\*\\*', must: true, hint: 'sum of squares'},
  ]}
  tests={[
    {name: 'n2', equals: '1.0000000000'},
  ]}
/>

:::

</Exercise>

<Exercise title="12.2b.2 Bloch amplitudes at equator" anchor="exercise-cp-122-bloch">

:::tip Activity: $\theta=\pi/2$, $\phi=0$
Print $\cos(\theta/2)$ and $\sin(\theta/2)$ with **10 decimals**.

No input.

<CodeExercise
  title="Bloch θ=π/2"
  heading="exercise-cp-122-bloch"
  lang="python"
  filename="main.py"
  prompt="cos(π/4) and sin(π/4); 10 decimals."
  sampleLog={`0.7071067812 0.7071067812`}
  starter={`import math

theta = math.pi / 2
c = 0.0  # TODO cos(theta/2)
s = 0.0  # TODO sin(theta/2)
`}
  wrapSuffix={`
print(f"{c:.10f} {s:.10f}")
`}
  hint="θ/2 = π/4."
  solution={`import math

theta = math.pi / 2
c = math.cos(theta / 2)
s = math.sin(theta / 2)
`}
  sourceChecks={[
    {name: 'trig', pattern: 'cos|sin', must: true, hint: 'Bloch trig'},
  ]}
  tests={[
    {name: 'amps', equals: '0.7071067812 0.7071067812'},
  ]}
/>

:::

</Exercise>

<Exercise title="12.2b.3 Tensor product" anchor="exercise-cp-122-kron">

:::tip Activity: $|0\rangle\otimes|1\rangle$
With $|0\rangle=[1,0]$, $|1\rangle=[0,1]$, print the four components of the Kronecker product space-separated with **10 decimals**.

No input.

<CodeExercise
  title="Kronecker"
  heading="exercise-cp-122-kron"
  lang="python"
  filename="main.py"
  prompt="[ac,ad,bc,bd] for a=1,b=0,c=0,d=1."
  sampleLog={`0.0000000000 1.0000000000 0.0000000000 0.0000000000`}
  starter={`a, b = 1.0, 0.0
c, d = 0.0, 1.0
# TODO: out = [a*c, a*d, b*c, b*d]
out = [0.0, 0.0, 0.0, 0.0]
`}
  wrapSuffix={`
print(" ".join(f"{x:.10f}" for x in out))
`}
  hint="Four products in Kronecker order."
  solution={`a, b = 1.0, 0.0
c, d = 0.0, 1.0
out = [a * c, a * d, b * c, b * d]
`}
  sourceChecks={[
    {name: 'prod', pattern: '\\*', must: true, hint: 'Kronecker products'},
  ]}
  tests={[
    {name: 'kron', equals: '0.0000000000 1.0000000000 0.0000000000 0.0000000000'},
  ]}
/>

:::

</Exercise>
