# 6.8b Nonlinear least-squares labs

> **Source:** Lab ideas from *Computational Physics* (Landau, Páez, Bordeianu), §6.8. Rewritten as original drills. Continues [6.8 Nonlinear fit to a resonance](./06-04-nonlinear-resonance-fit).

Build the pieces of a Breit-Wigner nonlinear fit one at a time: residuals, a finite-difference Jacobian entry, and a Newton-Raphson correction step. Stubs fail until filled in.

:::note Fixed data
Table 6.1: `E = [0,25,50,75,100,125,150,175,200]`, `sigma = [10.6,16.0,45.0,83.5,52.8,19.9,10.8,8.25,4.7]` (used as $y_i$ here, $\sigma_i\equiv1$).
:::

<Exercise title="6.8b.1 Residual f1 at a guess" anchor="exercise-cp-nl-f1">

:::tip Activity: Residual f1 at a guess
Implement $g(x,a_1,a_2,a_3)=a_1/[(x-a_2)^2+a_3]$ and the residual

$$
f_1(a_1,a_2,a_3)=\sum_{i=1}^{9}\frac{y_i-g(x_i,a)}{(x_i-a_2)^2+a_3}
$$

over the fixed Table 6.1 data.

Input: `a1 a2 a3`. Print $f_1$ with 6 decimals.

<CodeExercise

def g(x, a1, a2, a3):
    return a1 / ((x - a2) ** 2 + a3)

def f1(a1, a2, a3):

`}
  wrapSuffix={`

print(f"{f1(a1, a2, a3):.6f}")
`}
  hint="Sum (y_i - g(x_i,a)) / ((x_i-a2)**2+a3) over the 9 points."
  solution={`XS = [0, 25, 50, 75, 100, 125, 150, 175, 200]

def g(x, a1, a2, a3):

<Exercise title="6.8b.2 Jacobian entry by forward difference" anchor="exercise-cp-nl-jac">

:::tip Activity: Jacobian entry by forward difference
Using your `f1` from the previous exercise, estimate $\partial f_1/\partial a_3$ via

$$
\frac{\partial f_1}{\partial a_3}\simeq\frac{f_1(a_1,a_2,a_3+\Delta a_3)-f_1(a_1,a_2,a_3)}{\Delta a_3}, \qquad \Delta a_3=0.01\,a_3.
$$

Input: `a1 a2 a3`. Print the derivative with 8 decimals.

<Exercise title="6.8b.3 One Newton-Raphson correction" anchor="exercise-cp-nl-step">

:::tip Activity: One Newton-Raphson correction
Given a precomputed Jacobian $J$ (3×3) and residual vector $\mathbf f$ at a guess $\mathbf a$, solve $J\,\Delta\mathbf a=-\mathbf f$ (plain Gaussian elimination, no numpy) and return the updated guess $\mathbf a+\Delta\mathbf a$.

Input: 3 lines of `J` (each with 3 numbers), then one line for `f` (3 numbers), then one line for `a` (3 numbers). Print the updated `a` with 6 decimals.

<CodeExercise
  title="One Newton-Raphson correction"
  heading="exercise-cp-nl-step"
  lang="python"
  filename="main.py"
  prompt="Apply one Newton-Raphson update given J, f, and the current guess a."
  sampleLog={`(input) 2 0 0
0 3 0
0 0 4
4 9 8
10 10 10
8.000000 7.000000 8.000000`}
  starter={`def solve3(A, b):
    A = [row[:] for row in A]
    b = b[:]
    n = 3
    for i in range(n):
        piv = A[i][i]
        for j in range(i + 1, n):
            f = A[j][i] / piv
            for k in range(n):
                A[j][k] -= f * A[i][k]
            b[j] -= f * b[i]
    x = [0.0] * n
    for i in range(n - 1, -1, -1):
        s = b[i]
        for k in range(i + 1, n):
            s -= A[i][k] * x[k]
        x[i] = s / A[i][i]
    return x

def newton_step(J, f, a):
    return a
`}
  wrapSuffix={`
J = [list(map(float, input().split())) for _ in range(3)]
f = list(map(float, input().split()))
a = list(map(float, input().split()))
a_new = newton_step(J, f, a)
print(' '.join(f"{v:.6f}" for v in a_new))
`}
  hint="neg_f = [-v for v in f]; delta = solve3(J, neg_f); a_new = [a[i]+delta[i] for i in range(3)]."
  solution={`def solve3(A, b):
    A = [row[:] for row in A]
    b = b[:]
    n = 3
    for i in range(n):
        piv = A[i][i]
        for j in range(i + 1, n):
            f = A[j][i] / piv
            for k in range(n):
                A[j][k] -= f * A[i][k]
            b[j] -= f * b[i]
    x = [0.0] * n
    for i in range(n - 1, -1, -1):
        s = b[i]
        for k in range(i + 1, n):
            s -= A[i][k] * x[k]
        x[i] = s / A[i][i]
    return x

def newton_step(J, f, a):
    neg_f = [-v for v in f]
    delta = solve3(J, neg_f)
    return [a[i] + delta[i] for i in range(3)]
`}
  sourceChecks={[
    {name: 'negates residual', pattern: '-v for v in f|neg_f|-f\\[', must: true, hint: 'solve J*delta = -f, not J*delta = f'},
  ]}
  tests={[
    {
      name: 'diagonal Jacobian sample',
      stdin: '2 0 0\n0 3 0\n0 0 4\n4 9 8\n10 10 10',
      equals: '8.000000 7.000000 8.000000',
    },
  ]}
/>
