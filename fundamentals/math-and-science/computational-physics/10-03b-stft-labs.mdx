<Exercise title="10.3b.1 Box window" anchor="exercise-cp-103-box">

:::tip Activity: Rectangular $w$
Define $w(u)=1$ if $|u|\le 0.5$ else $0$. Print $w(-0.2)+w(0.7)$ with **10 decimals**.

No input.

<CodeExercise
  title="Box window samples"
  heading="exercise-cp-103-box"
  lang="python"
  filename="main.py"
  prompt="w=1 on |u|≤0.5 else 0; print w(-0.2)+w(0.7); 10 decimals."
  sampleLog={`1.0000000000`}
  starter={`def w(u):
    return 0.0  # TODO

s = w(-0.2) + w(0.7)
`}
  wrapSuffix={`
print(f"{s:.10f}")
`}
  hint="First sample 1, second 0."
  solution={`def w(u):
    return 1.0 if abs(u) <= 0.5 else 0.0

s = w(-0.2) + w(0.7)
`}
  sourceChecks={[
    {name: 'abs check', pattern: 'abs|<=', must: true, hint: 'test |u|≤0.5'},
  ]}
  tests={[
    {name: 'box', equals: '1.0000000000'},
  ]}
/>

:::

</Exercise>

<Exercise title="10.3b.2 Windowed sample" anchor="exercise-cp-103-wy">

:::tip Activity: $w(t-\tau)y(t)$
With $y=\sin(2\pi t)$, $\tau=1$, box half-width $0.5$, print the windowed value at $t=1.25$ with **10 decimals**.

No input.

<CodeExercise
  title="Windowed y at 1.25"
  heading="exercise-cp-103-wy"
  lang="python"
  filename="main.py"
  prompt="τ=1, |t−τ|≤0.5 box; y=sin(2πt); print w*y at t=1.25; 10 decimals."
  sampleLog={`1.0000000000`}
  starter={`import math

t, tau = 1.25, 1.0
y = math.sin(2.0 * math.pi * t)
w = 0.0  # TODO: 1 if |t-tau|<=0.5 else 0
val = 0.0  # TODO: w*y
`}
  wrapSuffix={`
print(f"{val:.10f}")
`}
  hint="|1.25−1|=0.25≤0.5 and sin(2π·1.25)=1."
  solution={`import math

t, tau = 1.25, 1.0
y = math.sin(2.0 * math.pi * t)
w = 1.0 if abs(t - tau) <= 0.5 else 0.0
val = w * y
`}
  sourceChecks={[
    {name: 'window', pattern: 'abs\\s*\\(\\s*t', must: true, hint: '|t−τ| test'},
  ]}
  tests={[
    {name: 'wy', equals: '1.0000000000'},
  ]}
/>

:::

</Exercise>

<Exercise title="10.3b.4 Discrete STFT bin sketch" anchor="exercise-cp-103-bin">

:::tip Activity: One-bin overlap
Approximate $\sum_k w_k y_k \cos(\omega t_k)$ with three samples $t=0.8,1.0,1.2$, $w=1$, $y=\sin(2\pi t)$, $\omega=2\pi$. Print the sum with **10 decimals**.

No input.

<CodeExercise
  title="Tiny STFT cosine sum"
  heading="exercise-cp-103-bin"
  lang="python"
  filename="main.py"
  prompt="Sum sin(2πt)*cos(2πt) at t=0.8,1.0,1.2; 10 decimals."
  sampleLog={`0.0000000000`}
  starter={`import math

omega = 2.0 * math.pi
times = [0.8, 1.0, 1.2]
acc = 1.0  # TODO: should become 0
`}
  wrapSuffix={`
print(f"{acc:.10f}")
`}
  hint="sin θ cos θ = (1/2)sin 2θ; samples symmetric about a node."
  solution={`import math

omega = 2.0 * math.pi
times = [0.8, 1.0, 1.2]
acc = 0.0
for t in times:
    acc += math.sin(omega * t) * math.cos(omega * t)
`}
  sourceChecks={[
    {name: 'loops', pattern: 'for\\s+', must: true, hint: 'sum over the three times'},
  ]}
  tests={[
    {name: 'bin', equals: '0.0000000000'},
  ]}
/>

:::

</Exercise>
