# 9.6 FFT implementation

> **Source:** Ideas from *Computational Physics* (Landau, Páez, Bordeianu), §9.6–9.7. Rewritten in original wording — **no textbook Fortran/Python listing dumps**. Continues [9.5b](./09-06b-fft-labs). Next: [9.6b](./09-07b-fft-implementation-labs).

## Power-of-two length

Classic radix-2 FFTs want $N=2^n$ samples. If your record length is not a power of two, **extend** it to the next $2^n$ (repeat a prefix, or zero-pad — both change the implied period). Because a DFT always treats the window as periodic, concatenating early samples just starts that period a little sooner; zeros assume “signal ended.”

## A concrete walk-through ($N=16$)

Assign complex probes

$$
y_m=m+mi,\qquad m=0,\ldots,15
$$

($16=2^4$ points ⇒ **four** butterfly stages after a bit-reversal shuffle). Store each sample as $(\mathrm{Re},\mathrm{Im})$. Many codes flatten to a length-$2N$ real buffer for contiguous access; that is a memory layout choice, not new mathematics.

**Pipeline:**

1. Bit-reverse permute the $N$ complex samples (or accept bit-reversed output).
2. For $s=1..\log_2 N$: run butterflies of span $2^s$ with twiddles $Z=e^{\mp 2\pi i/2^s}$.
3. Optionally multiply by the chapter’s $1/\sqrt{2\pi}$ (and $1/N$ on the inverse path) so that FFT$\circ$iFFT recovers $y$.

The DC bin without the physics factor is simply $\sum_m y_m$. For (9.78),

$$
Y_0^{\mathrm{(unnorm)}}=\sum_{m=0}^{15}(m+mi)=120+120i,
$$

and with $1/\sqrt{2\pi}$ both real and imaginary parts become $120/\sqrt{2\pi}$.

```python
    ...  # swap i <-> reverse_bits(i)

def fft_inplace(data, inverse=False):
    bitrev_permute(data)

    length = 2
    while length <= N:
        # butterflies of this span; twiddle = exp(sign*2πi/length)
        ...
        length *= 2
    if inverse:
        for k in range(N):
            data[k] /= N

```

Call a trusted library FFT for production work; implement a tiny $N=8$ or $N=16$ once so bit-reversal and butterflies stop feeling magical.

## §9.7 Assessment checklist

1. Run your FFT on $y_m=m+mi$ (or any §9.3 test tone) and **read** the bins.
2. Inverse-transform; check $\|y_{\mathrm{out}}-y_{\mathrm{in}}\|$ (with consistent norms, they match; proportional is the minimum bar).
3. Same signal through a direct $\mathcal{O}(N^2)$ DFT: compare **precision** and **wall time** as $N$ grows.
