# 6.4b Magnetization labs

> **Source:** Lab ideas from *Computational Physics* (Landau, Páez, Bordeianu), §6.4. Rewritten as original drills. Continues [6.4 Magnetization search](./06-04-magnetization-search).

At fixed reduced temperature $t$, root-find $f(m,t)=m-\tanh(m/t)=0$ for the **nontrivial** branch ($m>0$ when $t&lt;1$). Use `math.tanh`. Bisection and Newton conventions match §6.2b–6.3b ($\varepsilon=10^{-14}$; Newton uses forward difference $\delta x=10^{-6}$).

<CodeExercise
  title="Newton m(0.5)"
  heading="exercise-cp-magnet-newton"
  lang="python"
  filename="main.py"
  prompt="Newton on f(m,0.5) from 0.9; print m to 10 decimals."
  sampleLog={`0.9575040241`}
  starter={`import math

def f(m, t):
    return 0.0

def newton(fn, x0, eps=1e-14, dx=1e-6, maxit=100):
    return 0.0
`}
  wrapSuffix={`
print(f"{newton(lambda m: f(m, 0.5), 0.9):.10f}")
`}
  hint="Same Newton loop as 6.3b; start close to the root."
  solution={`import math

def f(m, t):
    return m - math.tanh(m / t)

def newton(fn, x0, eps=1e-14, dx=1e-6, maxit=100):
    x = float(x0)
    for _ in range(maxit):
        fx = fn(x)
        if abs(fx) < eps:
            return x
        dfdx = (fn(x + dx) - fx) / dx
        step = -fx / dfdx
        x = x + step
        if abs(step) < eps:
            return x
    return x
`}
  sourceChecks={[
    {name: 'Newton update', pattern: '-\\s*.*/|dfdx', must: true, hint: 'step = -f/f′'},
  ]}
  tests={[
    {name: 'm(0.5) Newton', equals: '0.9575040241'},
  ]}
/>

</Exercise>

  wrapSuffix={`

  hint="Count midpoint updates (bisection) and Newton loops as in 6.3b.4."
  solution={`import math

def f(m, t):
    return m - math.tanh(m / t)

def bisect_iters(fn, a, b, eps=1e-14):
    fa = fn(a)
    n = 0
    while (b - a) / 2 > eps:
        n += 1
        mid = (a + b) / 2
        fm = fn(mid)
        if fa * fm <= 0:
            b = mid
        else:
            a = mid
            fa = fm
    return n

def newton_iters(fn, x0, eps=1e-14, dx=1e-6, maxit=100):
    x = float(x0)
    for n in range(1, maxit + 1):
        fx = fn(x)
        if abs(fx) < eps:
            return n
        dfdx = (fn(x + dx) - fx) / dx
        step = -fx / dfdx
        x = x + step
        if abs(step) < eps:
            return n
    return maxit
`}
  sourceChecks={[
    {name: 'counts loops', pattern: 'for|while', must: true, hint: 'return the iteration counters'},
  ]}
  tests={[
    {name: '45 vs 5', equals: '45 5'},
  ]}
/>
