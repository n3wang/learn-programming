# 4.1b Monte Carlo labs

> **Source:** Lab ideas from *Computational Physics* (Landau, Páez, Bordeianu), §§4.1.2–4.2.1. Rewritten as original drills. Continues [4.1 Monte Carlo — random numbers](./04-01-monte-carlo-random).

Build a linear congruent generator, measure a pedagogical period, scale into $[A,B]$, then run unit-step 2D walks and compare $R_{\mathrm{rms}}$ to $\sqrt{N}$. Stubs fail until you fill them in. For graded walks we use a **fixed LCG** as the “random” source so outputs are reproducible.

## Labs

:::note Fixed LCG for graded walks
Build the generator labs with any $(a,c,M)$ from the prompt. For walk labs (4.1b.4 onward), use this shared LCG for draws in $[0,1)$ — not `random.random()`:

```python
# r ← (1103515245 * r + 12345) % 2**31 ; return r / 2**31
```

Each unit step: draw $\Delta x',\Delta y'$ via $2u-1$ for two uniforms $u$, then normalize to length 1.
:::

<Exercise title="4.1b.5 R_rms over trials" anchor="exercise-cp-walk-Rrms">

:::tip Activity: $R_{\mathrm{rms}}$ over trials
Run $K$ independent walks of $N$ unit steps. Trial $t=0..K-1$ uses seed `seed0 + t + 1`. Print

$\displaystyle R_{\mathrm{rms}}=\sqrt{\frac{1}{K}\sum R_t^{2}}$

with 6 decimals. (Theory for unit steps: $\sqrt{N}$.)

Input: `N K seed0`.

<CodeExercise
  title="R_rms over trials"
  heading="exercise-cp-walk-Rrms"
  lang="python"
  filename="main.py"
  prompt="Average R² over K seeded walks; print sqrt of the mean."
  sampleLog={`(input) 100 10 0
12.534830`}
  starter={`import math

def walk_R(N, seed):
    return 0.0

def R_rms(N, K, seed0):
    return 0.0
`}
  wrapSuffix={`
N, K, seed0 = map(int, input().split())
print(f"{R_rms(N, K, seed0):.6f}")
`}
  hint="Reuse walk_R. sumR2=0; for t in range(K): sumR2 += walk_R(N, seed0+t+1)**2; return sqrt(sumR2/K)."
  solution={`import math

def walk_R(N, seed):
    r = seed
    M = 2**31

    def rnd():
        nonlocal r
        r = (1103515245 * r + 12345) % M
        return r / M

    x = y = 0.0
    for _ in range(N):
        dx = rnd() * 2 - 1
        dy = rnd() * 2 - 1
        L = math.hypot(dx, dy)
        x += dx / L
        y += dy / L
    return math.hypot(x, y)

def R_rms(N, K, seed0):
    sum_r2 = 0.0
    for t in range(K):
        R = walk_R(N, seed0 + t + 1)
        sum_r2 += R * R
    return math.sqrt(sum_r2 / K)
`}
  sourceChecks={[
    {name: 'fixed LCG', pattern: '1103515245', must: true, hint: 'same LCG as the previous lab'},
    {name: 'averages R squared', pattern: 'R\\s*\\*\\s*R|\\*\\*\\s*2|pow\\s*\\(', must: true, hint: 'accumulate R² then sqrt'},
  ]}
  tests={[

<Exercise title="4.1b.7 Cross-term check" anchor="exercise-cp-walk-cross">

:::tip Activity: Cross-term check
For one unit-step walk of length $N$, store every $(\Delta x_i,\Delta y_i)$. Let $R^{2}=x^{2}+y^{2}$ at the end. Print

`abs_xx abs_xy`

where

- `abs_xx` $= \bigl|\mathrm{mean}_{i<j}(\Delta x_i\Delta x_j)\bigr|/R^{2}$
- `abs_xy` $= \bigl|\mathrm{mean}_{i,j}(\Delta x_i\Delta y_j)\bigr|/R^{2}$

each in `:.6e`. Theory wants both $\ll 1$.

Input: `N seed`.

<CodeExercise

  heading="exercise-cp-walk-cross"
  lang="python"
  filename="main.py"
  prompt="Report |⟨Δx_i Δx_{j>i}⟩|/R² and |⟨Δx_i Δy_j⟩|/R² for one walk."
  sampleLog={`(input) 80 3
1.021020e-04 3.666006e-05`}
  starter={`import math

def cross_ratios(N, seed):
    # return (abs_xx, abs_xy)
    return 0.0, 0.0
`}
  wrapSuffix={`
N, seed = map(int, input().split())
a, b = cross_ratios(N, seed)
print(f"{a:.6e} {b:.6e}")
`}
  hint="Keep lists dx,dy. xx = mean of dx[i]*dx[j] for i<j. xy = mean of all dx[i]*dy[j]. Divide abs by R²."
  solution={`import math

def cross_ratios(N, seed):
    r = seed
    M = 2**31

    def rnd():
        nonlocal r
        r = (1103515245 * r + 12345) % M
        return r / M

    dxs, dys = [], []
    x = y = 0.0
    for _ in range(N):
        dx = rnd() * 2 - 1
        dy = rnd() * 2 - 1
        L = math.hypot(dx, dy)
        dx /= L
        dy /= L
        dxs.append(dx)
        dys.append(dy)
        x += dx
        y += dy
    R2 = x * x + y * y
    s = 0.0
    m = 0
    for i in range(N):
        for j in range(i + 1, N):
            s += dxs[i] * dxs[j]
            m += 1
    xx = s / m
    s = 0.0
    for i in range(N):
        for j in range(N):
            s += dxs[i] * dys[j]
    xy = s / (N * N)
    return abs(xx) / R2, abs(xy) / R2
`}
  sourceChecks={[
    {name: 'fixed LCG', pattern: '1103515245', must: true, hint: 'deterministic LCG'},
    {name: 'pairs i<j or similar', pattern: 'range\\s*\\(\\s*i', must: true, hint: 'average cross products over pairs'},
  ]}
  tests={[
    {name: 'N=80', stdin: '80 3', equals: '1.021020e-04 3.666006e-05'},

  solution={`import math

OBS = [(3.0, 0.0, 1.5), (-2.0, 4.0, 1.2), (5.0, -3.0, 1.8), (-4.0, -2.0, 1.0), (0.0, 6.0, 1.4)]

def hits(x, y):
    return any(math.hypot(x - ox, y - oy) < r for ox, oy, r in OBS)

def walk_R(N, seed, mode):
    rstate = seed
    M = 2**31

    def rnd():
        nonlocal rstate
        rstate = (1103515245 * rstate + 12345) % M
        return rstate / M

    x = y = 0.0
    for _ in range(N):
        dx = rnd() * 2 - 1
        dy = rnd() * 2 - 1
        L = math.hypot(dx, dy)
        nx = x + dx / L
        ny = y + dy / L

        s += R * R

### Reference sketch — random walk

Textbook listings often used VPython (`visual`) for live plotting. Here is the same idea in plain Python: seed the generator (change the seed for a new path), take steps with independent $\Delta x',\Delta y'\in[-1,1]$, and print the path. For graded labs, use the **fixed LCG**, not `random.random()`.

```python
# walk_ref.py — 2D random walk (reference sketch)
import random

random.seed(None)  # None => system clock; pass an int for a fixed sequence
N = 20
x = y = 0.0
print(f"{x:.6f} {y:.6f}")
for _ in range(N):
    dx = (random.random() - 0.5) * 2.0  # in [-1, 1]
    dy = (random.random() - 0.5) * 2.0
    # Optional unit step (labs normalize; this sketch matches a raw box step):
    # import math; L = math.hypot(dx, dy) or 1.0; dx, dy = dx / L, dy / L
    x += dx
    y += dy
    print(f"{x:.6f} {y:.6f}")
```

### Reference sketch — self-avoiding HP fold

Textbook demos used VPython for a live grid. Here is the same physics in plain Python: self-avoiding steps on the square lattice, H more often than P, stop when the tip is boxed in, score $E=-\varepsilon f$ from non-bonded H–H contacts (the old “yellow dots”).

```python
# protein_fold_ref.py — self-avoiding HP walk (reference sketch)
import random

DIRS = [(1, 0), (-1, 0), (0, 1), (0, -1)]

def select_hp(p_h=0.7):
    return "H" if random.random() <= p_h else "P"

def fold(max_len=40, p_h=0.7, seed=None):
    random.seed(seed)
    occ = {(0, 0)}
    chain = [(0, 0, select_hp(p_h))]
    while len(chain) < max_len:
        x, y, _ = chain[-1]
        free = [(x + dx, y + dy) for dx, dy in DIRS if (x + dx, y + dy) not in occ]
        if not free:
            break  # corner / occupied neighbors — stop
        nx, ny = random.choice(free)
        occ.add((nx, ny))
        chain.append((nx, ny, select_hp(p_h)))
    return chain

def energy(chain, eps=1.0):
    index = {(x, y): i for i, (x, y, _) in enumerate(chain)}
    f = 0
    seen = set()
    for i, (x, y, kind) in enumerate(chain):
        if kind != "H":
            continue
        for dx, dy in DIRS:
            j = index.get((x + dx, y + dy))
            if j is None or j <= i or abs(i - j) == 1:
                continue
            if chain[j][2] != "H":
                continue
            if (i, j) in seen:
                continue
            seen.add((i, j))
            f += 1
    return -eps * f, f

if __name__ == "__main__":
    chain = fold(max_len=36, seed=11)
    E, f = energy(chain)
    print("length", len(chain), "f", f, "E", E)
    for x, y, k in chain:
        print(x, y, k)
```
