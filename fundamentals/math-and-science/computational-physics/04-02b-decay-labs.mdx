# 4.2b Spontaneous decay labs

> **Source:** Lab ideas from *Computational Physics* (Landau, Páez, Bordeianu), §4.3.4. Rewritten as original drills. Continues [4.2 Spontaneous decay](./04-02-spontaneous-decay).

Simulate discrete decay with the chapter LCG (`r ← (1103515245 r + 12345) % 2³¹`, uniform `r/2³¹`). Each time step, every remaining nucleus decays independently if `rnd() < lambda`. Stubs fail until you fill them in.

  hint="LCG state=seed. while N>0: Delta=count rnd()<lam over current N; N-=Delta; t+=1; append."
  solution={`def decay_rows(N0, lam, seed):
    r = seed
    M = 2**31

    def rnd():
        nonlocal r
        r = (1103515245 * r + 12345) % M
        return r / M

    N = N0
    t = 0
    rows = []
    while N > 0:
        Delta = 0
        for _ in range(N):
            if rnd() < lam:
                Delta += 1
        t += 1
        N -= Delta
        rows.append((t, Delta, max(N, 0)))
    return rows
`}
  sourceChecks={[

<Exercise title="4.2b.2 Early ln N slope" anchor="exercise-cp-decay-slope">

:::tip Activity: Early $\ln N$ slope
With large $N(0)$, fit $\ln N$ vs $t$ by least squares over $t=0..t_{\max}$ (include the starting point $(0,N_0)$; skip times after $N$ hits 0). Print the slope with 6 decimals. It should sit near $-\lambda$.

Input: `N0 lambda seed tmax`.

<CodeExercise
  title="Early ln N slope"
  heading="exercise-cp-decay-slope"
  lang="python"
  filename="main.py"
  prompt="Least-squares slope of ln N vs t over the early window."
  sampleLog={`(input) 5000 0.05 2 20
-0.052068`}
  starter={`import math

def early_slope(N0, lam, seed, tmax):
    return 0.0
`}
  wrapSuffix={`
N0, lam, seed, tmax = input().split()
print(f"{early_slope(int(N0), float(lam), int(seed), int(tmax)):.6f}")
`}
  hint="Collect (t,N) while N>0 and t<=tmax. OLS slope of ln N vs t."
  solution={`import math

def early_slope(N0, lam, seed, tmax):
    r = seed
    M = 2**31

    def rnd():
        nonlocal r
        r = (1103515245 * r + 12345) % M
        return r / M

    N = N0
    pts = [(0, N0)]
    for t in range(1, tmax + 1):
        if N <= 0:
            break
        Delta = sum(1 for _ in range(N) if rnd() < lam)
        N -= Delta
        if N > 0:
            pts.append((t, N))
    xs = [p[0] for p in pts]
    ys = [math.log(p[1]) for p in pts]
    n = len(xs)
    mx = sum(xs) / n
    my = sum(ys) / n
    num = sum((x - mx) * (y - my) for x, y in zip(xs, ys))
    den = sum((x - mx) ** 2 for x in xs)
    return num / den
`}
  sourceChecks={[
    {name: 'uses log', pattern: 'math\\.log|log\\s*\\(', must: true, hint: 'fit ln N'},
    {name: 'fixed LCG', pattern: '1103515245', must: true, hint: 'deterministic LCG'},
  ]}
  tests={[
    {name: 'λ=0.05', stdin: '5000 0.05 2 20', equals: '-0.052068'},
    {name: 'λ=0.10', stdin: '5000 0.10 2 20', equals: '-0.105700'},

<Exercise title="4.2b.4 Exponential vs power law" anchor="exercise-cp-decay-vs-power">

:::tip Activity: Exponential vs power law
Over $t=0..t_{\max}$ with $N>0$, compare residual sum of squares:

- **exp:** $\ln N$ vs model $\ln N_0 - \lambda t$ (use the known $\lambda$, not a fit)
- **power:** least-squares $\ln N = c + a\ln(t+1)$

Print `exp` if SSE$_{\mathrm{exp}}$ is smaller, else `power`.

Input: `N0 lambda seed tmax`.

<CodeExercise
  title="Exponential vs power law"
  heading="exercise-cp-decay-vs-power"
  lang="python"
  filename="main.py"
  prompt="Which model fits the early window better on this run?"
  sampleLog={`(input) 2000 0.05 3 40
exp`}
  starter={`import math

def better_model(N0, lam, seed, tmax):
    # return 'exp' or 'power'
    return 'exp'
`}
  wrapSuffix={`
N0, lam, seed, tmax = input().split()
print(better_model(int(N0), float(lam), int(seed), int(tmax)))
`}
  hint="Build pts. sse_exp = sum (ln N - ln N0 + λ t)^2. Fit ln N vs ln(t+1) for power SSE."
  solution={`import math

def better_model(N0, lam, seed, tmax):
    r = seed
    M = 2**31

    def rnd():
        nonlocal r
        r = (1103515245 * r + 12345) % M
        return r / M

    N = N0
    pts = [(0, N0)]
    for t in range(1, tmax + 1):
        if N <= 0:
            break
        Delta = sum(1 for _ in range(N) if rnd() < lam)
        N -= Delta
        if N > 0:
            pts.append((t, N))

    sse_exp = sum((math.log(n) - math.log(N0) + lam * t) ** 2 for t, n in pts)

    xs = [math.log(t + 1) for t, _ in pts]
    ys = [math.log(n) for _, n in pts]
    n = len(xs)
    mx = sum(xs) / n
    my = sum(ys) / n
    num = sum((x - mx) * (y - my) for x, y in zip(xs, ys))
    den = sum((x - mx) ** 2 for x in xs)
    a = num / den
    c = my - a * mx
    sse_pow = sum((y - (c + a * x)) ** 2 for x, y in zip(xs, ys))
    return "exp" if sse_exp < sse_pow else "power"
`}
  sourceChecks={[
    {name: 'compares SSE', pattern: 'sse|exp|power', must: true, hint: 'compare residual sums'},
    {name: 'fixed LCG', pattern: '1103515245', must: true, hint: 'deterministic LCG'},
  ]}
  tests={[
    {name: 'prefers exp', stdin: '2000 0.05 3 40', equals: 'exp'},
    {name: 'still exp', stdin: '2000 0.08 5 40', equals: 'exp'},

### Reference sketch — spontaneous decay

Older demos beeped with `winsound` on Windows each time a nucleus decayed. The loop below is the same physics: each survivor decays with probability $\lambda$ per time step. Print a `*` (or call your own sound API) for each decay — that irregular slowing click train is the Geiger-counter intuition. Graded labs use the **fixed LCG**, not `random.random()`.

```python
# decay_ref.py — spontaneous decay (reference sketch)
import random

random.seed(None)  # or an int for a repeatable run
lam = 0.005
N = 80
t_max = 500
print("t N")
print(0, N)
for t in range(1, t_max + 1):
    if N <= 0:
        break
    still = 0
    for _ in range(N):
        if random.random() < lam:
            # winsound.Beep(600, 100)  # optional Geiger click on Windows
            print("*", end="", flush=True)  # stand-in click
        else:
            still += 1
    N = still
    print()
    print(t, N)
```
