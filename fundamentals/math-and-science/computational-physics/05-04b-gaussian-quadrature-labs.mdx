<CodeExercise
  title="Integrate e^{-x}"
  heading="exercise-cp-gauss-exp"
  lang="python"
  filename="main.py"
  prompt="N=4 Gauss–Legendre of exp(-x) on [0,1]."
  sampleLog={`0.6321205585`}
  starter={`import math

def gauss_exp01():
    return 0.0
`}
  wrapSuffix={`
print(f"{gauss_exp01():.10f}")
`}
  hint="Reuse map_gauss4(0,1); sum w*exp(-x)."
  solution={`import math

def gauss4():
    y1, w1 = 0.339981043584856, 0.652145154862546
    y2, w2 = 0.861136311594053, 0.347854845137454
    return [(-y2, w2), (-y1, w1), (y1, w1), (y2, w2)]

def gauss_exp01():
    a, b = 0.0, 1.0
    mid = 0.5 * (a + b)
    half = 0.5 * (b - a)
    s = 0.0
    for y, wp in gauss4():
        x = mid + half * y
        w = half * wp
        s += w * math.exp(-x)
    return s
`}

<Exercise title="5.4b.5 Half-line map" anchor="exercise-cp-gauss-halfline">

:::tip Activity: Half-line map
Map one reference node with the $[0,\infty)$ rule at scale $a$:

$x=a\dfrac{1+y}{1-y}$,
$w=\dfrac{2a}{(1-y)^{2}}w'$.

Print `x w` with 10 decimals.

Input: `a y w_prime`.

<CodeExercise
  title="Half-line map"
  heading="exercise-cp-gauss-halfline"
  lang="python"
  filename="main.py"
  prompt="Map one Gauss node with the [0,∞) transform."
  sampleLog={`(input) 1 0.339981043585 0.652145154863
2.0302159969 2.9940665512`}
  starter={`def map_half(a, y, wp):
    return 0.0, 0.0
`}
  wrapSuffix={`
a, y, wp = map(float, input().split())
x, w = map_half(a, y, wp)
print(f"{x:.10f} {w:.10f}")
`}
  hint="x=a*(1+y)/(1-y); w=2*a/(1-y)**2 * wp."
  solution={`def map_half(a, y, wp):
    x = a * (1.0 + y) / (1.0 - y)
    w = (2.0 * a) / (1.0 - y) ** 2 * wp
    return x, w
`}
  sourceChecks={[
    {name: 'halfline formula', pattern: '1\\s*-\\s*y|\\(1\\s*-', must: true, hint: 'denominator (1-y)'},
