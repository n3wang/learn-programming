<Exercise title="5.2b.3 Second derivative two forms" anchor="exercise-cp-diff-d2">

:::tip Activity: Second derivative two forms
For $y=\cos t$, compute $y''$ two ways and print both with 10 decimals:

1. Staged: $y'_+= (y(t+h)-y(t))/h$, $y'_-=(y(t)-y(t-h))/h$, then $(y'_+-y'_-)/h$
2. Compact: $(y(t+h)+y(t-h)-2y(t))/h^{2}$

Input: `t h`.

<CodeExercise
  title="Second derivative two forms"
  heading="exercise-cp-diff-d2"
  lang="python"
  filename="main.py"
  prompt="Staged vs compact central y″ for cos."
  sampleLog={`(input) 1.0 0.1
-0.5398522040 -0.5398522040`}
  starter={`import math

def second_both(t, h):
    # return (d2_staged, d2_compact)
    return 0.0, 0.0
`}
  wrapSuffix={`
t, h = map(float, input().split())
a, b = second_both(t, h)
print(f"{a:.10f} {b:.10f}")
`}
  hint="Both should agree to many digits for cos; explore tiny h offline for cancellation differences."
  solution={`import math

def second_both(t, h):
    y = math.cos
    yp_p = (y(t + h) - y(t)) / h
    yp_m = (y(t) - y(t - h)) / h
    staged = (yp_p - yp_m) / h
    compact = (y(t + h) + y(t - h) - 2 * y(t)) / (h * h)
    return staged, compact
`}
  sourceChecks={[
    {name: 'compact stencil', pattern: '2\\s*\\*\\s*y|2\\s*\\*\\s*math', must: true, hint: 'y(t+h)+y(t-h)-2y(t)'},
  ]}
  tests={[
    {
      name: 'agree',
      stdin: '1.0 0.1',
      equals: '-0.5398522040 -0.5398522040',
    },
  ]}
/>

:::

</Exercise>

## Explorers

```python
# diff_ref.py
import math

def fd(y, t, h):
    return (y(t + h) - y(t)) / h

def cd(y, t, h):
    return (y(t + h / 2) - y(t - h / 2)) / h

def ed(y, t, h):
    return (8 * (y(t + h / 4) - y(t - h / 4)) - (y(t + h / 2) - y(t - h / 2))) / (3 * h)

def d2(y, t, h):
    return (y(t + h) - 2 * y(t) + y(t - h)) / (h * h)
```
