<Exercise title="10.7b.4 One CWT coefficient" anchor="exercise-cp-107-cwt">

:::tip Activity: Riemann $Y(s,\tau)$
Given `sig = [1, 0.5, 0, -0.5, -1, -0.5, 0, 0.5]`, $W=8$, $N=8$, $h=W/N$,
advance $t$ by $h$ **before** each term (start $t=0$), use $s=0.5$, $\tau=2$, and print
$Y=\bigl(\sum y_i\Psi((t-\tau)/s)\,h\bigr)/\sqrt{s}$ with **10 decimals**.

No input.

<CodeExercise
  title="Toy CWT point"
  heading="exercise-cp-107-cwt"
  lang="python"
  filename="main.py"
  prompt="One (s,τ) Morlet CWT sample; 10 decimals."
  sampleLog={`0.0549718913`}
  starter={`import math

sig = [1.0, 0.5, 0.0, -0.5, -1.0, -0.5, 0.0, 0.5]
W, N = 8.0, 8
h = W / N
s, tau = 0.5, 2.0
t = 0.0
acc = 0.0
for yi in sig:
    t += h
    T = (t - tau) / s
    # TODO: acc += yi * sin(8T)*exp(-T²/2) * h
Yn = 0.0  # TODO: acc / sqrt(s)
`}
  wrapSuffix={`
print(f"{Yn:.10f}")
`}
  hint="Accumulate then divide by sqrt(s)."
  solution={`import math

sig = [1.0, 0.5, 0.0, -0.5, -1.0, -0.5, 0.0, 0.5]
W, N = 8.0, 8
h = W / N
s, tau = 0.5, 2.0
t = 0.0
acc = 0.0
for yi in sig:
    t += h
    T = (t - tau) / s
    acc += yi * math.sin(8 * T) * math.exp(-0.5 * T * T) * h
Yn = acc / math.sqrt(s)
`}
  sourceChecks={[
    {name: 'loop', pattern: 'for', must: true, hint: 'sum over samples'},
  ]}
  tests={[
    {name: 'Yn', equals: '0.0549718913'},
  ]}
/>

:::

</Exercise>
