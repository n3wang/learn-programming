<Exercise title="9.3b.3 Coarse samples both zero" anchor="exercise-cp-93-coarse">

:::tip Activity: Missed sinusoids
At $t=0,2,4,6,8$, both $\sin(\pi t/2)$ and $\sin(2\pi t)$ vanish. Print the sum of absolute values of both functions over those five times with **10 decimals** (should be $0$).

No input.

<CodeExercise
  title="Coarse sample sum"
  heading="exercise-cp-93-coarse"
  lang="python"
  filename="main.py"
  prompt="Sum |sin(πt/2)|+|sin(2πt)| at t=0,2,4,6,8; 10 decimals."
  sampleLog={`0.0000000000`}
  starter={`import math

times = [0.0, 2.0, 4.0, 6.0, 8.0]
total = 1.0  # TODO: should become 0
`}
  wrapSuffix={`
print(f"{total:.10f}")
`}
  hint="Every sample is a node of both waves."
  solution={`import math

times = [0.0, 2.0, 4.0, 6.0, 8.0]
total = 0.0
for t in times:
    total += abs(math.sin(math.pi * t / 2.0)) + abs(math.sin(2.0 * math.pi * t))
`}
  sourceChecks={[
    {name: 'loops times', pattern: 'for\\s+', must: true, hint: 'loop over the five times'},
  ]}
  tests={[
    {name: 'all zero', equals: '0.0000000000'},
  ]}
/>

:::

</Exercise>

<Exercise title="9.3b.4 Alias sample match" anchor="exercise-cp-93-alias">

:::tip Activity: $f$ vs $f-2s$
With sampling rate $s=1$ (integer times), $f=1.25$ and $f-2s=-0.75$ give identical $\cos(2\pi f t)$ samples. Print the max absolute difference over $t=0..7$ with **10 decimals**.

No input.

<CodeExercise
  title="Alias cosine difference"
  heading="exercise-cp-93-alias"
  lang="python"
  filename="main.py"
  prompt="Max |cos(2π·1.25·t)−cos(2π·(−0.75)·t)| for t=0..7; 10 decimals."
  sampleLog={`0.0000000000`}
  starter={`import math

f = 1.25
fa = f - 2.0  # -0.75 when s=1
mx = 1.0  # TODO
`}
  wrapSuffix={`
print(f"{mx:.10f}")
`}
  hint="Loop integer t; track max abs difference."
  solution={`import math

f = 1.25
fa = f - 2.0
mx = 0.0
for t in range(8):
    d = abs(math.cos(2.0 * math.pi * f * t) - math.cos(2.0 * math.pi * fa * t))
    if d > mx:
        mx = d
`}
  sourceChecks={[
    {name: 'uses cos', pattern: 'cos\\s*\\(', must: true, hint: 'compare cosines'},
  ]}
  tests={[
    {name: 'alias diff', equals: '0.0000000000'},
  ]}
/>

:::

</Exercise>

<Exercise title="9.3b.6 One DFT bin (real even)" anchor="exercise-cp-93-dft-bin">

:::tip Activity: Manual DFT real part
Let $N=8$, $y_k=\cos(2\pi k/N)$ (pure bin $n=1$). With
$Y_n=\frac{1}{\sqrt{2\pi}}\sum_{k=0}^{N-1} y_k e^{-2\pi i kn/N}$,
print $\mathrm{Re}(Y_1)$ with **10 decimals**.

No input.

<CodeExercise
  title="Re Y1 for cos bin"
  heading="exercise-cp-93-dft-bin"
  lang="python"
  filename="main.py"
  prompt="N=8, y=cos(2πk/N); print Re(Y_1) with book 1/√(2π) DFT; 10 decimals."
  sampleLog={`1.5957691216`}
  starter={`import math
import cmath

N = 8
n = 1
Y = 0j
# TODO: sum y_k * exp(-2πi k n / N), then / sqrt(2π); take .real
re = 0.0
`}
  wrapSuffix={`
print(f"{re:.10f}")
`}
  hint="y_k = cos(2*pi*k/N); accumulate complex sum."
  solution={`import math
import cmath

N = 8
n = 1
Y = 0j
for k in range(N):
    yk = math.cos(2.0 * math.pi * k / N)
    Y += yk * cmath.exp(-2j * math.pi * k * n / N)
Y /= math.sqrt(2.0 * math.pi)
re = Y.real
`}
  sourceChecks={[
    {name: 'uses exp or cos/sin', pattern: 'exp|cos', must: true, hint: 'form the DFT sum'},
    {name: 'normalizes', pattern: 'sqrt', must: true, hint: 'divide by sqrt(2π)'},
  ]}
  tests={[
    {name: 'Re Y1', equals: '1.5957691216'},
  ]}
/>

:::

</Exercise>
