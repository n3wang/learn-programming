# 7.3b Matrices in Python labs

> **Source:** Lab ideas from *Computational Physics* (Landau, Páez, Bordeianu), §7.3–7.3.3. Rewritten as original drills. Continues [7.3 Matrices in Python](./07-01-matrices-in-python).

These drills implement what NumPy gives you for free (`+`, `dot`, `solve`) using plain Python lists — so build them yourself with `list`/`list-of-lists`, not `numpy` (the exercise sandbox has no third-party packages anyway). This reinforces exactly why a real array type is worth having. Stubs fail until filled in.

<Exercise title="7.3b.2 True matrix product (dot)" anchor="exercise-cp-np-dot">

:::tip Activity: True matrix product (dot)
Implement the real matrix product of two $n\times n$ matrices (represented as lists of lists) — what NumPy's `dot(A, B)` computes, as opposed to `A * B`'s elementwise product.

Input: `n`, then `n` rows of matrix `A`, then `n` rows of matrix `B`. Print the product, one row per line, space-separated.

<CodeExercise
  title="True matrix product (dot)"
  heading="exercise-cp-np-dot"
  lang="python"
  filename="main.py"
  prompt="Compute the real matrix product A dot B for two n x n matrices."
  sampleLog={`(input) 2
0 1
1 3
0 1
1 3
1 3
3 10`}
  starter={`def matmul(A, B):
    n = len(A)
    return [[0] * n for _ in range(n)]
`}
  wrapSuffix={`
n = int(input())
A = [list(map(float, input().split())) for _ in range(n)]
B = [list(map(float, input().split())) for _ in range(n)]
C = matmul(A, B)
for row in C:
    print(' '.join(str(int(v)) for v in row))
`}
  hint="C[i][j] = sum(A[i][k]*B[k][j] for k in range(n)) — the standard row-times-column rule."
  solution={`def matmul(A, B):
    n = len(A)
    C = [[0.0] * n for _ in range(n)]
    for i in range(n):
        for j in range(n):
            C[i][j] = sum(A[i][k] * B[k][j] for k in range(n))
    return C
`}
  sourceChecks={[
    {name: 'row-times-column sum', pattern: 'A\\[i\\]\\[k\\]\s*\\*\s*B\\[k\\]\\[j\\]', must: true, hint: 'sum over k of A[i][k]*B[k][j]'},
  ]}
  tests={[
    {
      name: "book's matrix1 dot matrix1",
      stdin: '2\n0 1\n1 3\n0 1\n1 3',
      equals: '1 3\n3 10',

<Exercise title="7.3b.4 Solve Ax=b (what numpy.linalg.solve does)" anchor="exercise-cp-np-solve">

:::tip Activity: Solve Ax=b (what numpy.linalg.solve does)
Implement Gaussian elimination for a general $n\times n$ system, the pure-Python equivalent of `numpy.linalg.solve(A, b)`.

Input: `n`, then `n` rows of `A`, then one line for `b`. Print `x`, space-separated, 6 decimals.

<CodeExercise
  title="Solve Ax=b (what numpy.linalg.solve does)"
  heading="exercise-cp-np-solve"
  lang="python"
  filename="main.py"
  prompt="Solve the general n x n linear system Ax=b via Gaussian elimination."
  sampleLog={`(input) 3
1 2 3
22 32 42
55 66 100
1 2 3
-1.405797 -0.188406 0.927536`}
  starter={`def solve(A, b):
    n = len(b)
    return [0.0] * n
`}
  wrapSuffix={`
n = int(input())
A = [list(map(float, input().split())) for _ in range(n)]
b = list(map(float, input().split()))
x = solve(A, b)
print(' '.join(f"{v:.6f}" for v in x))
`}
  hint="Standard Gaussian elimination: forward-eliminate to upper-triangular, then back-substitute."
  solution={`def solve(A, b):
    n = len(b)
    A = [row[:] for row in A]
    b = b[:]
    for i in range(n):
        piv = A[i][i]
        for j in range(i + 1, n):
            f = A[j][i] / piv
            for k in range(n):
                A[j][k] -= f * A[i][k]
            b[j] -= f * b[i]
    x = [0.0] * n
    for i in range(n - 1, -1, -1):
        s = b[i]
        for k in range(i + 1, n):
            s -= A[i][k] * x[k]
        x[i] = s / A[i][i]
    return x
`}
  sourceChecks={[
    {name: 'forward elimination then back substitution', pattern: 'A\\[j\\]\\[k\\]\s*-=|A\\[i\\]\\[k\\]\s*\\*\s*x\\[k\\]', must: true, hint: 'eliminate below the pivot, then solve from the last row upward'},
  ]}
  tests={[
    {
      name: "book's A x = b example",
      stdin: '3\n1 2 3\n22 32 42\n55 66 100\n1 2 3',
      equals: '-1.405797 -0.188406 0.927536',
    },
  ]}
/>

```python
# matrix_ref.py — matmul and Gaussian-elimination solve (original sketch)
def matmul(A, B):
    n = len(A)
    return [[sum(A[i][k] * B[k][j] for k in range(n)) for j in range(n)] for i in range(n)]

def solve(A, b):
    n = len(b)
    A = [row[:] for row in A]
    b = b[:]
    for i in range(n):
        piv = A[i][i]
        for j in range(i + 1, n):
            f = A[j][i] / piv
            for k in range(n):
                A[j][k] -= f * A[i][k]
            b[j] -= f * b[i]
    x = [0.0] * n
    for i in range(n - 1, -1, -1):
        s = b[i]
        for k in range(i + 1, n):
            s -= A[i][k] * x[k]
        x[i] = s / A[i][i]
    return x
```
