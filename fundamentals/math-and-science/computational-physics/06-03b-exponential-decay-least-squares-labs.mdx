<Exercise title="6.6b.1 Linear regression (equal weights)" anchor="exercise-cp-lsq-linreg">

:::tip Activity: Linear regression (equal weights)
Implement the numerically stable linear-regression formulas (6.51) with $\sigma_i\equiv1$:

$$
a_2=\frac{S_{xy}}{S_{xx}},\quad a_1=\bar y-a_2\bar x,\quad
S_{xy}=\sum_i(x_i-\bar x)(y_i-\bar y),\quad S_{xx}=\sum_i(x_i-\bar x)^2.
$$

Input: first line `n`, then `n` lines of `x_i y_i`. Print `a1 a2` with 6 decimals.

<CodeExercise
  title="Linear regression (equal weights)"
  heading="exercise-cp-lsq-linreg"

  filename="main.py"
  prompt="Fit y=a1+a2*x by least squares, sigma_i=1."
  sampleLog={`(input) 4
0 1
1 3
2 5
3 7
1.000000 2.000000`}
  starter={`def linreg(xs, ys):
    return 0.0, 0.0
`}
  wrapSuffix={`
n = int(input())
xs, ys = [], []
for _ in range(n):
    x, y = map(float, input().split())
    xs.append(x)
    ys.append(y)
a1, a2 = linreg(xs, ys)
print(f"{a1:.6f} {a2:.6f}")
`}
  hint="xbar = mean(xs), ybar = mean(ys); a2 = sum((x-xbar)*(y-ybar)) / sum((x-xbar)**2); a1 = ybar - a2*xbar."
  solution={`def linreg(xs, ys):
    n = len(xs)
    xbar = sum(xs) / n
    ybar = sum(ys) / n
    sxy = sum((xs[i] - xbar) * (ys[i] - ybar) for i in range(n))
    sxx = sum((xs[i] - xbar) ** 2 for i in range(n))
    a2 = sxy / sxx
    a1 = ybar - a2 * xbar
    return a1, a2
`}
  sourceChecks={[
    {name: 'uses mean-centered sums', pattern: 'xbar|mean', must: true, hint: 'use the (6.51) mean-centered form, not the raw S/Sx/Sxx formula'},
  ]}
  tests={[
    {name: 'exact line y=1+2x', stdin: '4\n0 1\n1 3\n2 5\n3 7', equals: '1.000000 2.000000'},
  ]}
/>

:::tip Activity: Decay lifetime from log-linear fit

    n = len(xs)

<Exercise title="6.6b.4 Quadratic least-squares fit" anchor="exercise-cp-lsq-quad">

:::tip Activity: Quadratic least-squares fit
Fit $g(x)=a_1+a_2x+a_3x^2$ (equal weights, $\sigma_i\equiv1$) by building the $3\times3$ system (6.56)-(6.57) and solving it with plain Gaussian elimination (no numpy).

Input: first line `n`, then `n` lines of `x_i y_i`. Print `a1 a2 a3` with 4 decimals.

<CodeExercise
  title="Quadratic least-squares fit"
  heading="exercise-cp-lsq-quad"
  lang="python"
  filename="main.py"
  prompt="Least-squares fit of a quadratic to (x_i, y_i) data."
  sampleLog={`(input) 4
0 1
1 3
2 7
3 15
1.1000 0.1000 1.5000`}
  starter={`def solve3(A, b):
    A = [row[:] for row in A]
    b = b[:]
    n = 3
    for i in range(n):
        piv = A[i][i]
        for j in range(i + 1, n):
            f = A[j][i] / piv
            for k in range(n):
                A[j][k] -= f * A[i][k]
            b[j] -= f * b[i]
    x = [0.0] * n
    for i in range(n - 1, -1, -1):
        s = b[i]
        for k in range(i + 1, n):
            s -= A[i][k] * x[k]
        x[i] = s / A[i][i]
    return x

def quad_fit(xs, ys):
    return 0.0, 0.0, 0.0
`}
  wrapSuffix={`
n = int(input())
xs, ys = [], []
for _ in range(n):
    x, y = map(float, input().split())
    xs.append(x)
    ys.append(y)
a1, a2, a3 = quad_fit(xs, ys)
print(f"{a1:.4f} {a2:.4f} {a3:.4f}")
`}
  hint="Build S, Sx, Sxx, Sxxx, Sxxxx, Sy, Sxy, Sxxy from the data, assemble the 3x3 matrix A and vector b from (6.57), and call solve3(A, b)."
  solution={`def solve3(A, b):
    A = [row[:] for row in A]
    b = b[:]
    n = 3
    for i in range(n):
        piv = A[i][i]
        for j in range(i + 1, n):
            f = A[j][i] / piv
            for k in range(n):
                A[j][k] -= f * A[i][k]
            b[j] -= f * b[i]
    x = [0.0] * n
    for i in range(n - 1, -1, -1):
        s = b[i]
        for k in range(i + 1, n):
            s -= A[i][k] * x[k]
        x[i] = s / A[i][i]
    return x

def quad_fit(xs, ys):
    n = len(xs)
    S = float(n)
    Sx = sum(xs)
    Sxx = sum(x * x for x in xs)
    Sxxx = sum(x ** 3 for x in xs)
    Sxxxx = sum(x ** 4 for x in xs)
    Sy = sum(ys)
    Sxy = sum(xs[i] * ys[i] for i in range(n))
    Sxxy = sum(xs[i] ** 2 * ys[i] for i in range(n))
    A = [[S, Sx, Sxx], [Sx, Sxx, Sxxx], [Sxx, Sxxx, Sxxxx]]
    b = [Sy, Sxy, Sxxy]
    a1, a2, a3 = solve3(A, b)
    return a1, a2, a3
`}
  sourceChecks={[
    {name: 'builds 3x3 system', pattern: 'Sxxxx|Sxxx', must: true, hint: 'assemble S, Sx, Sxx, Sxxx, Sxxxx from the data'},

  <Problem

    answer={`Taking the log gives ln N(t) = ln N0 - t/tau, which is linear in t with slope -1/tau and intercept ln N0, so ordinary linear regression on (t, ln N) recovers tau and N0.`}

  <Problem
