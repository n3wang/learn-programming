# 8.7 ODE solver sketches

> **Source:** Structural ideas from *Computational Physics* (Landau, Páez, Bordeianu), §8.7 listings. **Original sketches only** — do **not** paste `rk4.py`, `rk45.py`, `ABM.py`, or VPython GUIs from the book / Mathpix CDN.

## Fixed-step RK2 / RK4 (sandbox-ready)

Graded work in [8.4b](./08-03b-ode-algorithms-labs) already implements these. Structure reminder:

```python
# rk_fixed_sketch.py — original structure (pure Python)
def f(t, y, params):
    x, v = y
    # return [v, F(x,v,t)/m]
    ...

def rk2_step(t, y, h, params):
    k1 = scale(h, f(t, y, params))
    y_mid = add(y, scale(0.5, k1))
    k2 = scale(h, f(t + 0.5 * h, y_mid, params))
    return add(y, k2)

def rk4_step(t, y, h, params):
    k1 = f(t, y, params)
    k2 = f(t + 0.5 * h, add(y, scale(0.5 * h, k1)), params)
    k3 = f(t + 0.5 * h, add(y, scale(0.5 * h, k2)), params)
    k4 = f(t + h, add(y, scale(h, k3)), params)
    incr = scale(h / 6.0, add(k1, add(scale(2, k2), add(scale(2, k3), k4))))
    return add(y, incr)
```

Swap `F` for harmonic, $|x|^{p}$, soft $\alpha$, or $-bv+F_0\cos\omega t$ without changing the stepper.

## Adaptive RK45 (sketch only)

Two formulas of different order share stages. Their difference estimates the local error; grow or shrink $h$ to hit a tolerance. Pseudocode:

```python
# rk45_adapt_sketch.py — structure only (original)
def rk45_step(t, y, h, tol, params):
    # evaluate shared stages → y4 (order 4) and y5 (order 5)
    # err ≈ ||y5 - y4||
    # if err < tol: accept y5 (or y4), maybe increase h
    # else: reject, shrink h, retry
    ...
```

Not required for locked labs; useful when stiffness or sharp drives make fixed $h$ wasteful.

## When to prefer fixed RK4 vs adaptive RK45

| Prefer fixed RK4 | Prefer adaptive RK45 |
| --- | --- |
| Smooth $F$, known period, you want reproducible $h$ | Sharp kicks, stiffness, or unknown timescales |
| Energy / period scans at fixed resolution | Hitting a tolerance with fewer $f$ calls |
| Graded sandbox locks (stdout samples) | Local notebooks once RK4 energy checks pass |

Fixed RK4 with a **chosen** $h$ is easier to debug: if energy drifts, shrink $h$ or fix $F$. Adaptive methods hide the step size — great for production, worse for learning the truncation story.

## Energy check (use the explorer)

For conservative forces, monitor

$$
E=\tfrac12 mv^2+V(x)
$$

along the trajectory. A good stepper keeps $E$ flat to many digits; Euler drifts; RK4 usually holds until $h$ is too coarse. Use the harmonic explorer below to compare methods before trusting a nonlinear run.

## Adams–Bashforth–Moulton (sketch only)

Multistep methods store a short history of $\mathbf f$ values. Adams–Bashforth **predicts** $\mathbf y_{n+1}$; Adams–Moulton **corrects** with an implicit formula (often one evaluation of $\mathbf f$ at the predicted point). Startup needs a single-step RK fill of the history.
