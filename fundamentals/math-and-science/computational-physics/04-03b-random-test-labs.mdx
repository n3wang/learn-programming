<Exercise title="4.3b.1 Moment √N errors" anchor="exercise-cp-rng-moments">

:::tip Activity: Moment $\sqrt{N}$ errors
Draw $N$ uniforms from seed `seed`. For $k=1,3,7$ print

$\displaystyle\sqrt{N}\left|\frac{1}{N}\sum x_i^{k}-\frac{1}{k+1}\right|$

with 6 decimals, space-separated on one line.

Input: `N seed`.

<CodeExercise
  title="Moment √N errors"
  heading="exercise-cp-rng-moments"
  lang="python"
  filename="main.py"
  prompt="Print three √N|⟨x^k⟩−1/(k+1)| values for k=1,3,7."
  sampleLog={`(input) 100 1
0.154895 0.068253 0.043376`}
  starter={`def moment_stats(N, seed):
    # return (stat_k1, stat_k3, stat_k7)
    return 0.0, 0.0, 0.0
`}
  wrapSuffix={`
N, seed = map(int, input().split())
a, b, c = moment_stats(N, seed)
print(f"{a:.6f} {b:.6f} {c:.6f}")
`}
  hint="Generate list xs. For each k in (1,3,7): m=mean(x**k); append sqrt(N)*abs(m-1/(k+1))."
  solution={`def moment_stats(N, seed):
    r = seed
    M = 2**31
    xs = []
    for _ in range(N):
        r = (1103515245 * r + 12345) % M
        xs.append(r / M)
    out = []
    for k in (1, 3, 7):
        m = sum(x**k for x in xs) / N
        out.append((N**0.5) * abs(m - 1 / (k + 1)))
    return tuple(out)
`}
  sourceChecks={[
    {name: 'fixed LCG', pattern: '1103515245', must: true, hint: 'chapter LCG'},
    {name: 'moments 1,3,7', pattern: '1.*3.*7|\\(1,\\s*3,\\s*7\\)', must: true, hint: 'k = 1, 3, 7'},
  ]}
  tests={[
    {name: 'N=100', stdin: '100 1', equals: '0.154895 0.068253 0.043376'},
    {name: 'N=10000', stdin: '10000 1', equals: '0.251548 0.179018 0.030592'},
    {name: 'N=100000', stdin: '100000 1', equals: '0.492209 0.395367 0.186067'},
  ]}
/>

:::

</Exercise>

<Exercise title="4.3b.2 Lag product C(k)" anchor="exercise-cp-rng-Ck">

:::tip Activity: Lag product $C(k)$
With cyclic wrap $x_{i+k}\equiv x_{(i+k)\bmod N}$, compute

$C(k)=\dfrac{1}{N}\sum_i x_i x_{i+k}$

and

$\sqrt{N}\,|C(k)-1/4|$.

Print `C scaled` with 6 decimals each.

Input: `N seed k`.

<CodeExercise
  title="Lag product C(k)"
  heading="exercise-cp-rng-Ck"
  lang="python"
  filename="main.py"
  prompt="C(k) and √N|C−1/4| for the chapter LCG."
  sampleLog={`(input) 100 1 1
0.266878 0.168785`}
  starter={`def C_stats(N, seed, k):
    # return (C, sqrtN_abs_err)
    return 0.0, 0.0
`}
  wrapSuffix={`
N, seed, k = map(int, input().split())
C, scaled = C_stats(N, seed, k)
print(f"{C:.6f} {scaled:.6f}")
`}
  hint="xs from LCG; C = mean xs[i]*xs[(i+k)%N]; scaled = sqrt(N)*abs(C-0.25)."
  solution={`def C_stats(N, seed, k):
    r = seed
    M = 2**31
    xs = []
    for _ in range(N):
        r = (1103515245 * r + 12345) % M
        xs.append(r / M)
    C = sum(xs[i] * xs[(i + k) % N] for i in range(N)) / N
    return C, (N**0.5) * abs(C - 0.25)
`}
  sourceChecks={[
    {name: 'fixed LCG', pattern: '1103515245', must: true, hint: 'chapter LCG'},
    {name: 'cyclic lag', pattern: '%\\s*N|mod', must: true, hint: 'wrap index with % N'},
  ]}
  tests={[
    {name: 'N=100 k=1', stdin: '100 1 1', equals: '0.266878 0.168785'},
    {name: 'N=10000 k=1', stdin: '10000 1 1', equals: '0.252430 0.242992'},
    {name: 'N=10000 k=2', stdin: '10000 1 2', equals: '0.253951 0.395053'},
  ]}
/>

:::

</Exercise>

<Exercise title="4.3b.3 Uniformity verdict" anchor="exercise-cp-rng-verdict">

:::tip Activity: Uniformity verdict
For given $N$, seed, and $k$, print `ok` if

$\sqrt{N}\left|\langle x^{k}\rangle-1/(k+1)\right| < 3$

else `fail`. (A crude “order 1” gate for the book’s printout.)

Input: `N seed k`.

<CodeExercise
  title="Uniformity verdict"
  heading="exercise-cp-rng-verdict"
  lang="python"
  filename="main.py"
  prompt="ok if √N|moment error| < 3, else fail."
  sampleLog={`(input) 10000 1 1
ok`}
  starter={`def verdict(N, seed, k):
    return 'fail'
`}
  wrapSuffix={`
N, seed, k = map(int, input().split())
print(verdict(N, seed, k))
`}
  hint="Same moment statistic as 4.3b.1 for a single k; compare to 3."
  solution={`def verdict(N, seed, k):
    r = seed
    M = 2**31
    xs = []
    for _ in range(N):
        r = (1103515245 * r + 12345) % M
        xs.append(r / M)
    m = sum(x**k for x in xs) / N
    stat = (N**0.5) * abs(m - 1 / (k + 1))
    return 'ok' if stat < 3 else 'fail'
`}
  sourceChecks={[
    {name: 'fixed LCG', pattern: '1103515245', must: true, hint: 'chapter LCG'},
    {name: 'ok/fail', pattern: 'ok|fail', must: true, hint: 'print ok or fail'},
  ]}
  tests={[
    {name: 'pass', stdin: '10000 1 1', equals: 'ok'},
    {name: 'pass k=7', stdin: '100 1 7', equals: 'ok'},
  ]}
/>

:::

</Exercise>
