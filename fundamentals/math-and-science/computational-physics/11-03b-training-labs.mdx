<Exercise title="11.3b.4 One-sample $\partial\mathcal{L}/\partial w_1$" anchor="exercise-cp-113-grad">

:::tip Activity: Chain rule
For the same all-ones net on $(x_1,x_2)=(-2,-1)$, $y^c=1$, use
$\partial\mathcal{L}/\partial y^p=-2(y^c-y^p)$ (single-sample $N=1$ form),
$\partial y^p/\partial h_1=w_5 f'(h_1+h_2)$,
$\partial h_1/\partial w_1=x_1 f'(x_1+x_2)$,
and print $\partial\mathcal{L}/\partial w_1$ with **10 decimals**.

No input.

<CodeExercise
  title="dL/dw1"
  heading="exercise-cp-113-grad"
  lang="python"
  filename="main.py"
  prompt="Chain-rule gradient; 10 decimals."
  sampleLog={`0.0214695353`}
  starter={`import math

    return 1.0 / (1.0 + math.exp(-z))

    return f * (1.0 - f)

x1, x2 = -2.0, -1.0
yc = 1.0
h = sigmoid(x1 + x2)
yp = sigmoid(h + h)
dL_dy = 0.0  # TODO
dy_dh = 0.0  # TODO
dh_dw = 0.0  # TODO
dL_dw1 = 0.0  # TODO product
`}
  wrapSuffix={`
print(f"{dL_dw1:.10f}")
`}
  hint="dL_dy=-2*(yc-yp); dy_dh=1*dsigmoid(2*h); dh_dw=x1*dsigmoid(x1+x2)."
  solution={`import math

def sigmoid(z):
    return 1.0 / (1.0 + math.exp(-z))

def dsigmoid(z):
    f = sigmoid(z)
    return f * (1.0 - f)

x1, x2 = -2.0, -1.0
yc = 1.0
h = sigmoid(x1 + x2)
yp = sigmoid(h + h)
dL_dy = -2.0 * (yc - yp)
dy_dh = 1.0 * dsigmoid(h + h)
dh_dw = x1 * dsigmoid(x1 + x2)
dL_dw1 = dL_dy * dy_dh * dh_dw
`}
  sourceChecks={[
    {name: 'product', pattern: '\\*', must: true, hint: 'multiply the three factors'},
  ]}
  tests={[
    {name: 'grad', equals: '0.0214695353'},
