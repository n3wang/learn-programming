# 12.7 Qiskit plus IBM Quantum

> **Source:** Ideas from *Computational Physics* (Landau, Páez, Bordeianu), §12.7. **Original sketches** — package names (`Aer`, `IBMProvider`, …) evolve; check current Qiskit docs. Continues [12.6](./12-06-ibm-quantum). Labs: [12.7b](./12-07b-qiskit-labs).

[Qiskit](https://www.ibm.com/quantum/qiskit) is an open-source SDK for circuits, simulators, and IBM hardware. Running the **same** circuit on a noiseless simulator and on a real backend shows how decoherence and gate error tilt histograms away from ideal $|\beta_{00}\rangle$ peaks.

## Bell circuit in Qiskit

```python
# beta00_sketch.py — structure
from qiskit import QuantumCircuit

circuit = QuantumCircuit(2)
circuit.h(0)
circuit.cx(0, 1)
# circuit.draw("mpl")  # local matplotlib
```

Same gate order as Composer / Cirq: H on qubit 0, CNOT control→target.

## Statevector and density city plot

On a **statevector simulator**, retrieve the amplitudes and visualize $\mathrm{Re}/\mathrm{Im}$ of the density matrix $\rho=|\psi\rangle\langle\psi|$ (city plot). For ideal $|\beta_{00}\rangle$ the imaginary part is zero and the real part shows the $|00\rangle$ / $|11\rangle$ block structure (Figure 12.6).

![Figure 12.6 — density city sketch.](/img/computational-physics/fig-12-6-bell-density.svg)

Graded labs lock the ideal amplitudes $1/\sqrt2$ without importing Qiskit.

## Hardware path (conceptual)

1. Authenticate with your saved account.  
2. Pick an operational backend with enough qubits (historically “least busy”; APIs change).  
3. `measure_all()` (or explicit measures), **transpile** to the device’s native gates / coupling map.  
4. Submit the job, monitor, download counts.

Expect $|00\rangle$ and $|11\rangle$ to dominate, with small leakage into $|01\rangle$ / $|10\rangle$ from noise — unlike the perfect simulator.
