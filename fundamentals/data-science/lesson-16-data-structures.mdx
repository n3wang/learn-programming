> **Source:** Concepts adapted from *Ace the Data Science Interview* — Chapter 9 (“Coding”) by Kevin Huo & Nick Singh. Rewritten in original wording for this course.

Know what each structure is good at, the usual Big-O, and **implement a tiny version** in both **Python** and **C++**. Interviewers care that you can build the tool, not only name it.

| Structure | Access | Search | Insert / delete | Notes |
| --- | --- | --- | --- | --- |
| Array / list | $O(1)$ index | $O(N)$ unsorted | End often amortized $O(1)$ | Off-by-one |
| Stack | top $O(1)$ | — | push/pop $O(1)$ | LIFO |
| Queue | front $O(1)$ | — | enqueue/dequeue $O(1)$ | FIFO |
| Linked list | $O(N)$ | $O(N)$ | $O(1)$ at known node | Pointer bugs |
| Hash map | — | avg $O(1)$ | avg $O(1)$ | Collisions |
| Balanced BST | $O(\log N)$ | $O(\log N)$ | $O(\log N)$ | Skew → $O(N)$ |
| Heap | min/max $O(1)$ | $O(N)$ | $O(\log N)$ | Priority queues |
| Graph (adj list) | — | BFS/DFS $O(V+E)$ | — | Sparse-friendly |

## Arrays / dynamic arrays

Consecutive elements, $O(1)$ index. Weak for search/delete of arbitrary values unless sorted. Patterns: two pointers, prefix sums, in-place tricks. Python `list` and C++ `vector` are dynamic arrays (amortized $O(1)$ append).

    def __init__(self, capacity=16):
        self.cap = capacity
        self.buckets = [[] for _ in range(capacity)]
        self.n = 0
    def _i(self, key):
        return key % self.cap
    def put(self, key, val):
        b = self.buckets[self._i(key)]
        for i, (k, _) in enumerate(b):
            if k == key:
                b[i] = (key, val)
                return
        b.append((key, val))
        self.n += 1
    def get(self, key):
        for k, v in self.buckets[self._i(key)]:
            if k == key:
                return v
        return None
    def size(self):
        return self.n
