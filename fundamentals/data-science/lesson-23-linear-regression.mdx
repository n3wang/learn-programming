## The model

We model a continuous response as a linear function of features plus noise:

$$
y = \beta_0 + \beta_1 x_1 + \cdots + \beta_p x_p + \varepsilon
$$

In matrix form $y = X\beta + \varepsilon$ (with a column of ones in $X$ for the intercept). **Simple** regression has one $x$; **multiple** regression has many.

**Interpretation:** $\beta_j$ is the change in expected $y$ for a one-unit increase in $x_j$, holding other features fixed (ceteris paribus). That “holding fixed” story breaks down under multicollinearity or omitted-variable bias — interview gold.

## Ordinary least squares (OLS)

OLS chooses $\beta$ to minimize squared residuals:

$$
\hat\beta = \arg\min_\beta \| y - X\beta \|_2^2
$$

When $X^{\top}X$ is invertible, the closed form is:

$$
\hat\beta = (X^{\top}X)^{-1} X^{\top} y
$$

(Quant / research loops sometimes ask you to derive this via $\nabla_\beta = 0$.) Numerically, libraries use QR / SVD rather than forming $(X^{\top}X)^{-1}$ naively.

Geometrically, $\hat y = X\hat\beta$ is the **projection** of $y$ onto the column space of $X$. Residuals $e = y - \hat y$ are orthogonal to those columns.

## Assumptions (interview checklist)

Classic “LINE”-style assumptions for inference / BLUE-style stories:

1. **Linearity** — $E[y \mid X]$ is linear in the parameters (or transform features)
2. **Independence** — errors independent (watch time series / clustered data)
3. **Homoscedasticity** — constant error variance (else WLS / robust SEs)
4. **Normality of errors** — mainly for exact $t$/$F$ inference; prediction can still work without it
5. **No perfect multicollinearity** — full column rank
6. **Exogeneity** — errors uncorrelated with predictors (causal claims need more)

Interviewers love: name the assumptions, say what breaks, and what you do (plots, transforms, robust methods, different model).

## Fit metrics

| Metric | Formula idea | Notes |
| --- | --- | --- |
| **MSE** | $\frac{1}{n}\sum e_i^2$ | Same units² as $y$ |
| **RMSE** | $\sqrt{\mathrm{MSE}}$ | Same units as $y$ |
| **MAE** | $\frac{1}{n}\sum \|e_i\|$ | More robust to outliers than MSE |
| **R²** | $1 - \mathrm{SS_{res}}/\mathrm{SS_{tot}}$ | Fraction of variance “explained”; can mislead |

Always compare metrics on **held-out** data (or CV). High train R² + weak test R² → overfit.

## Multicollinearity and regularization

**Multicollinearity:** predictors move together → unstable, hard-to-interpret $\beta$s (large SEs, sign flips). Checks: correlation matrix, VIFs, condition number. Fixes: drop / combine features, domain constraints, **ridge**.

**Ridge (L2)** and **lasso (L1)** add penalties (see [Math Behind ML](./lesson-22-math-behind-ml)): shrink coefficients; lasso can zero some out. Use when $p$ is large, features correlated, or you want sparsity.

## Quick synthesis

| Topic | Sound bite |
| --- | --- |
| Model | $y = X\beta + \varepsilon$; read $\beta_j$ as a partial effect |
| OLS | Minimize $\|y - X\beta\|^2$; $\hat\beta = (X^{\top}X)^{-1}X^{\top}y$ when invertible |
| Assumptions | LINE + rank + exogeneity for clean inference |
| Metrics | MAE / MSE / RMSE / R² — always check held-out |
| Collinearity | Unstable β; ridge / drop features / combine |
| Code | Drills after OLS, after metrics, and after regularization (sklearn) |
