**Reinforcement learning (RL)** sits outside supervised and unsupervised learning. An **agent** takes **actions** in an **environment**, visits **states**, and receives **rewards**. The goal is to learn a behavior that maximizes long-term return — not to imitate labeled “correct” outputs.

Famous use cases: games (AlphaGo, chess, StarCraft) and robotics. Prefer RL when the problem is **decisions over time** and you do **not** already know the right action labels (supervised assumes you do). Unless RL is on your résumé, most DS interviews will not drill it deeply — still know the vocabulary.

## Core components

| Piece | Role |
| --- | --- |
| **Reward function** | Scores good vs bad outcomes in a state (defines the goal) |
| **Policy** | Maps states → actions (how the agent chooses) |
| **Model** | Predicts next state / reward given (state, action) — optional; model-free methods skip an explicit dynamics model |
| **Value function** | Predicts expected **discounted** future return from a state (or state–action); re-estimated as the agent learns |

Learning loop: act → observe reward & next state → update policy / values → repeat.

## Discounting, exploration, Q-learning

**Return** with discount $\gamma\in[0,1]$:

$$
G_t = r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + \cdots
$$

One-step **Bellman** sketch: $V(s) \approx r + \gamma V(s')$.

**Q-learning** (model-free) updates action-values:

$$
Q(s,a) \leftarrow Q(s,a) + \alpha\big(r + \gamma \max_{a'} Q(s',a') - Q(s,a)\big)
$$

**ε-greedy:** with probability $1-\varepsilon$ pick $\arg\max_a Q(s,a)$; otherwise explore randomly — because good actions are not labeled up front.

## Interview note

| When RL shows up | What to say |
| --- | --- |
| Gaming / robotics / sequential control | Agent, reward, policy, value, explore/exploit |
| Typical product DS | Prefer supervised / unsupervised unless RL is in scope |
| Contrast | Supervised = labeled y; RL = learn actions from reward |
