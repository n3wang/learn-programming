## Item 74: Document all exceptions thrown by each method

Document **every** exception a method can throw — checked **and** unchecked — with **`@throws`** in Javadoc (Item 56). Unchecked exceptions describe **preconditions**; unchecked docs are especially important on **interfaces**.

Rules:

- Declare **each checked exception individually** in the method’s **`throws`** clause — never `throws Exception` or `throws Throwable` (except `main`).
- Document unchecked exceptions with **`@throws` only** — do **not** list them in `throws` (that visual distinction matters).
- Class-level docs can cover repeated cases (e.g. “all methods throw `NullPointerException` on null args”).

## Item 75: Include failure-capture information in detail messages

When something fails in production, the stack trace’s **detail message** may be the only clue. Include **parameter and field values** that contributed to the failure:

```java
throw new IndexOutOfBoundsException(
    "Index: " + index + ", Size: " + size);
```

Prefer exception **constructors** that take structured data and build the message centrally — and expose **accessors** on checked exceptions for recovery logic. Don’t put secrets (passwords, keys) in messages.

Detail messages are for **engineers**, not end-user UI copy.

<CodingExam

## Item 76: Strive for failure atomicity

After a method throws, the object should usually remain **usable** — in the same state as before the call (**failure-atomic**).

Techniques:

1. **Immutable objects** — failure atomicity is free.
2. **Validate before mutate** — check preconditions first (`Stack.pop` checks `size == 0` before `--size`).
3. **Compute-then-commit** — do risky work on a copy, swap in on success.
4. **Recovery/rollback** — rare; mainly for durable structures.

Document when atomicity **cannot** be guaranteed (e.g. after `ConcurrentModificationException`).

<CodingExam
  title="check before mutate"
  heading="Challenge: failure atomicity"
  lang="java"
  filename="Main.java"
  prompt="Counter starts at 0. decrement() throws IllegalStateException when count is already 0 — check BEFORE decrementing so count stays 0 on failure. wrap: decrement once on empty counter; print count after catch."
  sampleLog={`0`}
  starter={`public class Main {
    public static class Counter {
        private int count = 0;

        public int getCount() {
            return count;
        }

        public int decrement() {
            count--;
            if (count < 0) {
                throw new IllegalStateException("below zero");
            }
            return count;
        }
    }
}
`}
  wrapSuffix={`
class Runner {
    public static void main(String[] args) {
        Main.Counter c = new Main.Counter();
        try {
            c.decrement();
        } catch (IllegalStateException e) {
            // expected on empty counter
        }
        System.out.println(c.getCount());
    }
}
`}
  sourceChecks={[
    { name: 'check before decrement', pattern: 'if\\s*\\(\\s*count\\s*<=\\s*0|if\\s*\\(\\s*count\\s*==\\s*0|if\\s*\\(\\s*0\\s*>=\\s*count', must: true, hint: 'if (count <= 0) throw ... before count--' },
    { name: 'decrement after check', pattern: 'count--', must: true, hint: 'decrement only after the guard passes' },

## Item 77: Don’t ignore exceptions

An **empty catch block** silences failures and makes debugging nightmares — the program may fail later, far from the root cause.

```java
// Don't
try {
    ...
} catch (SomeException e) {
}

// Rare OK: comment why, name variable ignored
} catch (IOException ignored) {
    // already read everything needed; close failure is harmless
}
```

Prefer **handling**, **propagating**, or **logging**. Applies to checked **and** unchecked exceptions.

<CodingExam
  title="do not swallow"
  heading="Challenge: propagate, don't ignore"
  lang="java"
  filename="Main.java"
  prompt="runChecked(action) invokes action.run(). If it throws RuntimeException, rethrow it — do not use an empty catch block. wrap: action throws IllegalArgumentException; catch outside and print propagated."
  sampleLog={`propagated`}
  starter={`public class Main {
    public static void runChecked(Runnable action) {
        try {
            action.run();
        } catch (RuntimeException e) {
        }
    }
}
`}
  wrapSuffix={`
class Runner {
    public static void main(String[] args) {
        try {
            Main.runChecked(() -> {
                throw new IllegalArgumentException("fail");
            });
            System.out.println("ok");
        } catch (IllegalArgumentException e) {
            System.out.println("propagated");
        }
    }
}
`}
  sourceChecks={[
    { name: 'rethrow', pattern: 'throw\\s+e\\s*;|throw\\s+new\\s+\\w+Exception\\s*\\(\\s*e\\s*\\)', must: true, hint: 'throw e; or wrap and rethrow' },
    { name: 'no empty catch', pattern: 'catch\\s*\\(\\s*RuntimeException\\s+\\w+\\s*\\)\\s*\\{\\s*\\}', must: false, hint: 'empty catch ignores the failure' },
  ]}
  tests={[
    { name: 'rethrows', stdin: '', equals: 'propagated' },
  ]}
/>
