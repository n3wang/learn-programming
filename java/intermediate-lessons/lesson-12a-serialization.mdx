> **Source:** Effective Java, 3rd Edition — Chapter 12 by Joshua Bloch (Items 85–87)

Java serialization encodes object graphs as bytes — and opens a large **attack surface** (gadget chains, deserialization bombs). These items: avoid it when you can, implement `Serializable` only with care, and design a **logical** serialized form.

## Item 85: Prefer alternatives to Java serialization

Deserialization invokes **`readObject`** on types that implement **`Serializable`** — including library **gadgets** you never intended to run. Untrusted byte streams can mean **RCE**, **DoS** (deserialization bombs), or worse.

**Winning move:** don’t play — **don’t deserialize untrusted data**. For new systems use **JSON**, **Protocol Buffers**, or similar **cross-platform structured data** (attribute maps, not arbitrary object graphs).

If legacy serialization is unavoidable:

- Never accept untrusted streams (including careless **RMI**)
- Use **`ObjectInputFilter`** (Java 9+) — prefer **whitelisting** over blacklisting
- Filters limit class/memory depth but **won’t** stop all bombs

## Item 86: Implement Serializable with great caution

`implements Serializable` is a **long-term API commitment**: the **serialized form** becomes exported forever. Default serialization exposes **private fields** and ties you to the **physical** representation.

Costs:

- **Evolution** — missing **`serialVersionUID`** breaks compatibility when the class changes
- **Security** — deserialization is a hidden constructor (Item 88)
- **Testing** — round-trip across releases

**Declare explicitly:**

```java
private static final long serialVersionUID = 1L;
```

**Inner classes** should not implement Serializable (ill-defined default form). **Static member classes** may. Classes for **inheritance** rarely should implement Serializable.

## Item 87: Consider using a custom serialized form

**Default serialized form** mirrors the **physical** object graph — often wrong when representation ≠ **logical state** (linked lists, hash tables).

Prefer **custom** `writeObject` / `readObject` emitting **logical data** only. Mark implementation fields **`transient`**. Still call **`defaultWriteObject`/`defaultReadObject`** first (even if all fields are transient) for forward compatibility.

Document serialized fields with **`@serial`** and custom writers with **`@serialData`**. Declare **`serialVersionUID`**.

<CodingExam
  title="custom write read"
  heading="Challenge: logical serialized form"
  lang="java"
  filename="Main.java"
  prompt="StringBag stores strings in a transient list. writeObject: defaultWriteObject, writeInt(size), each string. readObject: defaultReadObject, new ArrayList, read size, add each string. serialVersionUID=1L. wrap: round-trip bag with a,b; print size:second."
  sampleLog={`2:b`}
  starter={`import java.io.IOException;
import java.io.ObjectInputStream;
import java.io.ObjectOutputStream;
import java.io.Serializable;
import java.util.ArrayList;
import java.util.List;

public class Main {
    public static class StringBag implements Serializable {
        private static final long serialVersionUID = 1L;
        private transient List<String> items = new ArrayList<>();

        public void add(String s) {
            items.add(s);
        }

        public List<String> items() {
            return List.copyOf(items);
        }

        private void writeObject(ObjectOutputStream out) throws IOException {
            out.defaultWriteObject();
        }

        private void readObject(ObjectInputStream in) throws IOException, ClassNotFoundException {
            in.defaultReadObject();
            items = new ArrayList<>();
        }
    }
}
`}
  wrapSuffix={`
class Runner {
    public static void main(String[] args) throws Exception {
        Main.StringBag bag = new Main.StringBag();
        bag.add("a");
        bag.add("b");
        byte[] bytes;
        try (java.io.ByteArrayOutputStream bos = new java.io.ByteArrayOutputStream();
             java.io.ObjectOutputStream oos = new java.io.ObjectOutputStream(bos)) {
            oos.writeObject(bag);
            bytes = bos.toByteArray();
        }
        try (java.io.ObjectInputStream ois = new java.io.ObjectInputStream(
                new java.io.ByteArrayInputStream(bytes))) {
            Main.StringBag restored = (Main.StringBag) ois.readObject();
            System.out.println(restored.items().size() + ":" + restored.items().get(1));
        }
    }
}
`}
  sourceChecks={[
    { name: 'transient list', pattern: 'transient\\s+List\\s*<\\s*String\\s*>\\s+items', must: true, hint: 'private transient List<String> items' },
    { name: 'write size', pattern: 'writeInt\\s*\\(\\s*items\\.size\\(\\s*\\)|writeInt\\s*\\(', must: true, hint: 'out.writeInt(items.size()); then write each string' },
