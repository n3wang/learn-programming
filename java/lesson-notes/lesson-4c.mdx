## Chapter summary

:::important Key takeaways

1. An `if` / `else if` / `else` chain is a great fit whenever a program has to react differently to a small, fixed set of situations (a signal number, a weather condition).
2. Put a trailing `else` on chains that read outside input — it is your safety net for values you did not explicitly plan for.
3. Combining boolean conditions with `&&` (and) and `||` (or) lets one branch cover a rule that depends on more than one fact at once (temperature **and** days since rain).
4. Test the edges of your conditions (the boundary between two branches) — that is where off-by-one mistakes hide.

:::
