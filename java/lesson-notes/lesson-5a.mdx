## Chapter summary

:::important Key takeaways

1. `new Random()` creates a random number generator; `rand.nextInt(bound)` gives a value from `0` up to (not including) `bound`.
2. Add 1 to `nextInt(n)` to shift a `0..n-1` range into a `1..n` range (a classic die roll).
3. Since randomness cannot be tested by comparing exact output, separate the **decision logic** (what to do with a roll) from the **random source** (how the roll was generated) — you can test the logic on its own by passing in a known value.
4. `DecimalFormat("0.00")` formats a `double` to a fixed number of decimal places, useful for cleaning up `Math.random()` output.

:::
