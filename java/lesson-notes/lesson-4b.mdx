```java

public class Main {
  public static void main(String[] args) {
    
    int age = 17;
    if(age == 17){
      System.out.println("Age is 17");
    }else if(age>17) {
      System.out.println("You are an adult now");
    }else{
      System.out.println("You are still a kid.");
    }
  }
}
```

Explaination:
```java
If (Boolean condition1) Then

    (perform computation or action)

Else if (Boolean condition2) Then

    (perform another computation or action)

Else
    (perform a default computation or action)
```

## Chapter summary

:::important Key takeaways

1. `if` / `else if` / `else` runs **exactly one** branch — the first condition that is true, or the final `else` if none match.
2. Order matters: conditions are checked top to bottom, and the chain stops at the first match, so put the most specific checks first.
3. Nested `if`s (an `if` inside another `if`'s block) let you check a second condition only when the first already passed.
4. Leaving out the final `else` is fine if you genuinely have nothing to do for the "none of the above" case — but it is easy to forget a case by accident, so double check.

:::
