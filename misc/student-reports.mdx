# Student reports

Daily participation from the settings **Pick student** tool (stored in this browser via IndexedDB).

- **+** → +1 point  
- **−** → −1 point  
- **Absent** → removed from that day’s random pool  

Students with points closer to **0** are more likely to be picked. Former names that no longer appear on the roster still show if they have saved data for that day.
