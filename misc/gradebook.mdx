<PageTitle title="成绩册" subtitle="按周记录各班成绩。">

- 需要以 **管理员** 身份登录才能编辑。
- 选择班级和学期（**上半** 2–7 月，**下半** 8–次年 1 月）。都会被记住；新学期开始时自动切换到当前学期。
- **最近5周**（默认）：最近五周并排显示，每个成绩都可以直接修改；点击周标题打开该周。
- **单周** / 周按钮：编辑一周（添加或重命名栏目、写评语、设置对家长可见）。
- **+ 新的一周**：添加下一周，沿用上一周的栏目，成绩为空。每个学期从第1周开始编号。
- **+ 课堂表现 / 作业 / 小测 / 考试 / 网站活动**：添加成绩栏目。在栏目顶部可以改名、改满分；**‹ ›** 调整顺序，**×** 删除。
- 成绩可以填数字或等级：优 优- 良 良- 及格 差 不及格 未交 `-`（快捷键 `y` `y-` `l` `l-` `j` `c` `b` `w`）。`-` 表示免交，不计入成绩。
- 输入后按 **Enter**（或 ↓）到下一行。从表格（Excel / Sheets）复制一整列，粘贴到第一个格子即可整列填入。
- **=满分**：空格填满分。**↻自动**：课堂表现按本周点名加减分（满分的一半 ± 分数）填写；网站活动按本周活动次数（每次 1 分，不超过满分）填写，会覆盖原有成绩。
- 修改会自动保存。勾选 **对家长可见** 后，该周会显示在 [成绩](./report) 页面上；标有 **·** 的周家长看不到。
