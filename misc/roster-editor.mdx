# Roster editor (admin)

Bulk-edit a class list as **tab-separated text** (copy/paste from Sheets or Excel).

- Load a roster → edit names / pinyin / approx / email in the big text box → **Save**
- **Replace** archives students who disappear from the text (history kept)
- **Merge** only adds or updates rows

Admin login required (`admin` / `admin` in settings).
